# Кейсы экрана S-14

База кейсов живёт между ночами. Номера постоянные и не переиспользуются: кейс, потерявший
смысл, помечается устаревшим, но не удаляется и номер не отдаёт.

Пройденным кейс считается только со скриншотом в `docs/evidence/<карточка>/`.
Проверка чтением кода, curl или пересказом разработчика не засчитывается.

Формат: `S-14-TC-001 · название` → начало, действия, точный ожидаемый результат.

## Кейсы

### S-14-TC-001 · Упаковка после кросс-складского подбора проходит без тоста «Товар списан из другой ячейки»

**Добавлен:** 04-warehouse-switch · 2026-08-22

**Начало:** Тенант с двумя настоящими складами. Поставка FBS создана на «Основном» складе.
Товар подобран из ячейки «Дополнительного» склада через кросс-складской подбор (S-03-TC-008).
Заказ в поставке переведён в статус «Подобран» и готов к упаковке. Авторизован как
`fulfillment_admin`. Оператор переходит к упаковке.

**Действия:**

1. Перейти на `/app/ff/packaging` (экран `FfPackagingPage`).
2. Найти задание на упаковку для данного заказа.
3. Отсканировать/выбрать товар и ввести данные упаковки.
4. Нажать «Упаковать» (или аналогичную кнопку завершения).
5. Дождаться ответа системы.

**Ожидаемый результат:**

Упаковка проходит успешно. На экране **не появляется** тост с текстом «Товар списан из
другой ячейки сортировки» (или похожим). Статус заказа меняется на «Упакован» (или
следующий по процессу). Никаких предупреждений о складе на экране упаковки нет.

### S-14-TC-002 · На экране упаковки нет никакого выбора или упоминания склада

**Добавлен:** 04-warehouse-switch · 2026-08-22

**Начало:** Тенант с двумя настоящими складами. Авторизован как `fulfillment_admin`.
Есть хотя бы одно задание на упаковку.

**Действия:**

1. Перейти на `/app/ff/packaging`.
2. Осмотреть весь экран: шапку, форму задания, кнопки, фильтры.

**Ожидаемый результат:**

На экране нет ни одного элемента выбора склада: ни `WarehouseSwitcher` (он только в
глобальной шапке `AuthedAppLayout`, но не дублируется здесь), ни селекта «Склад для
упаковки», ни подписи «Текущий склад: N». Экран содержит только то, что относится
к упаковке: список заданий, поле ввода баркода, кнопки.
