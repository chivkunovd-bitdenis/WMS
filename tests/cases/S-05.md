# Кейсы экрана S-05

База кейсов живёт между ночами. Номера постоянные и не переиспользуются: кейс, потерявший
смысл, помечается устаревшим, но не удаляется и номер не отдаёт.

Пройденным кейс считается только со скриншотом в `docs/evidence/<карточка>/`.
Проверка чтением кода, curl или пересказом разработчика не засчитывается.

Формат: `S-05-TC-001 · название` → начало, действия, точный ожидаемый результат.

## Кейсы

### S-05-TC-001 · Сборка ленты ЧЗ из HonestSign пока S-03 уже собирает ленту — тредпул не блокирует

**Карточка:** 05-prod-slow (A — смежный экран, карта волны MAP.md строка «HonestSignScreen / HonestSignProductPage — ручка /marking-codes/label-artifact-tape переезжает в тредпул (05)»)

**Начало.** Стенд доступен. В Tab A открыт S-03, модалка `FbsPrintPreviewDialog`
готова к печати с 155 кодами. В Tab B открыт S-05 (`FfHonestSignPage`,
`/app/ff/honest-sign`), подготовлен запрос на печать ленты ЧЗ. В третьей вкладке —
готов `GET /health`.

**Действия.**
1. В Tab A нажать «Печать» — запущен `POST /marking-codes/label-artifact-tape`
   (155 кодов, тредпул занят).
2. **Немедленно** в Tab B запустить печать ленты ЧЗ из интерфейса S-05.
3. Пока оба запроса in-flight, выполнить `GET /health` из третьей вкладки.

**Точный ожидаемый результат.**
- `GET /health` возвращает **HTTP 200 за ≤100 мс** — не зависает.
- Оба запроса завершаются успешно: каждый из браузеров получает корректный PDF.
- Интерфейс S-05 не показывает ошибку «сервер не отвечает» и не зависает.
- Печать в S-05 работает так же, как до переезда в тредпул: кнопка → индикатор
  ожидания → открывается диалог браузера «Печать» с PDF.

### S-05-TC-002 · Сборка ленты ЧЗ из S-05 → сервер вернул 500 → ErrorNotice, не крэш

**Карточка:** 05-prod-slow (A — смежный экран, ломающий)

**Начало.** Открыт S-05 (`FfHonestSignPage`). На стенде временно настроена
заглушка, возвращающая HTTP 500 на `POST /marking-codes/label-artifact-tape`
(имитация сбоя PyMuPDF или тредпула).

**Действия.**
1. Инициировать сборку ленты ЧЗ из интерфейса S-05.
2. Дождаться ответа от сервера (500).

**Точный ожидаемый результат.**
- Экран S-05 показывает `ErrorNotice` (`Alert severity="error"`) с текстом
  на языке склада — например, **«Не удалось собрать ленту ЧЗ»**.
- В тексте ошибки нет «500», «Internal Server Error», стектрейса, технических слов.
- Страница S-05 **не крашится**: шапка, фильтры, таблица остаются на месте.
- Кнопка «Печать ленты» снова активна — оператор может повторить попытку.
