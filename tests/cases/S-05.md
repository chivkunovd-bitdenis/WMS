# Кейсы экрана S-05

База кейсов живёт между ночами. Номера постоянные и не переиспользуются: кейс, потерявший
смысл, помечается устаревшим, но не удаляется и номер не отдаёт.

Пройденным кейс считается только со скриншотом в `docs/evidence/<карточка>/`.
Проверка чтением кода, curl или пересказом разработчика не засчитывается.

Формат: `S-05-TC-001 · название` → начало, действия, точный ожидаемый результат.

## Кейсы

### S-05-TC-001 · Фактический вердикт Wildberries для привязанного кода

**Начало.** Оператор FF вошёл в систему и открыл `/app/ff/honest-sign`. Для FBS-заказа
`WB-1001` локально привязан код маркировки `010123456789012121ABC`; Wildberries в ответе
проверки этого заказа возвращает для кода решение `filled`.

**Действия.** Оператор открывает строку заказа `WB-1001` и запускает проверку маркировки.

**Ожидаемый результат.** После завершения проверки у кода `010123456789012121ABC` показано
решение Wildberries `filled`; рядом нет сообщения об ошибке проверки. При повторном открытии
строки тот же вердикт остаётся видимым, то есть экран не возвращается к исходному локальному
статусу вместо полученного ответа WB.

### S-05-TC-002 · Код есть локально, но отсутствует в ответе Wildberries

**Начало.** Оператор FF вошёл в систему и открыл `/app/ff/honest-sign`. Для FBS-заказа
`WB-1002` локально привязан код маркировки `010123456789012121MISSING`, однако ответ
Wildberries для этого заказа не содержит ни этого кода, ни его метаданных.

**Действия.** Оператор открывает строку заказа `WB-1002` и запускает проверку маркировки.

**Ожидаемый результат.** После завершения проверки код `010123456789012121MISSING` не
показан как подтверждённый Wildberries и не получает зелёный признак «всё в порядке».
Оператор видит, что результат WB для этого локально привязанного кода отсутствует, и может
отличить это расхождение от успешного решения `filled` или `optional`.

**Ограничение контракта.** До решения владельца не проверяется конкретное имя состояния
(`rejected`, `unlinked`, `conflict` либо другое) и действие с уже потраченным кодом пула:
источник их не определяет.
