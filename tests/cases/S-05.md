# Кейсы экрана S-05

База кейсов живёт между ночами. Номера постоянные и не переиспользуются: кейс, потерявший
смысл, помечается устаревшим, но не удаляется и номер не отдаёт.

Пройденным кейс считается только со скриншотом в `docs/evidence/<карточка>/`.
Проверка чтением кода, curl или пересказом разработчика не засчитывается.

Формат: `S-05-TC-001 · название` → начало, действия, точный ожидаемый результат.

## Кейсы

### S-05-TC-001 · Обновление списка не скрывает предупреждение о межскладском подборе

**Начало:** оператор открыл диалог создания FBS-поставки. Для склада «Север» остатка не хватает, но общий остаток на «Север» и «Юг» достаточен; уже показан `WarningNotice` с разбивкой, откуда нужно подобрать товар.

**Действия:** дождаться автоматического обновления списка FBS либо вручную обновить данные, пока диалог остаётся открытым.

**Ожидаемый результат:** после обновления остаются то же предупреждение и разбивка для актуальных заказов; кнопка `Создать поставку` доступна, пока общего остатка достаточно. Если данные изменились и общего остатка уже не хватает, предупреждение заменяется на блокирующую понятную ошибку до создания поставки; диалог не создаёт документ по устаревшим данным.
