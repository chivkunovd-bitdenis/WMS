# Кейсы экрана S-19

База кейсов живёт между ночами. Номера постоянные и не переиспользуются: кейс, потерявший
смысл, помечается устаревшим, но не удаляется и номер не отдаёт.

Пройденным кейс считается только со скриншотом в `docs/evidence/<карточка>/`.
Проверка чтением кода, curl или пересказом разработчика не засчитывается.

Формат: `S-19-TC-001 · название` → начало, действия, точный ожидаемый результат.

## Кейсы

### S-19-TC-001 · Тариф хранения использует единый контур начислений

**Начало:** администратор ФФ открыл вкладку «Тарифы ФФ»; есть операционный склад и
зафиксированный расчёт хранения за прошлый месяц для одного селлера.

**Действия:** найти ставку хранения для этого склада, сверить единицу и код услуги, затем
открыть начисления за тот же период.

**Ожидаемый результат:** ставка существует в едином тарифном контуре с кодом
`storage_liter_day` и единицей «литро-день». В начислениях ей соответствует одна строка
хранения с количеством литро-дней, снимком этой ставки и суммой зафиксированного расчёта.
Отдельного второго тарифа, второго журнала или отдельного счёта «за хранение» интерфейс не
создаёт; повторное открытие начислений не дублирует строку.
