# Кейсы экрана S-08

База кейсов живёт между ночами. Номера постоянные и не переиспользуются: кейс, потерявший
смысл, помечается устаревшим, но не удаляется и номер не отдаёт.

Пройденным кейс считается только со скриншотом в `docs/evidence/<карточка>/`.
Проверка чтением кода, curl или пересказом разработчика не засчитывается.

Формат: `S-08-TC-001 · название` → начало, действия, точный ожидаемый результат.

## Кейсы

### S-08-TC-001 · Хранение читает фактический склад межскладского движения

**Начало:** для товара есть подтверждённый кросс-складской подбор: исходящая сторона переноса записана на «Юг», входящая — на «Север», обе стороны принадлежат одной операции. В списке рабочих экранов оператор меняет контекст между этими складами.

**Действия:** открыть расчёт хранения за период, включающий дату переноса, сначала с контекстом «Юг», затем с «Север».

**Ожидаемый результат:** расчёт использует фактический склад, записанный у каждой стороны движения, а не текущий экранный контекст или нынешнюю связь ячейки. Операционные остатки и литро-дни не удваиваются и не исчезают при переключении; служебный `FBS WB *` в расчёт не попадает.
