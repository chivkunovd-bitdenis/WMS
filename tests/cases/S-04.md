# Кейсы экрана S-04

База кейсов живёт между ночами. Номера постоянные и не переиспользуются: кейс, потерявший
смысл, помечается устаревшим, но не удаляется и номер не отдаёт.

Пройденным кейс считается только со скриншотом в `docs/evidence/<карточка>/`.
Проверка чтением кода, curl или пересказом разработчика не засчитывается.

Формат: `S-04-TC-001 · название` → начало, действия, точный ожидаемый результат.

## Кейсы

### S-04-TC-001 · Контекст склада ограничивает данные остатков WB

**Начало:** оператор ФФ вошёл в систему. У tenant есть операционные склады «Север» и «Юг» и служебный `FBS WB Москва`; для «Север» существуют привязки и данные остатков WB.

**Действия:** открыть «Остатки WB», выбрать в строке `Склад` значение «Север».

**Ожидаемый результат:** экран показывает разбивку и привязки только для «Север». В выборе нет `FBS WB Москва`; смена контекста не показывает сообщение об обновлении или публикации остатка WB.
