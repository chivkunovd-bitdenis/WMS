# Кейсы экрана S-33 · ReportsHubScreen — портал ФФ

База кейсов живёт между ночами. Номера постоянные и не переиспользуются: кейс, потерявший
смысл, помечается устаревшим, но не удаляется и номер не отдаёт.

Пройденным кейс считается только со скриншотом в `docs/evidence/<карточка>/`.
Проверка чтением кода, curl или пересказом разработчика не засчитывается.

Формат: `S-33-TC-001 · название` → начало, действия, точный ожидаемый результат.

## Кейсы

### S-33-TC-001 · Открытие раздела «Отчёты» через пункт меню ФФ

**Начало.** Пользователь вошёл как ФФ-администратор (роль `isFulfillmentAdmin`). Открыт любой экран ФФ-портала.

**Действия.**
1. Найти в левом меню пункт «Отчёты».
2. Кликнуть пункт.

**Ожидаемый результат.** Браузер переходит на `/app/ff/reports`. Страница содержит заголовок **«Отчёты»** (ScreenHeader, h5) и подзаголовок **«Данные по складу, приёмкам, отгрузкам и остаткам за период»** (body2). Слева — вертикальный список отчётов в `Paper variant="outlined"`. Справа — рабочая область выбранного отчёта.

### S-33-TC-002 · Двухпанельный каркас без карточек внутри карточки

**Начало.** Открыт `/app/ff/reports` как ФФ-администратор.

**Действия.** Просмотреть страницу без дополнительных действий.

**Ожидаемый результат.** Видны ровно два `Paper variant="outlined"`: левый (навигационный список) и правый (рабочая область). Ни одна из зон правой области — фильтры, таблица, totals, график — не обёрнута в отдельную «карточку внутри карточки». В заголовке экрана нет счётчиков, KPI-плашек и цветных чипов статусов.

### S-33-TC-020 · Отчёт aging — четыре ковша, тона ok/neutral/warn/stop

**Начало.** Открыт отчёт «Мёртвые остатки» (`aging`). Есть товары с разным количеством дней без движения (минимум по одному в каждом ковше).

**Действия.** Дождаться загрузки таблицы. Посмотреть колонку «Ковш».

**Ожидаемый результат.** Колонка «Ковш» содержит `StatusChip` с одним из четырёх значений:
- **«0–30»** — тон `ok` (зелёный)
- **«30–60»** — тон `neutral` (синий)
- **«60–90»** — тон `warn` (жёлтый)
- **«90+»** — тон `stop` (красный)

Каждый товар попадает в ровно один ковш. Ковшей с другими подписями нет. В таблице только товары с положительным `inventory_balance` (нулевые остатки в `aging` не показаны).

### S-33-TC-022 · Сравнение в totals — стрелка ↑/↓ и % рядом с числом

**Начало.** Открыт отчёт с данными. В поле «Сравнение» выбрано «Прошлый период». Данные за оба периода ненулевые.

**Действия.** Посмотреть плитки totals.

**Ожидаемый результат.** Под каждым числом плитки — строка `body2`:
- Если текущий период **больше** прошлого: **«↑ +12% vs прошлый период»** — зелёный (тон `ok`).
- Если **меньше**: **«↓ −8% vs прошлый период»** — красный (тон `stop`).
- Если **равны**: без стрелки, нейтральный цвет.

Стрелки — unicode ↑/↓ inline в строке. Отдельного значка из ui-kit нет.
