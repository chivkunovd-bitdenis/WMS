# Кейсы экрана S-22

База кейсов живёт между ночами. Номера постоянные и не переиспользуются: кейс, потерявший
смысл, помечается устаревшим, но не удаляется и номер не отдаёт.

Пройденным кейс считается только со скриншотом в `docs/evidence/<карточка>/`.
Проверка чтением кода, curl или пересказом разработчика не засчитывается.

Формат: `S-22-TC-001 · название` → начало, действия, точный ожидаемый результат.

## Кейсы

### S-22-TC-001 · Приёмка создаётся в текущем складе без дублирующего поля

**Начало:** оператор ФФ вошёл в систему. У tenant есть операционные склады «Север» и «Юг».

**Действия:** открыть «Приёмка», выбрать «Юг» в строке `Склад`, начать новую заявку на приёмку и заполнить её обязательные поля.

**Ожидаемый результат:** в форме нет второго поля `Склад для заявки`; создаваемая заявка получает склад «Юг». Набор доступных ячеек относится к «Юг».
