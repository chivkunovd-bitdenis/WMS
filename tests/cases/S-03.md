# Кейсы экрана S-03

База кейсов живёт между ночами. Номера постоянные и не переиспользуются: кейс, потерявший
смысл, помечается устаревшим, но не удаляется и номер не отдаёт.

Пройденным кейс считается только со скриншотом в `docs/evidence/<карточка>/`.
Проверка чтением кода, curl или пересказом разработчика не засчитывается.

Формат: `S-03-TC-001 · название` → начало, действия, точный ожидаемый результат.

## Кейсы

### S-03-TC-001 · Подтверждение WB видно в строке FBS-заказа после привязки кода

**Начало.** Оператор FF вошёл в систему. Есть FBS-заказ, для которого требуется маркировка,
и код уже можно привязать к заказу. Wildberries в ответ на проверку этого заказа подтверждает
возможность сдачи.

**Действия.**

1. Открыть экран FBS-заказов `/app/ff/fbs` и найти этот заказ.
2. Привязать к нему код маркировки штатным действием рабочего процесса.
3. Дождаться завершения проверки Wildberries и вернуться к строке этого заказа на экране
   FBS-заказов.
4. Перейти к передаче заказа в составе FBS-поставки.

**Ожидаемый результат.** В строке заказа до начала передачи есть понятная текстовая отметка,
что Wildberries подтвердил возможность сдачи. Строка не показывает оптимистичное «сдавать
можно» до ответа Wildberries. После такого подтверждения заказ проходит проверку перед
передачей; действие передачи не блокируется из-за отсутствия подтверждения WB.

### S-03-TC-002 · Отказ WB с причиной виден в строке до передачи FBS-заказа

**Начало.** Оператор FF вошёл в систему. Есть FBS-заказ, для которого требуется маркировка,
и код уже можно привязать к заказу. Wildberries в ответ на проверку возвращает отказ и его
причину.

**Действия.**

1. Открыть экран FBS-заказов `/app/ff/fbs` и найти этот заказ.
2. Привязать к нему код маркировки штатным действием рабочего процесса.
3. Дождаться завершения проверки Wildberries и вернуться к строке заказа, не начиная
   передачу.
4. Попробовать передать заказ в составе FBS-поставки.

**Ожидаемый результат.** До перехода к передаче строка показывает текстовый вердикт об
отказе Wildberries и причину, которую вернул маркетплейс. В строке нет статуса, означающего,
что сдача разрешена. Проверка перед передачей не считает заказ готовым и не позволяет
передать его, пока WB не подтвердит возможность сдачи.
