# Кейсы экрана S-03

База кейсов живёт между ночами. Номера постоянные и не переиспользуются: кейс, потерявший
смысл, помечается устаревшим, но не удаляется и номер не отдаёт.

Пройденным кейс считается только со скриншотом в `docs/evidence/<карточка>/`.
Проверка чтением кода, curl или пересказом разработчика не засчитывается.

Формат: `S-03-TC-001 · название` → начало, действия, точный ожидаемый результат.

## Кейсы

### S-03-TC-001 · Первая загрузка вкладки «Новые» — скелет, затем ровно 50 строк

**Карточка:** 05-prod-slow (C — пагинация списка)

**Начало.** Открыт экран «Заказы FBS» (`/app/ff/fbs`). Активна вкладка «Новые».
В системе есть не менее 50 заказов в статусе «Новый».

**Действия.**
1. Перезагрузить страницу браузера (`Cmd+R` / `Ctrl+R`) так, чтобы вкладка
   «Новые» загружалась с нуля.
2. Наблюдать за состоянием тела таблицы до и после ответа сервера.

**Точный ожидаемый результат.**
- Пока летит первый запрос к серверу: в теле таблицы видно **5 строк-заглушек**
  (`TableSkeletonBody`); спиннера поверх пустой таблицы нет.
- После ответа сервера: таблица содержит **ровно 50 строк** (не 100, не 500).
- Нигде на экране нет текста «50 из N», «страница 1 из …» или любого иного
  счётчика страниц — общее число «Новых» неизвестно до полного обхода.
- Таблица имеет **4 колонки**: «Товар», «Селлер», «Маршрут сдачи», «Отгрузить до»
  — ни одной лишней.

### S-03-TC-007 · Автотик 30 с обновляет только первую страницу, скролл не сбрасывается

**Карточка:** 05-prod-slow (C, R-38)

**Начало.** Экран S-03, вкладка «Новые». В системе >100 заказов. Загружены 2
страницы (нажата «Показать ещё» один раз — итого ≥100 строк). Оператор прокрутил
таблицу до строк второй страницы (строки 51–100 видны на экране).

**Действия.**
1. Подождать 30 секунд, не трогая мышь и не кликая.

**Точный ожидаемый результат.**
- В DevTools Network появился **один** новый запрос к `/fbs/worklist` с
  `limit=50` и **без** курсора (`cursor=null` или параметр отсутствует) — тик
  запросил только первую страницу.
- Строки второй страницы (51–100) **остаются** в таблице.
- Позиция прокрутки **не изменилась** — оператор по-прежнему видит строки
  второй страницы, экран не «прыгнул» наверх.
- Скелет строк **не появлялся** во время тика.
- Строка `formatFreshness` в шапке экрана обновилась с «N минут назад»
  на **«только что»**.

### S-03-TC-017 · Сборка PDF-ленты ЧЗ не блокирует соседние запросы (карточка A)

**Карточка:** 05-prod-slow (A — тредпул PDF)

- Сборка ленты завершается в штатном режиме: PDF приходит, модалка показывает
  результат (или открывает диалог браузера печати).
