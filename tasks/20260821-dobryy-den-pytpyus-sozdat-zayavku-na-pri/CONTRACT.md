# Контракт · кнопка добавления товара в заявку на приёмку

## Экран

`S-29` — новая заявка на поставку в кабинете селлера.

## Поведение

В окне «Выбор товаров» действие «Добавить в заявку» доступно только после того,
как для хотя бы одного доступного товара указано количество больше нуля. До этого
кнопка недоступна: пустое подтверждение не должно молча закрывать окно и создавать
впечатление, что добавление не сработало.

После ввода количества действие становится доступным и сохраняет выбранные товары
как раньше. Во время сохранения и для уже добавленных товаров правила блокировки
остаются прежними.

## API и данные

Не затрагиваются: формат и вызов API добавления строк остаются прежними. Пустой
набор больше не передаётся в обработчик подтверждения на клиенте.

## Тест-кейсы

1. После открытия окна выбора товаров кнопка подтверждения отключена.
2. После ввода положительного количества она включается.
3. Подтверждение создаёт строку заявки через существующий API-вызов.
