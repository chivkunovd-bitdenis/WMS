# 01 — Анализ + арх-коучинг

## Продуктовая часть
- **Проблема/цель по сути:** на вкладке «Новые» оператор видит заказы разных FBS-складов селлера в одном списке. Это повышает риск выбрать несовместимые заказы и тратить время на ручное отделение нужного склада.
- **Ожидаемое поведение:** оператор открывает «Новые», выбирает «Склад селлера», таблица остаётся в утверждённом виде и показывает только новые заказы этого склада.
- **Границы:** не меняем состав колонок FBS-таблицы, не добавляем технические чипы/статусы, не меняем сборку поставки и не трогаем WB-интеграцию.
- **Соответствие MVP-решениям:** фича остаётся внутри operator FBS flow и не противоречит разделению seller/WMS/WB складов.

## Техническая часть
- **Как устроено сейчас (по факту кода):** экран `FfFbsOrdersScreen.tsx` грузит `/operations/fbs-orders/worklist` с `seller_id`, `status_group`, `search`, `limit`. Ответ уже содержит `wms_warehouse` и `wb_warehouse` на каждой строке. Сервер собирает read model в `fbs_worklist_service.py`.
- **Где узкие/неочевидные места:** чисто клиентский фильтр по уже загруженным 200 строкам может пропустить подходящие заказы за пределами лимита. Поэтому фильтр должен попадать в API-запрос.
- **Варианты решения:** клиентский фильтр быстрее, но рискован при пагинации; отдельная ручка складов избыточна; выбран тонкий параметр `warehouse_id` в существующей worklist-ручке плюс `warehouse_options` в её ответе.
- **Предлагаемый стек/инструменты:** существующие FastAPI + SQLAlchemy на backend, React + MUI Select на frontend, pytest и Playwright для проверки.

## 🎓 Вопросы человеку (арх-коучинг — обязательно)
1. В WMS мы фильтруем по физическому WMS-складу, который уже привязан к WB-складу селлера. Это верная бизнес-единица для оператора?
2. Если у двух селлеров один физический WMS-склад, фильтр «Все селлеры + склад» должен показывать оба селлера или сначала всегда ожидается выбор селлера?
3. Нужен ли позже отдельный справочник складов селлера вне текущих новых заказов, или достаточно показывать склады, по которым сейчас есть новые FBS-заказы?
