# Контракт · печать внутренних коробов и грузомест

## Экран

Карточка приёмки на ФФ, существующий раскрывающийся раздел «Короба и грузоместа».

## Поведение

1. Кнопки «Печать коробов» и «Печать грузомест» остаются там же и доступны
   администратору ФФ, когда в документе есть соответствующие сущности — вне
   зависимости от статуса приёмки.
2. Подтверждение существующей модалки печатает все выбранные внутренние
   этикетки одним заданием принтера: каждая этикетка занимает одну физическую
   страницу выбранного размера, страницы идут подряд.
3. Одиночная печать и массовая печать внутренних коробов/грузомест используют
   одинаковый крупный Code 128: штрихи занимают рабочую ширину этикетки и имеют
   достаточную высоту для считывания складским сканером.
4. После печати каждая напечатанная сущность по-прежнему отмечается в системе;
   ошибка отметки показывается оператору, как и раньше.

## Не затрагивается

- API и данные;
- печать товарных ШК, ЧЗ, QR и ячеек;
- состав экрана и права доступа;
- процесс приёмки/сортировки.

## Проверки

- HTML массовой печати содержит все коды, физический размер выбранной этикетки
  и разрыв страницы между этикетками;
- подтверждение массовой печати вызывает один `window.print()`;
- представительский PNG Code 128 декодируется обратно в исходный код;
- кнопки массовой печати доступны после завершения приёмки.
