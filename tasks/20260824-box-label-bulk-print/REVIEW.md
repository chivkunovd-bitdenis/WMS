# Самопроверка перед независимым ревью

## Границы

Изменены только внутренние этикетки коробов и грузомест в приёмке и уже
существующий путь печати короба отгрузки. Товарные ШК, ЧЗ, QR и ячейки
используют прежний `default`/`storageCell` макет и не менялись.

## Поведение

- массовая печать создаёт один iframe и один вызов печати;
- каждая этикетка сохраняет выбранный физический размер и отделяется разрывом
  страницы, поэтому термопринтер получает одну ленту;
- PNG ждёт `image.decode()` перед печатью, а iframe живёт до `afterprint`;
- после печати каждая сущность помечается тем же существующим API.

## Гейты

- `npm run build` — зелёный;
- целевой Chromium E2E — зелёный, включая обратное декодирование ZXing;
- `git diff --check` — зелёный.

`npm run lint` сейчас красный до этой карточки: 61 ошибка в не затронутых
компонентах и экранах. В этом диффе новых lint-ошибок нет; исправлять их здесь
запрещено границей наряда.

Нужно независимое ревью перед интеграцией.
