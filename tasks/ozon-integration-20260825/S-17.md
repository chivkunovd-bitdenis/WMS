# Вердикт S-17 — приёмка и возвраты

Файл: экран по маршруту `/app/ff/reception` (см. `frontend/src/App.tsx`).

Готового вердикта по коду здесь нет намеренно: **возвраты Ozon в ресёрче остались неподтверждёнными**,
а кабинет заблокирован, живой проверки нет. Поэтому вердикт снимается на месте, по правилу — но
именно по правилу, а не свободным решением.

Порядок: открыть экран, перечислить кнопки и строки, и на каждую применить:

- процесс совпадает с текущим и наружу не ходит → `UNCHANGED`;
- то же действие, но под ним другой внешний метод → `PROVIDER_DISPATCH`, вид кнопки не меняется;
- без конкретного обязательного поля Ozon действие физически невозможно → `MINIMAL_DELTA`, одно поле,
  без нового блока;
- правило Ozon не подтверждено официальным источником → `BLOCKED`: действие локально выключено с
  понятной строкой на экране, остальной экран работает.

Запрещено: новый экран возвратов, отдельный раздел Ozon, изменение процесса приёмки для WB.
Если ни одно действие не требует дельты — это нормальный результат, так и записать и идти дальше.
