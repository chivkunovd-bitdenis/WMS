# Контракт S-16: вкладка коробов и источник прихода

## Просьба владельца

На экране «Каталог» сверху нужен явный переключатель между товарами и коробами. Экран товаров
не переделывается. Во вкладке «Короба и грузоместа» остаётся сканер физического короба, список
коробов и раскрываемый состав. Строки состава повторяют основные товарные колонки каталога:
фото, название, артикул продавца, SKU, ШК, размер и селлер. Дополнительно показываются количество
в коробе и документ, которым товар был принят: тип, номер и дата.

## Экран

- Под заголовком «Каталог» расположены две вкладки: «Товары» и «Короба и грузоместа».
- По умолчанию открыта вкладка «Товары». Её действия, фильтры, таблица, колонки и пустые состояния
  остаются без изменений.
- Во вкладке «Короба и грузоместа» сверху расположен приглушённый сканер. Успешный скан раскрывает
  и подсвечивает найденный короб; неизвестный ШК показывает локальную ошибку.
- Каждый короб раскрывается. Таблица состава использует тот же порядок и ширины основных товарных
  колонок, что и каталог, затем колонки «В коробе» и «Документ прихода».
- Грузоместо без поштучного состава честно показывает, что состав по нему не ведётся.

## API и данные

- Текущий read-only API коробов расширяется данными товарной строки и объектом `source_document`.
- `source_document` — общий контракт для разных источников: `kind`, `id`, `number`, `date`.
  Сейчас адаптер заполняет его из заявки на приёмку (`kind = inbound_intake`). Будущая
  инвентаризация или другой документ добавляет свой адаптер к этому контракту без изменения UI.
- Новых таблиц и миграций нет. Сканирование и просмотр ничего не изменяют в складских данных.
- Обратная совместимость текущих полей API сохраняется.

## Тест-кейсы

- `TC-NEW-CATALOG-BOX-003`: дан каталог; когда пользователь переключается между вкладками, тогда
  товарная таблица остаётся прежней, а коробная панель показывается отдельно.
- `TC-NEW-CATALOG-BOX-004`: дан наполненный короб; когда пользователь сканирует его ШК во вкладке
  коробов, тогда короб раскрывается, подсвечивается, а строка показывает основные колонки каталога,
  количество и приёмку с номером и датой.
- Негатив: неизвестный ШК не меняет выбранный короб и показывает понятную локальную ошибку.

## Не затрагивается

- Логика создания, наполнения, закрытия и распределения коробов.
- Существующие фильтры, колонки, действия и данные вкладки «Товары».
- Историческое хранение состава после фактического распределения товара.
