# Контракт · восстановление релизного гейта

## Экран

Экран и операторский сценарий не меняются.

## API и данные

- Устраняются только причины падения обязательных статических проверок и тестов.
- Поведение FBS, формат `FBS-*` и официальные QR от WB остаются прежними.
- Исправление ленивой загрузки данных не меняет ответ API, а предотвращает исключение `MissingGreenlet`.
- Служебные cleanup-скрипты проверяются безопасно; destructive-режим на реальной БД не запускается.

## Тест-кейсы

1. Полные `ruff check .`, `mypy .` и `pytest` проходят.
2. `npm run build` и полный `npm run test:e2e` проходят.
3. Целевые тесты проблемных сервисов проходят отдельно.
4. FBS QR и форматы штрихкодов не меняются.
5. В diff нет изменений production-интерфейса (`frontend/src`).
