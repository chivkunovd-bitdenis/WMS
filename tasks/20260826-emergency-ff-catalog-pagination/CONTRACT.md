# Контракт аварийного исправления каталога

## Экран

Каталог открывает первую страницу товаров без загрузки всего тенанта. Фильтры по селлеру,
поиску и категории применяются на сервере. Счётчик показывает число найденных товаров во
всём результате, а не только на текущей странице. Во время запроса экран сообщает о загрузке,
не выдавая пустой каталог за итог.

## API и данные

Новый совместимый постраничный маршрут возвращает `items`, `total` и категории. Старый
`GET /products/ff-catalog` сохраняется без изменений для существующих потребителей. Остатки
запрашиваются только для товаров текущей страницы. Миграций и изменений складских данных нет.

## Проверки

- первая страница ограничена и имеет точный `total`;
- селлер, поиск и категория фильтруют весь каталог до пагинации;
- устаревший запрос не перезаписывает новый;
- остатки загружаются только для идентификаторов текущей страницы;
- старый маршрут продолжает отвечать в прежнем формате.
