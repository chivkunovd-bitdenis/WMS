# Контракт · пустое подтверждение выбора товара

## Экран

`S-29`, портал селлера, новая заявка на поставку.

## Поведение

Если в окне «Выбор товаров» не выбран ни один товар с количеством больше нуля,
нажатие «Добавить в заявку» не закрывает окно и не делает пустой запрос. Внутри
окна появляется понятная ошибка: нужно выбрать товар и указать количество.

После выбора товара кнопка работает как раньше: создаёт или увеличивает строку
заявки через существующий API.

## API и данные

Не затрагиваются. Пустой набор останавливается до вызова API.

## Тест-кейсы

1. Пустое подтверждение оставляет окно открытым и показывает ошибку.
2. После ввода количества подтверждение отправляет POST строки и показывает её в заявке.
