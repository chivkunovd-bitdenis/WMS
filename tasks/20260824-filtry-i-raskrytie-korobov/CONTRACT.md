# Контракт · фильтры и раскрытие коробов

## Экран

`S-16`, только вкладка «Короба и грузоместа».

## Поведение

1. Над списком коробов и грузомест есть селект «Селлер» и компактный поиск по названию товара, артикулу (`sku_code`), артикулу продавца (`wb_vendor_code`) или ШК (`wb_barcode`). Сравнение без учёта регистра.
2. Если заполнены оба поля, строка состава должна пройти оба условия. Короб показывается только когда после этого в нём остаётся хотя бы одна строка; в раскрытом составе остаются только совпавшие строки.
3. Без фильтров короб или грузоместо с пустым составом (`lines.length === 0`) не показывается. Селлеры в селекте строятся только из непустых строк состава.
4. Открытие одного короба не закрывает остальные. Кнопка «Раскрыть все» раскрывает только короба, видимые в текущем фильтре.
5. Сканирование сохраняет активные фильтры. Если отсканированный короб не проходит текущий фильтр, он не подмешивается в список обходным путём.

## Не затрагивается

- Вкладка «Товары»: фильтры, таблица, действия и данные.
- FBS и другие экраны.
- API, модели, миграции и контракт ответа.
- Визуальная система и новые примитивы ui-kit.

## Проверки

- Unit: AND-фильтр по одной строке состава и скрытие пустого короба.
- E2E: AND-фильтр, скрытие пустого короба, независимое раскрытие, «Раскрыть все», сохранение фильтра при скане.
- Существующий сценарий сканирования и production build.
