## Просили дословно

> В разделе короба нужно добавить строчку для фильтрации по селлеру из списка и небольшую поисковую строку, куда можно вбить шика товара или артикул товара или название. Соответственно, короба, грузы места будут фильтроваться по этому, если... ну, по этим условиям. То есть они суммируются. Выбрали селлера, значит внутри селлера будут отображаться только товары, которые в поиске. Ну и наоборот. То есть только те короба, в которых есть хотя бы один этот товар, который соответствует условиям. Второе: пустые короба отсюда вообще надо скрывать, они тут не нужны. Только короба должны отображаться, в которых есть хотя бы одна позиция. Следующий момент. Сейчас, если я открываю один из коробов, потом открываю второй, то прошлый схлопывается. Нужно, чтобы они оставались открытыми, то есть я сколько угодно могу открыть. И следующий момент: маленькая аккуратная кнопка где-то должна быть, чтобы раскрыть все коробки.
