# Code Review · WB-совместимые ШК обычных коробов

Дата: 27.08.2026

Reviewer: изолированная сильная модель (`gpt-5.6-sol`, xhigh)

Финальный вердикт: `CODE_REVIEW_PASSED`

## Найдено и исправлено

1. E2E требовал старый формат `INB-` + 12 hex-символов.
2. Mocked-тесты lookup не доказывали обратную совместимость старых ШК.
3. Первый 30-символьный вариант формально проходил ограничения WB, но Code 128
   не читался стабильно с этикетки 58x40 мм на термопринтере 203 dpi.
4. Артефакты наряда устарели после восстановления общих release gates.

## Повторная проверка

- Точный формат: `<WHB|INB>-[0-9A-HJKMNP-TV-Z]{14}` — 18 символов, 70 случайных битов.
- Генератор использует равномерный `secrets.randbits(70)`, без фиксированных UUID-битов.
- Старые `WHB` и `INB` проходят настоящий SQLite/service attach path.
- Физический regression использует реальный `internalBox` renderer, 58x40 мм,
  `deviceScaleFactor=203/96` и ZXing: 4 худших шаблона и 256 детерминированных
  кодов декодируются точно; известный небезопасный 20-символьный canary не декодируется.
- Целевой backend: `23 passed`; целевой Playwright: `2 passed`.
- Полный backend: `1054 passed, 5 skipped`; полный Playwright: `202 passed, 7 skipped`.
- Все FBS production/test blobs совпадают с `origin/etalon`.
