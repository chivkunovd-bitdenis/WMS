# Контракт · база знаний «Создание приёмки»

## Пользовательский результат

В портале селлера и в интерфейсе ФФ появляется пункт «База знаний». Он открывает одну инструкцию
«Создание приёмки», которая проводит пользователя через весь согласованный сценарий: селлер создаёт
приёмку и передаёт её на склад, сотрудник ФФ находит документ, начинает приёмку, фиксирует фактическое
количество и завершает её.

## Экран

- В боковом меню обоих порталов есть один одинаково названный пункт «База знаний».
- В статье сверху виден результат и короткий маршрут из четырёх этапов.
- Шаги разделены по ролям: сначала «Селлер», затем «ФФ».
- Каждый шаг содержит настоящий скриншот интерфейса, одну обведённую зону действия, короткую инструкцию
  и пояснение, что пользователь увидит после действия.
- Из статьи можно перейти в рабочий раздел текущего портала: селлеру — в «Документы», сотруднику ФФ —
  в «Приёмку на FF».
- В рабочем настольном интерфейсе статья использует доступную ширину: текст и скриншоты стоят рядом,
  а на более узком окне складываются в одну колонку внутри существующего каркаса портала.

## API и данные

Не затрагиваются. Статья и изображения поставляются вместе с фронтендом; новые запросы к API не нужны.

## Состояния

- Успех: статья открывается из обоих порталов, все четыре изображения загружены, переход в рабочий
  раздел ведёт по правильному адресу.
- Ошибка изображения: у изображения есть осмысленный альтернативный текст, поэтому шаг остаётся понятен.
- Пустое состояние не предусмотрено: в этой волне опубликована ровно одна инструкция.

## Тест-кейсы

1. Селлер открывает «База знаний», видит статью, четыре шага, изображения и кнопку перехода в документы.
2. Администратор ФФ открывает тот же раздел, видит ту же статью и кнопку перехода в очередь приёмки.
3. У каждого шага есть ровно одна пронумерованная обводка и связанная с ней подсказка.
4. Существующие рабочие экраны создания и проведения приёмки не меняются.

## Не входит в эту волну

- API-ключи, интеграции маркетплейсов и отгрузка.
- Полнотекстовый поиск, категории, редактор статей и загрузка материалов через админку.
- Изменение самого процесса приёмки или его рабочих экранов.
