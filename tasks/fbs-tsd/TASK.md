# TASK — fbs-tsd: сборка FBS на мобильном ТСД

- **Эпик:** FBS — см. `../fbs-marketplace-orders/SPEC.md`. Гейт 1 эпика ✅, под-задача наследует.
- **Дизайн-принципы:** `../fbs-marketplace-orders/DESIGN.md` (минимализм, крупные цели под палец, спокойные статусы).
- **Тип / размер:** feature / L
- **Зависит от:** `fbs-orders-intake`, `fbs-supply-assembly`, `fbs-marking` (потребляет их API)
- **Трек:** мобильное Android-приложение ТСД. Состояние трека — `mobile/docs/PROGRESS.md` (читать первым).

## Описание (для Composer / мобильного трека)
Дать сборщику собирать заказы FBS прямо на ТСД (терминал сбора данных — мобильный сканер): открыть отгрузку,
идти по листу подбора, сканировать товар, вносить КИЗ сканером, отмечать «Собрал/Упаковал», печатать стикер
заказа на месте. Экраны — крупные, под палец, минимум текста, один акцент на шаг; логика — та же, что на портале,
но оптимизирована под сканер и одну руку.

## Scope
- Список отгрузок «На сборке» для селлера/склада; вход в отгрузку.
- Пошаговая сборка по листу подбора: скан баркода товара → подсветка позиции → отметка «Собрал».
- Внесение идентификаторов (КИЗ/УИН/IMEI/GTIN) сканером (DataMatrix), с передачей GS-разделителей (F8/Alt+0029).
- Печать стикера заказа (58×40) на мобильный/подключённый принтер.
- Отметка «Упаковал», прогресс сборки.

## Out of scope
- Создание/передача отгрузки в доставку (портал `fbs-frontend`). Грузоместа (портал). Веб-экраны.

## Арх-подход
- Переиспользовать существующий каркас ТСД (сканер, печать) из `mobile/`; данные/действия — через API
  бэкенд-под-задач; стикеры — `POST /orders/stickers` (⚠️ сверить). КИЗ — `PUT /orders/{id}/meta/sgtin` (⚠️).
- Настройка сканера на передачу GS-разделителя (по `wb-docs/.../verify-product-identifiers.md`).

## Критерии приёмки (DoD)
- [ ] Сборщик открывает отгрузку и видит лист подбора на ТСД.
- [ ] Скан баркода находит/подсвечивает позицию; отметка «Собрал» сохраняется.
- [ ] Скан КИЗ вносит идентификатор с корректным GS-разделителем; ошибка маркировки видна.
- [ ] Стикер заказа печатается; после сборки+упаковки позиция закрыта.
