## Типология визуальных элементов

### Интерфейс портала WB Partners
- Список сборочных заданий (колонки, фильтры, таймеры)
- Лист подбора (интерактивный, отметки, счётчики, переключатели)
- Окна модальные (выбор маркировки, подтверждение отмены, добавление маркировки)
- Статусы проверки маркировки (цветные коды: зелёный/красный/серый)
- Таблицы параметров (требования, допустимые значения)
- Виджеты боковой панели (стоимость, этапы, пропуски)

### Маркировка и стикеры
- Стикер заказа WB (40×58 мм, QR-код)
- Стикер баркода (печать на склад)
- КИЗ/DataMatrix (размеры по категориям, примеры формата)
- УИН (Data Matrix для ювелирных)
- QR-коды поставок и грузомест
- Примеры печатных стикеров для подбора и данных поставки

### Физические объекты
- Схемы зон на складах (красные ворота, крыльца, тара)
- Требования к машинам и упаковке (таблицы габаритов, весов)
- Пакетные требования (материалы, слои защиты)

### Таблицы категорий и ограничений
- Категории товаров (20+ типов упаковки)
- Размеры маркировки для разных категорий
- Невозвратные товары (102 позиции)
- Автовозврат по регионам (20 регионов)
- Причины обезличивания и требования к доказательствам

### Документы и формы
- Пример бланка ДТ (графа А)
- Шаблоны Excel (маркировка, остатки, ДТ)

### Схемы и диаграммы
- Старая схема возврата (через обычный процесс)
- Новая схема возврата (перезаказ в ПВЗ)

## Рекомендации для UI копирования

**Приоритет высокий:**
- Список заказов (step-1) — основной экран навигации
- Лист подбора (interactive-assembly-task) — ключевой рабочий инструмент сборки
- Статусы маркировки (verify-product-identifiers, kiz-common-errors) — визуальная обратная связь
- Стикеры (stickers-for-marking-orders, items-and-shipment-labeling) — распечатка

**Приоритет средний:**
- Таблицы упаковки (how-to-pack-*) — справочная информация
- Таблицы параметров (step-3a, step-3b) — бизнес-логика
- Окна модальные (step-2) — форма добавления маркировки
- Таблицы ограничений (item-returns-by-customer-request) — справочная информация

**Приоритет низкий:**
- Схемы зон (self-acceptance-at-sc) — фотографии физических мест
- Таблицы регионов (item-auto-return-to-seller) — данные для справочника
- Диаграммы процессов (reordering-refused-at-pvz) — процессные диаграммы
