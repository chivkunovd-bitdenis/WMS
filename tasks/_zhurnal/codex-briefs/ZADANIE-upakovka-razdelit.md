# Задание: разделить файл экрана упаковки

## Зачем

`frontend/src/screens/ff/FfPackagingPage.tsx` разросся до 2146 строк — втрое выше
порога монолита в этом проекте. Из-за размера сторож `scripts/ui/ui_guard.py` не
пропускает ни одну правку этого экрана, а на нём висят две задачи владельца
(столбец количества с правкой и столбец Честного знака). Пока файл не разделён,
экран заморожен.

## Что сделать

**Только механическое разделение. Поведение экрана не менять ни на йоту.**
Ни одной новой кнопки, колонки, подсказки или изменённой формулировки.
Если по ходу увидишь баг — запиши его в итог текстом, но не чини.

Раздели по смысловым кускам в папку `frontend/src/screens/ff/packaging/`:
таблица позиций, диалоги, работа со сканером, обращения к серверу, вычисления
над строками. Точную нарезку выбери сам по тому, как код реально сгруппирован,
но каждый получившийся файл должен быть заметно меньше порога и иметь понятное
имя на латинице в стиле соседних файлов проекта.

Сам `FfPackagingPage.tsx` оставь на прежнем месте и с прежним именем — он
становится тонкой сборкой из новых кусков. Маршрут в `App.tsx` и его импорт
менять нельзя.

Посмотри, как уже разделены соседние экраны — `frontend/src/screens/ff/inventory/`
и `frontend/src/screens/ff/warehouse-map/`. Повтори их манеру: экран отдельно,
дерево/таблица отдельно, диалоги отдельно, чистые вычисления отдельным файлом
без React.
