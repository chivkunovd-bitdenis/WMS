# Грузоместо должно принимать товары ровно так же, как короб

## Что не так

Владелец: «во всех местах, где мы сейчас можем добавить в короба товары, у нас
вроде есть грузоместа — и вот в них так же нужно добавлять товары, в точности по
такому же процессу, как и в короба».

Сервис для этого уже написан: `backend/app/services/inbound_cargo_place_service.py`,
функции `set_line_quantity` и `update_free_text`. Модель строк тоже есть —
`InboundIntakeCargoPlaceLine`.

**Но ручек нет.** Я прогрепал весь `backend/`: единственные три ссылки на этот
сервис — в `backend/tests/test_warehouse_structure_wave1.py`. Ни один роут его не
вызывает, значит из интерфейса товар в грузоместо положить нельзя.

## Что сделать

Открыть для грузоместа те же операции, что есть у короба, **зеркально**, с теми
же именами и той же формой запроса-ответа. Короб живёт в
`backend/app/api/inbound_intake.py`, вот его ручки — по ним и равняйся:

- `POST /{request_id}/boxes/open` (строка ~1212) — открыть короб в работу;
- `POST /{request_id}/boxes/{box_id}/scan` (~1234) — пикнуть товар в короб;
- `PUT  /{request_id}/boxes/{box_id}/lines/{product_id}` (~1259) — задать
  количество товара в коробе;
- `POST /{request_id}/boxes/{box_id}/close` (~1300) — закрыть короб.

Сначала прочитай эти четыре ручки целиком и `inbound_box_svc`, который они
зовут. Реши по факту, какие из них имеют смысл для грузоместа: если у
грузоместа нет понятия «открыт/закрыт» — не выдумывай его, сделай то, что есть,
и напиши в итоге, что пропустил и почему.

Обязательный минимум: **задать количество товара в грузоместе** и **пикнуть
товар сканером**, потому что владелец просил «в точности такой же процесс».

Правила, которые уже соблюдает короб и должно соблюдать грузоместо:
- товар должен быть в строках самой приёмки, иначе отказ;
- нельзя опустить количество ниже уже оприходованного;
- количество ноль убирает строку;
- у пары «грузоместо + товар» строка одна (в модели уже стоит уникальность).

Ответ ручки должен отдавать грузоместо целиком с его строками, как `_box_out`
отдаёт короб со строками — фронту нужно перерисовать карточку после правки.
Сейчас `_cargo_place_out` (строка ~333) строк не отдаёт вовсе: дополни его.

## Тесты

- задали количество товара в грузоместе — строка появилась, в ответе видна;
- изменили количество — обновилось, дубля строки нет;
- ноль — строка ушла;
- товар не из этой приёмки — понятный отказ, не пятисотка;
- попытка опустить ниже оприходованного — отказ;
- чужой арендатор своего грузоместа не видит.
