# Как подключается принятый экран к серверу — образец

Три экрана уже подключены этим способом. Повторяй его, не изобретай свой.

**Смотри готовые примеры в этой же ветке:**
- `frontend/src/screens/ff/inventory/FfInventoryPage.tsx` — самый простой;
- `frontend/src/screens/ff/products-fbs/FfProductsFbsPage.tsx` — с сохранением;
- `frontend/src/screens/ff/sorting-objects/FfSortingObjectsPage.tsx` — с
  оптимистичным обновлением и ключом пересборки.

## Правила

1. **Экран не знает про сеть.** Он принимает данные пропсами и зовёт коллбэки.
   Загрузка и отправка живут в отдельном файле-связке `Ff<Что>Page.tsx`.

2. **Превью обязано продолжать работать.** Пропсы делаются необязательными, а
   без них берутся выдуманные данные из заглушки:
   `const products = productsProp ?? PRODUCTS`. Это не запасной путь: макет
   должен открываться без сервера, иначе смотреть на экран можно только после
   готового бэка, а смотреть надо раньше. **Файл `preview.tsx` не ломать.**

3. **Заголовок авторизации** собирается в связке:
   `function headers(token: string) { return { Authorization: \`Bearer ${token}\` } }`
   Адрес — через `apiUrl` из `../../../api`, разбор ошибки — через
   `readApiErrorMessage` из `../../../utils/readApiErrorMessage`.

4. **Маршрут** добавляется в `frontend/src/App.tsx` рядом с уже добавленными
   (`ff/stocktaking`, `ff/fbs-stock`, `ff/sorting-objects`). Существующие
   маршруты не трогать: они заняты работающими экранами.

5. **Если экран берёт данные начальным состоянием** и дальше двигает их сам —
   не перезаписывай их на каждый ответ сервера, это отменит работу оператора под
   руками. Пересобирай экран по `key`, когда пришёл новый состав. Пример — в
   `FfSortingObjectsPage.tsx`.

6. **Оптимистичное обновление**: экран меняет своё состояние сразу, не дожидаясь
   сервера. Отказ — показать и перечитать данные, иначе на экране будет одно, а
   в системе другое.

## Ворота фронта

```
cd frontend && npx tsc --noEmit -p tsconfig.app.json
python3 scripts/ui/ui_guard.py     # из корня репозитория
```
Своя вёрстка таблиц, кнопок и чипов запрещена — только `frontend/src/ui-kit`.
npm run build и Playwright НЕ ЗАПУСКАТЬ, это долго и не нужно.
