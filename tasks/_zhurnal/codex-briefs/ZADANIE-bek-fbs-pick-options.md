# Подбору ФБС нужен список мест по товару — как в отгрузке

## Зачем

Согласованный владельцем экран подбора идёт **от товара**: строка показывает
план, снято, осталось и «где лежит — в N местах», а оператор снимает нужное
количество с конкретных ячеек. Этот экран уже работает в документе отгрузки.

Владелец требует тот же экран и в подборе ФБС. Встроить его нечем: сервер не
отдаёт места по товарам поставки.

## Что есть сейчас

В отгрузке источник — `GET /operations/marketplace-unload-requests/{request_id}/pick-options`
(`backend/app/api/marketplace_unload_requests.py`, около строки 1176), сервис
`get_pick_options` в `backend/app/services/marketplace_unload_pick_service.py`
(строка 175). Он отдаёт по каждому товару документа список мест: ячейка, её код,
сколько лежит, сколько зарезервировано, сколько доступно и сколько уже подобрано.

В ФБС есть подбор с ячеек, но **обратного порядка**: `POST /{supply_id}/pick/scan-location`,
`/pick/manual/location`, `/pick/scan-product`, `/pick/manual`, `/pick/{order_id}/undo`
(`backend/app/api/fbs_supplies.py`, строки 1116–1202) — сначала ячейка, потом товар.
А `GET /{supply_id}/picking-list` (строка 1510) отдаёт только артикул, SKU,
размер, название и количество — **ни одной ячейки**.

## Что сделать

Добавить для поставки ФБС выдачу мест по товарам — зеркало `get_pick_options`.

Форму ответа возьми **ровно такую же**, как у отгрузки: тот же состав полей и те
же имена, чтобы один и тот же экран читал оба источника без переходников.
Сначала прочитай `get_pick_options` целиком и повтори её смысл:

- перечень товаров поставки с плановым количеством;
- по каждому товару список мест на складе поставки: идентификатор ячейки, её
  код, сколько лежит, сколько зарезервировано, сколько доступно, сколько уже
  подобрано по этому товару в этом месте;
- места, где остаток стал нулевым, но подбор по ним уже был, **не терять** —
  иначе оператор не сможет вернуть снятое обратно (в отгрузке это отдельно
  решено, посмотри как).

Учти, что в ФБС единица подбора — заказ, а не строка документа: разберись, как
`FbsOrderPick` хранит уже подобранное, и считай «сколько подобрано» из него.

Адрес выбери в стиле соседних ручек поставки. Права — как у остальных ручек
подбора ФБС.

## Тесты

- поставка с товарами на двух ячейках отдаёт оба места с верными числами;
- уже подобранное по месту видно в ответе;
- место с нулевым остатком, но с подбором, из ответа не исчезает;
- чужой арендатор поставки не видит;
- пустая поставка отдаёт пустой список, а не ошибку.
