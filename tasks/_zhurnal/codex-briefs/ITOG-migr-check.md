# Итог: миграция 0130 не запрещает законный минус FBS

В миграции `20260828_0130_warehouse_structure_wave1.py` удалены три операции
создания ограничений, запрещавших отрицательные значения `quantity`,
`quantity_unpacked` и `quantity_packed` в `inventory_balances`. Из
`downgrade()` удалены соответствующие операции снятия этих ограничений.

Рядом с оставшимися ограничениями структуры контейнера добавлен комментарий:
минус в остатке является законным следом подтверждённой доставки FBS, а на
боевой базе уже есть 115 таких строк. Поэтому обновление базы больше не должно
останавливаться на существующих отрицательных остатках при прохождении ревизии
`20260828_0130`.

Миграция `20260828_0210_inventory_balance_allow_negative.py` проверена отдельно.
Изменять её не потребовалось: в `upgrade()` все три ограничения снимаются через
`ALTER TABLE inventory_balances DROP CONSTRAINT IF EXISTS`, поэтому их отсутствие
после исправленной `0130` безопасно.

Проверки на текущем worktree:

- `ruff check .` — прошёл;
- `mypy .` — прошёл, проверено 390 исходных файлов;
- `python3 -m pytest tests/test_warehouse_structure_wave1.py -q` — прошёл:
  14 тестов, включая запрет обычного списания ниже нуля и разрешённый минус при
  подтверждённой доставке FBS;
- `python3 -m pytest tests/test_inventory_service_reporting_dimensions.py -q`
  — прошёл: 1 тест;
- `python3 -m alembic heads` — вернул ровно одну голову:
  `20260829_0241 (head)`;
- `git diff --check` — прошёл.

Буквально указанную команду выполнить нельзя по двум проверенным причинам:
команды `python` в окружении нет, а файла `tests/test_inventory_service.py` нет
ни в рабочем дереве, ни в доступной истории этого пути. Поэтому те же проверки
запущены через `python3`; основной адресный файл
`test_warehouse_structure_wave1.py` выполнен полностью, а дополнительно запущен
существующий тестовый файл сервиса остатков
`test_inventory_service_reporting_dimensions.py`.

Полный `pytest` и проверки фронтенда не запускались по прямому ограничению
владельца.

Изменения сохранены в локальной ветке `codex/fix-migr-check-20260829` отдельным
коммитом. Публикация ветки в `origin` не состоялась: окружение вернуло
`Could not resolve host: github.com`, поэтому результат пока не доступен в
удалённом репозитории.
