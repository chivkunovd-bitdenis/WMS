СДЕЛАТЬ:

1. `GET /warehouses/{warehouse_id}/map` — вернуть `WarehouseMapData`:
   - `cells`: ячейки склада с деревом содержимого, суммы `qty` считаются снизу вверх;
   - `unassigned`: всё, что не разложено по ячейкам (виртуальная зона «Без ячеек»);
   - `sellers`, `categories`: списки для фильтров, собираются на сервере, а не на экране;
   - `journal`: последние перемещения по этому складу (см. `MovementEntry`).
   Суммы обязаны сходиться с `InventoryBalance` — это закрывается тестом.

2. `POST /warehouses/{warehouse_id}/map/move` — переместить объект:
   тело `{kind, id, to_kind, to_id, qty}`. Перемещать можно товар, короб, палету,
   грузоместо. Запреты: палету внутрь себя, отрицательный и нулевой остаток,
   чужого арендатора. Пишет движение через существующую
   `inventory_service.record_movement_and_adjust_balance` — своей арифметики остатка НЕ писать.

3. `POST /warehouses/{warehouse_id}/map/disband` — расформировать палету:
   содержимое уезжает в служебную зону сортировки (`get_or_create_sorting_location`),
   палета помечается расформированной. Сервис для этого уже есть в волне 1.

   `GET /warehouses/{warehouse_id}/sorting-objects` — что лежит в сортировке и ждёт раскладки.
   `POST /warehouses/{warehouse_id}/sorting-objects/place` — поставить объект на ячейку.
