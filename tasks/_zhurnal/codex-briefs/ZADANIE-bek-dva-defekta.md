# Два дефекта, найденных живой проверкой на стенде

## Дефект 1. Служебный код `__SORTING__` виден оператору

Открой `backend/app/api/inventory_counts.py`, место сборки ячеек документа —
около строки 292: `nodes_by_cell[(str(location.id), location.code)]`.

В `location.code` для зоны сортировки лежит техническая строка
`__SORTING__` (константа `SORTING_LOCATION_CODE` из
`app.services.sorting_location_service`). Она уходит в ответ как название ячейки
и **показывается оператору в документе пересчёта**. Я это видел на живом стенде:
в таблице пересчёта короба первой строкой стоит `__SORTING__`.

Карта склада ту же самую зону называет **«Без ячеек»** — посмотри
`UNASSIGNED_LABEL` и как её отдаёт ручка `GET /warehouses/{id}/map`.

**Что сделать:** в ответе документа пересчёта показывать «Без ячеек» вместо
технического кода. Менять сам код ячейки в базе НЕЛЬЗЯ — по нему работает поиск
зоны сортировки. Правится только то, что уходит наружу как подпись.

Тест: документ по объекту, лежащему в зоне сортировки, отдаёт человеческую
подпись, а не `__SORTING__`.

## Дефект 2. Правило остатка FBS отдаётся только по одному товару

Есть `GET /products/{product_id}/fbs-rule` (строка 1411) и пакетный
`PUT /products/fbs-rule` (строка 1461). **Пакетного чтения нет.**

Из-за этого экран «Остатки FBS» вынужден делать запрос на каждый товар: на
боевых данных это 200 запросов на одно открытие экрана. Я замерил в браузере —
ровно 200 уникальных обращений подряд.

**Что сделать:** добавить пакетное чтение правил. Форму выбери по тому, как в
проекте уже сделаны похожие пакетные ручки (посмотри `PUT /products/fbs-rule` и
`/products/fbs-stock-limit/from-balance/bulk`) — важно, чтобы одним запросом
можно было получить правила для списка товаров.

Ограничь размер пачки разумным числом и отдавай понятную ошибку при превышении.
Товары чужого арендатора и чужого продавца отдавать нельзя — проверь, как это
сделано в существующей ручке на один товар, и повтори.

Тест: пачка из нескольких товаров возвращает их правила; товар другого
арендатора не возвращается; превышение размера пачки даёт понятный отказ.

**Старую ручку на один товар не удаляй** — фронт переведут на пакетную отдельно.
