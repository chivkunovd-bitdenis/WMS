## Что уже решено — не переоткрывать

- Место товара **не хранится, а вычисляется** по цепочке держателей: товар в
  коробе, короб на палете, палета в ячейке. Одна правда на карту и раскладку.
- Товар внутри **короба и грузоместа** сначала вынимают. С палеты — напрямую.
- Снятие с ячейки — **целиком**, и снимается любой объект, не только товар.
- Нумерация коробов, палет и грузомест **наша и сквозная**: номер выдаётся один
  раз при создании и не меняется никогда. Стикер для WB — отдельная история,
  туда идёт идентификатор от WB.
- По FBS идентификатор грузоместа выдаёт WB (`POST .../trbx`). По FBO публичного
  метода нет — код из кабинета или XLSX-шаблона.
- Остаток для FBS — **доля свободного остатка**, не абсолютное число. Склады
  продавца делят один и тот же остаток, сумма долей не больше ста процентов.
- Какие заказы наши — **по складу**, а не по остатку. Галочка «заказы FBS» в
  карточке продавца. Чужие отсеиваются при импорте.
- Среднее время сборки: переключатель периода с календарём, по умолчанию неделя,
  при выбранном продавце — только по нему.
- Заказы чужих фулфилментов не показываем нигде.
