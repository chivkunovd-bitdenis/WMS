## Фичи

### 1. Read-only API коробов и грузомест для каталога

Оператор с тем же правом, что открывает каталог, получает два безопасных запроса: ленивый список актуальных коробов и грузомест и точный поиск по `INB-*`/`ICG-*`. Сервис считает только текущий остаток короба `max(quantity - posted_qty, 0)`, не придумывает состав грузоместа, не показывает чужой тенант и не меняет ни одного поля приёмки. Обычный список оставляет только короба с остатком, пустые короба незавершённой приёмки и грузоместа незавершённой приёмки; адресный поиск также находит завершённые объекты для спокойного состояния на экране.

### 2. Раскрываемый блок «Короба и грузоместа» на экране каталога

Оператор видит под текущей таблицей свёрнутый раздел без нового маршрута. Первое ручное раскрытие загружает список и показывает скелет, пустоту, ошибку с «Повторить» либо объекты; у короба открывается таблица актуального состава, у пустого короба и грузоместа — предусмотренное спокойное состояние. В существующем поле поиска Enter на точном `INB-*`/`ICG-*` запускает адресный запрос, раскрывает ровно найденный объект, прокручивает к нему и сохраняет готовность поля к следующему скану; товарный поиск остаётся прежним.

Тест также закрепляет безопасные ошибки скана, грузоместо без состава и доступ сотрудника. Постоянный каталог сценариев получает TC-ID, на которые ссылается e2e-тест.
