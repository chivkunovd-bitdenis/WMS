# Устаревший проход карточки 06

Эти артефакты сохранены для аудита и восстановления, но больше не являются
входом активного процесса. Они были построены на расширенном толковании задачи:
добавляли нумерацию, новую служебную этикетку, новый режим печати и изменения
существующих FBS-компонентов.

Актуальная граница владельца находится в `../OWNER-SCOPE.md`. Новый проход обязан
сохранить существующий интерфейс и изменить только общий стабильный порядок
существующего листа подбора и полной ленты.
