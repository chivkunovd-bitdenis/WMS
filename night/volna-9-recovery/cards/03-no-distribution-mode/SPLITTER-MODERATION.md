# Модерация allowlist 03

Splitter корректно сузил реализацию до четырёх последовательных атомов, но ошибочно
предложил удалить строку шапки `Без распределения · коробов N`. Эта строка уже была
в исходном экране до карточки 03, поэтому её удаление само стало бы лишней FBS-правкой.

Точечная коррекция allowlist:

- существующая строка шапки остаётся без изменений;
- удаляется только незапрошенный новым кандидатом тултип;
- `backend/app/api/fbs_errors.py` разрешён атому API только для удаления
  незапрошенного нового текста ошибки из текущего кандидата;
- другие экраны, UI-kit, QR, печать, лист подбора и лента по-прежнему запрещены.

Продуктовый контракт, кейсы и порядок стадий не менялись.
