## Назначенные кейсы

- `S-05-TC-001` — фактический вердикт Wildberries для привязанного кода.
- `S-05-TC-002` — локальный код отсутствует в ответе Wildberries.
- `S-14-TC-001` — упаковка не показывает ложную готовность при отсутствии кода у WB.
- `S-14-TC-002` — подтверждённая Wildberries маркировка проходит проверку готовности.

## Репро

**Статус:** воспроизведение в живом интерфейсе не выполнялось: роль tester описывает
контракт до разработки, а не проверяет уже написанный код.

**Как повторить дефект по входному описанию:** для FBS-заказа привязать локальный код
маркировки, удалить этот код на стороне Wildberries и открыть проверку маркировки или
готовности задания упаковки.

**Что видно сейчас по описанию дефекта:** из-за неактуального метода либо отсутствующей
детали WB локальный статус остаётся исходным, а оператор может увидеть зелёное «всё в
порядке» без фактического подтверждения Wildberries.

**Что должно быть:** оператор видит фактический вердикт Wildberries либо явное отсутствие
ответа для конкретного локального кода; отсутствие ответа не выглядит как успешная проверка.
