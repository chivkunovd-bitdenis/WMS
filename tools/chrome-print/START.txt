Это текстовые команды запуска уже установленного Google Chrome. Они ничего не устанавливают и не скачивают, не запускают помощников, не меняют службы или настройки безопасности.

Windows: сохраните WMS-Chrome-Print-Windows.cmd и откройте его двойным щелчком.
macOS: сохраните WMS-Chrome-Print-macOS.command. В Terminal выполните: sh "$HOME/Downloads/WMS-Chrome-Print-macOS.command"

Команда открывает отдельное окно Chrome с --kiosk-printing и отдельным постоянным профилем. Личный Chrome закрывать не нужно. Для рабочей печати открывайте страницу через эту команду: обычный запуск Chrome не включает этот режим.

Термопринтер должен быть установлен и выбран принтером по умолчанию в ОС. В его настройках заранее выберите размер бумаги, совпадающий с размером на странице. В режиме --kiosk-printing Chrome отправляет печать без окна подтверждения. Команды не меняют принтер и размер бумаги за вас.
