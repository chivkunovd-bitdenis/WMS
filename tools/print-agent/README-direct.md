# WMS Print — прямая печать из Chrome

Распакуйте архив. На Mac запустите `WMS Print.app`, на Windows — `WMS Print.exe`
внутри папки. Python и просмотрщик PDF устанавливать не нужно. Программа
работает в фоне, пока запущен её процесс, и не открывает вкладки браузера.
Сканируйте в существующем экране WMS: QR передаётся системному принтеру по умолчанию.

Адрес сервера, код подключения, склад и выбор очереди не требуются.
Размер листа берётся из системного драйвера, QR вписывается с сохранением пропорций.
Формат носителя в драйвере должен соответствовать бумаге, которая реально стоит
в принтере: приложение не может определить физическую ширину неизвестного рулона.

Локальная проверка не меняет рабочий сайт. Для настоящей упаковки сайт должен
содержать `printDirectQr`; неопубликованная ветка сама сайт не обновляет.
При обращении HTTPS-сайта к программе Chrome может один раз запросить доступ
к локальному компьютеру. Приложение не меняет защиту браузера и ОС.
Неподписанное приложение может потребовать системное подтверждение первого запуска.

Отсутствие окна печати обеспечивается прямой передачей в очередь ОС, а не
настройкой kiosk-printing. Квитанция очереди не подтверждает физический выход бумаги.
Повтор с тем же идентификатором возвращает прежнюю квитанцию. После неизвестного
исхода автоматической повторной отправки нет.

Исходный SHA содержится в `build.json` внутри пакета. Windows x64, Mac arm64 и
Mac Intel собираются отдельно в `.github/workflows/print-direct-package.yml`.
