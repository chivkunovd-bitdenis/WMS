# Массовая упаковка WB FBS с непрерывной печатью

Эта инструкция помогает настроить непрерывную печать этикеток и упаковывать заказы WB FBS по одному скану товара.

## 1. Подготовьте WMS Print

- ☐ На macOS запустите **WMS Print.app**, на Windows — **WMS Print.exe**. Оставьте программу запущенной во время работы.
- ☐ Проверьте системный принтер по умолчанию: WMS Print отправляет задания именно на него.
- ☐ В драйвере принтера выберите размер бумаги, который фактически установлен в принтере.
- ☐ Если Chrome впервые запрашивает доступ к локальному компьютеру, разрешите его.

## 2. Откройте упаковку

1. Откройте раздел **FBS** и нужную поставку **WB**.
2. Если видна кнопка **«Начать работу с поставкой»**, нажмите её.
3. Откройте вкладку **«Упаковка и маркировка»**.

## 3. Выберите настройки печати

- **«Печатать QR»** — печатает индивидуальный QR выбранного заказа WB. Если сохранённой настройки ещё нет, режим включён по умолчанию. Выбор сохраняется отдельно для каждого пользователя и арендатора.
- **«Печатать ЧЗ»** — включите для маркируемого товара. После скана товарного штрихкода WMS берёт свободный КИЗ из пула селлера, привязывает его к заказу и печатает этикетку. Вручную сканировать КИЗ не нужно.
- **«Перепечатывать ЧЗ»** — альтернативный режим. После скана товарного штрихкода отсканируйте КИЗ с товара: WMS напечатает его точную копию.
- **«Печатать ЧЗ»** и **«Перепечатывать ЧЗ»** нельзя включить одновременно.
- Счётчик **«− N +»** рядом с активным режимом задаёт число этикеток. Значения для обычной печати ЧЗ и перепечатки сохраняются отдельно. Доступно от 1 до 10 экземпляров, по умолчанию — 1.
- Если одновременно включены QR и один из режимов ЧЗ, сначала печатается один QR, затем выбранное количество этикеток ЧЗ.

## 4. Сканируйте товар

Один скан товарного штрихкода обрабатывает одну единицу и один заказ. После успешной печати WMS автоматически упаковывает этот заказ.

## 5. Если печать прервалась

При ошибке WMS Print упаковка не завершается. Устраните проблему и повторите тот же товарный штрихкод. WMS продолжит тот же заказ и допечатает только недостающие задания; уже принятые задания повторно не создаются.

## 6. Отмена действий

- **Escape** отменяет незавершённый выбор, после чего можно начать сканирование заново.
- **«Назад»** отменяет последний сохранённый скан в WMS. Физически уже напечатанную этикетку вернуть или отменить нельзя.
