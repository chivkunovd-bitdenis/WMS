# WMS-396 — ручная проверка приёмки, 08.09.2026

Проверено через CUA (реальные нажатия и чтение экрана) в локальном интерфейсе
`http://127.0.0.1:15396`, API `http://127.0.0.1:18396`.
Это синтетический склад SQLite, не боевой склад и не доказательство деплоя.
Внешние соединения запрещены тестовым запуском; ответы ЧЗ подменены:
`GOOD` → `INTRODUCED`, остальные → `APPLIED`, `UNAVAILABLE` → ошибка соединения.
Это проверяет операторский путь и отображение ответа, но не доступность внешнего ЧЗ.

товара — 1. Скан товара увеличил его до 2. Следующий КИЗ появился вложенной
строкой со статусом «Ожидает проверки», количество осталось 2. Повтор того же
КИЗ сохранил одну строку кода и количество 2. Ещё один скан товара увеличил
количество до 3; ещё два КИЗ количества не изменили.

Неизвестный товар дал сообщение о поиске товара. Следующий КИЗ был отклонён
с сообщением «Сначала отсканируйте товар, затем его код Честного знака»:
предыдущий товар не использовался автоматически.

Второй товар добавлен штатным выбором товаров с количеством 1. Его скан
увеличил только его количество до 2. Попытка отсканировать код первого товара
дала русское сообщение о другом товаре. Новый код `GOODSECOND123` прикрепился
ко второму товару, количество осталось 2. При фокусе в ручном поле количества
повтор полного КИЗ с GS сохранил значение поля `2` и не добавил строку.

**Оговорка о первом вводе:** CUA-комбинация `CTRL+]` не передала GS; первый
`GOOD123456789` сохранился без разделителей. Этот ввод не является доказательством
сохранения GS. Следующие коды, в том числе `GOODSECOND123`, набраны через
`Control+]`: экран показывает разделители `␝`, SQLite хранит настоящие ASCII 29.
Например, проверенная строка БД:
`010460123456789021GOODSECOND123\x1d91KEY1\x1d92SIGNATURE`.
