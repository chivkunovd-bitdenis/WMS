# WMS-506 — печать КИЗ без установки программы

Дата: 22.09.2026. Анализ документации браузеров и кода WMS на production-базе `3e125074d5cb4c38e9107f864c3075f4f1f224cd`. Это не физическая приёмка и не изменение настроек рабочих компьютеров.

## Вывод

Отдельная программа печати не обязательна. Chrome и Edge с версии 144 имеют штатную политику `SilentPrintingEnabled` на Windows и macOS. Её включают один раз на компьютере; страница WMS продолжает вызывать обычную печать. Браузер автоматически закрывает предпросмотр и отправляет документ на принтер по умолчанию с настройками по умолчанию. Обещать полное отсутствие даже краткого появления окна без проверки конкретной версии нельзя: документация описывает его автоматическое закрытие.

Установка WMS Print, QZ Tray или расширения не требуется. Сам принтер должен быть уже доступен операционной системе с рабочим драйвером. Без настройки браузера обычная веб-страница не может приказать ему пропустить диалог. Галочка внутри WMS управляет событием автоматической перепечатки, а разрешение бесшумной печати задаётся на рабочем компьютере.

## Существующая реализация и повторное использование

`frontend/src/components/KizReprintDialog.tsx` после сохранения скана вызывает `startAutoKizReprintPrint`, затем `printMarkingCodeLabels(codes, { duplicateCopies: 1 })`. В `frontend/src/utils/printMarkingCodeLabel.ts` печатная разметка передаётся скрытому iframe и вызывается `frameWindow.print()`. Перепечатка уже использует браузерный механизм, совместимый с указанной настройкой.

Для FBS требуется новая точка вызова этого же формирования этикетки после подтверждённой штатной привязки отсканированного КИЗ. Не следует запускать печать от каждого обновления списка заказов или от фонового изменения вердикта WB. Печатается полное значение привязанного КИЗ с сохранением разделителей; новая маркировка не выделяется. Подробные требования и разбор пути привязки — в `docs/requirements/WMS-506.md`.

На момент анализа WMS-506 не реализована: вызов из успешного скана упаковки и галочка ещё не добавлены. Наличие готового генератора этикетки не является готовностью новой функции.

## Что можно и нельзя подтвердить из веб-страницы

Программно можно обеспечить один вызов печати на успешно обработанное действие, не печатать из-за повторного HTTP-ответа/перерисовки и подготовить одну страницу/копию. Можно отдельно сообщить ошибку формирования этикетки или явное исключение вызова печати, сохранив уже выполненную привязку КИЗ.

Обычный браузерный API не возвращает идентификатор задания системной очереди, статус бумаги, состояние конкретного принтера или достоверное подтверждение физического выхода этикетки. Даже `afterprint` возникает при закрытии предпросмотра, поэтому не доказывает печать. Нельзя выдавать его за подтверждение или обещать автоматическое обнаружение выключенного принтера. Потеря подтверждения не должна порождать слепую автоматическую перепечатку.

Состояние принтера и задания оператор при необходимости смотрит в штатной очереди Windows/macOS. Практическая надёжность подтверждается прогоном на настоящем оборудовании, а не успешным завершением JavaScript-функции.

## Однократная настройка рабочего места и проверка

1. Определить используемые ОС, браузер/версию, принтер и размер этикетки. Убедиться, что штатная печать на него уже работает.
2. Включить штатную политику тихой печати в выбранном Chrome/Edge. Проверить её фактическое применение на странице политик браузера. Настройки автоматически в рамках этого анализа не менялись.
3. Проверить выбранный по умолчанию принтер и его параметры: формат этикетки, масштаб, поля и одна копия. Если назначением является Save as PDF, политика сохранит файл вместо вывода бумаги.
4. Учесть область настройки: это настройка браузера, а не одного WMS-чекбокса. Она повлияет и на другие вызовы печати в этом браузере; нельзя обещать сохранение диалога для накладных без отдельной проверки/решения рабочего места.
5. На новой функции проверить серию разных заказов, точность полного содержимого DataMatrix повторным сканированием напечатанной этикетки, отсутствие лишних страниц, сохранность фокуса и следующего скана.
6. Проверить отключённую галочку, отказ привязки, повтор ответа, медленное формирование, переключение поставки, отключённый принтер и возобновление системной очереди. Не считать возврат print() подтверждением бумаги.

Физические Windows/Mac-прогоны, реальная скорость, сохранение настроек после перезапуска и конкретный принтер пока не проверены. Политики и программные агенты на компьютерах пользователя не устанавливались и не изменялись. Production в этом анализе не менялся.
