# Аварийный фикс S-03 · 20.08.2026

## Причина

Вкладка «Новые» запрашивала и одновременно отрисовывала 500 заказов. На рабочем
ноутбуке даже выбор одной-двух строк приводил к тяжёлой повторной отрисовке всей
MUI-таблицы, а компонент фото параллельно проверял ссылки скрытых изображений.

## Ограниченная правка

- Вкладка `status_group=new` снова загружает и показывает полный набор из 500 заказов.
- Строка нового заказа вынесена в `React.memo`: выбор одного заказа перерисовывает
  эту строку, а не остальные 499 тяжёлых строк таблицы.
- Фото получают настоящий `src` только рядом с видимой областью. Экран больше не
  запускает одновременно сотни скрытых проверок изображений.
- Состав выбора и сценарии поставки не изменялись: оператор может отметить любые
  два, десять или больше заказов обычными галками.

## Проверки до деплоя

- `npm run build` — успешно.
- Целевой Playwright: API отдаёт и таблица содержит 500 заказов; оператор выбирает
  первую и пятисотую строки, панель показывает `Выбрано заказов: 2` — 1 passed.
- Полный `ff-fbs-orders.spec.ts` — 7 passed.
- `git diff --check` — успешно.
