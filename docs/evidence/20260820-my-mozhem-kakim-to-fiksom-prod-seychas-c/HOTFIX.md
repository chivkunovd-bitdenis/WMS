# Аварийный фикс S-03 · 20.08.2026

## Причина

Вкладка «Новые» запрашивала и одновременно отрисовывала 500 заказов. На рабочем
ноутбуке массовый выбор приводил к тяжёлой повторной отрисовке всей MUI-таблицы.

## Ограниченная правка

- Только для `status_group=new` клиентский лимит уменьшен с 500 до 100.
- Поставки и остальные вкладки сохраняют прежний лимит 500.
- После создания или пополнения поставки выбранная сотня уходит из «Новых», и
  следующий запрос показывает следующую сотню.
