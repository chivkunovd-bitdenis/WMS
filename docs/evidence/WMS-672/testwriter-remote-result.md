## Доказательства и пределы

Artifact первого run: `11401650562`, 21485169 bytes. Второго:
`11401895860`, 18968276 bytes; retention14дней. GitHub REST не применил Range на
redirect: архивы были получены временно в памяти, ZIP/PDF на диск не
сохранялись. Сырые выбранные JSON первого запуска временно содержали HTML;
после извлечения сводок они удалены, полный HTML в Git не сохранён. На диск и в Git оставлены выбранные журналы, pins/hashes, timing,
сводки JSON с ID/состоянием/длиной/hash HTML и шесть PNG. Raw snapshot hashes/размеры
в selected-files относятся к оригинальным записям artifact, не к сводным JSON.
Побайтная идентичность продукта подтверждена runner diff и совпадающими manifests;
SHA256 обоих manifests `26a096a52bfe5a92e68a9844cf1679d5193d0690036e010dcf8262ccb4f5f5b6`.
Финальный browser blob `3f29649e56f986e8e549da592937474197197418`,
DOM blob `d29e1134cf728bb114c3c35a868df2fba2b7ce8e`.

Предыдущие C7/C8 PASS не повторялись и **не доказывают завершение всех300 отметок
после потери ответа/перезагрузки**. Они доказывают только выполненные тогда assertions
сохранения исходной попытки/источника и отсутствия второй передачи. Текущий C6
доказывает двойное подтверждение и однократный успешный состав отметок; отдельный
повтор HTTP mark запроса/серверная идемпотентность в этом браузерном probe не проверены.
C9/C11/C12 этим результатом не закрыты. Бумага/реальный принтер не проверялись.

Локально выполнены только syntax/diff/blob проверки. Навыки, другие агенты,
Mac Chrome/локальный Playwright, локальный build/npm ci, новая БД, секреты, live
API/операции, полный CI, ревью, merge/main/etalon и деплой этой сессией не выполнялись.

затем заключение аналитика. Самоприёмки нет.
