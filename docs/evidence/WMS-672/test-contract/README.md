Первый API-запуск: невозможность создать временный файл; следующий запуск дошёл до проверки доступа, но SQLite cleanup/setup завершились ошибками при нехватке места. В подходящей CI-среде дополнительно обязательны исходные C1–C4/C6–C8/C10: реальные 200/300 для приёмки и возврата, один общий документ, PDF N страниц 58×40 без пустых страниц, декодирование реального CODE128 первой/средней/последней этикетки, отзывчивость и замер подготовки, быстрое двойное подтверждение, reload с сохранением попытки, соседние действия и неизменные WMS-659.
