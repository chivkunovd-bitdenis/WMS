Парсер сохраняет идентичность страницы, PDF-блока и строки текста, вместо
уплощения всех слов документа в одну последовательность. Склейка требует
одного блока на одной странице, соседних строк текста, одинаковой левой
координаты и последовательного переноса. Дополнительно вертикальный шаг
ограничен 1.5 высоты извлечённых глифов; это ограничение парсера для обычного
переноса, а не новая продуктовая ширина или изменение печатного шрифта.
Реальные шаблоны с сохранённым переносом прошли проверку.

PDF-блок здесь означает блок текста из Poppler, а не DOM-элемент `td`.
Проверки его идентичности и координат закрывают предъявленный reviewer
контрпример; отрицательные сценарии отдельно проверяют реальные строки и
колонки исходной HTML-таблицы. Порядок заголовков, границы имени до Артикула,
границы страницы, числовые ширины и старые TCIDs не изменены. Очистка
принадлежащего тесту Chrome с ожиданием exit сохранена.
