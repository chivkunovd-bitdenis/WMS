# WMS-679: обезличенный официальный шаблон FBW

Файл `wb-fbw-shk-excel-template-anonymized.xlsx` — тестовая фикстура,
полученная только из настоящего шаблона WB Partners. Оригинал был скачан
06.10.2026 через уже авторизованный браузер по действию «Упаковка и печать
ШК → Через Excel → Скачать шаблон со штрихкодами». Это было только чтение:
загрузки файла обратно в WB, создания коробов, изменения поставки, печати,
извлечения cookie и доступа к секретам не было.

Оригинал не добавлен в Git, потому что его две строки содержат реальные коды
коробов/печати. Он сохранён без изменений в локальном доказательстве. Его
SHA-256: `db2465473b70c2e1d6bf26d1b81cee1b8bf0b245808ea2b82a78aa7a7e2c00a5`;
размер — 6182 байта. Рядом с оригиналом сохранены `source.json` и снимок
экрана; они также не публикуются, чтобы не раскрывать идентификаторы внешней
поставки. Их SHA-256 соответственно
`c0151c3b66af0297b6efc6d5c54239de99567bab566d7709a01989cb996f559b` и
`d4b27a02edb6cc2d3f58aaedd4b08a5b029a112f721d2503f431253d2131d2a5`.

Трансформация выполнена только внутри `xl/sharedStrings.xml`. В оригинале
индекс 6 используется ячейками C2/E2, а индекс 7 — C3/E3. Их две разные
строки длиной 13 заменены соответственно на `ANON-BOX-0001` и
`ANON-BOX-0002`; одинаковость C и E в каждой строке сохранена. Все остальные
элементы XLSX-пакета побайтно совпадают с оригиналом, включая пустую строку
A2/A3, числовые нули B2/B3, пустые D2/D3, заголовки, лист, типы ячеек и
форматы. SHA-256 обезличенной фикстуры:
`3dc986bd74ca7397cd7ab6ebb02793cd4b3e017a317d517b5cbd13915a1640c7`.

Совпадение C и E — наблюдение только этих двух строк нулевого количества. Оно
не доказывает, что «ШК короба» всегда равен значению для печати в стороннем
сервисе, и не подтверждает принятие WB кодов WHB/INB.
