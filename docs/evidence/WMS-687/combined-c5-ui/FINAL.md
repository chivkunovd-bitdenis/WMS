# WMS-687: окончательная аналитическая приёмка C5

**C5 подтверждена; WMS-687 принята назначенным аналитиком.** Проверка исходников интеграции `230cad6f370825480a86cbdbd8e16287977b8560` продолжает выполненную браузерную проверку на `05da854733eb35584c096b9995b52ae8aafe6877` (доказательства `9f39e1fa6fba13190be3e2d1da876a25167b9cdf`). В приёмке и возврате длинные строки, общий диалог остатка с сохранённым лимитом 7, кнопки PDF/Excel и стикера с номером, датой и селлером совместимы. Это вердикт по WMS-687; приёмка других тикетов, CI и production им не подтверждаются.

Прежний аналитик цепочки заменён по прямому назначению ведущего, поскольку ephemeral-сессия `01a112bf-b759…` недоступна. Принимающий аналитик выполнил первоначальную браузерную проверку и сейчас закрывает её прежнее ожидание C5. Сверены актуальные правила origin/etalon, исходные требования и уточнения, код и сохранённые доказательства. R, ожидаемое поведение, классы проверок и точные ссылки Test из 6040daef не переписаны.

Открытый ранее дефект PDF WMS-586 закрыт отдельным продуктом `b6e14f56692cf0561955e48af0a30e1415ccea36` и независимым PASS `1fbbcf5e750de1bc7ffec13973a4eccb590881c8`. Прочитаны `docs/reviews/2026-10-07-wms684-586-geometry-followup/README.md` и source-evidence: 64/128 строк имеют 3/4 непустые страницы и зазор около 5,007 pt; название из 255 символов с 253 переносами сохраняет Х/Я без пустых страниц. Две зафиксированные регрессии и две API-проверки прошли. Этот продукт меняет только серверный сервис и передачу результатов, фронт не менялся. Это независимое техническое основание, а не новое серверное ревью принимающего аналитика.

**Весь FfInboundRequestView побайтно не равен прежнему браузерному снимку.** Сохранённый diff показывает только согласованные поля `size`/`color` WMS-680 в InboundLine и их передачу в прежнюю печатную накладную. Эти изменения сохранены. Программно подтверждено равенство трёх участков: downloadAcceptanceAct, headerPDF/Excel/stockcontrols, stickerMetadataAndRecovery. Четыре полных файла общего диалога, контейнера, печатного помощника и сохранения приёмки также прежние. Точные SHA-256 и границы содержатся в `final-source-comparison.json`. Новые поля WMS-680 не меняют контекст, кнопки, компоновку и обработчики C5; повтор браузерной проверки без нового основания не выполнялся и не заявляется.

Реальная React-сцена, шесть снимков экрана и два DOM сохранены здесь. README сохраняет историю промежуточных ограничений и ошибки bare QA-token: исправлялась только синтетическая сцена, продукт не менялся. PDF/XLSX созданы на двух синтетических строках; запросы API и отметки печати подменены, производственные данные не менялись. Фактическое скачивание и физическая бумага не подтверждены и не требуются для проверки совместимости C5. Внешние передачи WB/Ozon не заявляются.

Проверки C1–C8 WMS-687 подтверждены прежними проверками выполнения, независимым ревью и завершённой совместной C5. Полный CI, сохранение постоянной защиты (исправление проверки развёрнутых имён тестов ведётся отдельно), merge, деплой, фактически обслуживаемая версия и остальные тикеты остаются ведущему.
