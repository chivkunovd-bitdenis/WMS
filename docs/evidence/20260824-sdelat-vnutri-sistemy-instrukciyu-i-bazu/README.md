# Доказательства · база знаний «Создание приёмки»

Проверено 25.08.2026 в настоящем браузере.

## Откуда взяты рабочие экраны

Все четыре изображения внутри статьи сняты на актуальном Railway-стенде
`https://web-production-9e7c1.up.railway.app`:

- портал селлера: `/seller/documents`;
- заполненный черновик поставки: `/seller/inbound/b0954f52-d235-441b-9f86-ccc42e83c97a`;
- очередь ФФ: `/app/ff/reception`;
- активная карточка приёмки №000025 в очереди ФФ.

Локальные демонстрационные изображения, использованные в первом черновике, удалены из результата.
Временный пароль тестовой учётной записи селлера после съёмки возвращён к исходному значению.
