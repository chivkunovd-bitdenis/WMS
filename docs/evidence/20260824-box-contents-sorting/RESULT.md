# S-20 · короба и россыпь

- Каждый короб показывает стандартные товарные строки внутри своего блока.
- У товарных строк короба нет выбора ячейки и отдельных действий.
- Ячейка выбирается один раз для короба; размещение переносит весь его остаток.
- Ниже показывается только россыпь; исходное количество коробов из неё вычитается стабильно.
- Незакрытый короб не блокируется на сортировке.
- Существующий сценарий сканирования «ячейка → товар» сохранён.

Доказательство: `box-and-loose.png`.

## Раунд правок 1

- «Короба» и «Россыпь» — крупные жирные заголовки; оба раздела независимо сворачиваются.
- Общий счётчик и «Применить раскладку» находятся в верхнем ряду действий документа.
- Размещённый короб остаётся видимым, показывает полный исходный состав, фактическую ячейку
  и зелёный статус «Разложен»; в сканер и повторное размещение он больше не попадает.
- Старый неприменённый черновик ячейки не выдаётся за фактическое размещение: для показа берутся
  только новые строки, подтверждённые `posted_qty` короба.

Доказательство после размещения: `box-placed-visible.png`.
