# WMS-604: признак ЧЗ для принятой одежды

30 сентября 2026, 12:40 UTC. Выполнено в рабочей БД WMS через существующий SSH/psql-доступ. Значения секретов и коды маркировки не читались и не сохранялись.

Выбраны карточки товаров с явно указанными категориями одежды (включая палантины и шарфы), встречающиеся в завершённых входящих приёмках: `operation_type=inbound`, статус `sorting`/`done` либо старый `verified`/`posted`, заполненная дата `verified_at`, положительное фактическое количество строки `actual_qty`. Статусы старого формата подтверждены датами завершения приёмки в рабочей БД. Возвраты и незавершённая приёмка не включены. Товарный признак общий для карточки: изменение действует при последующей работе с этим товаром независимо от конкретной поставки.

Из 551 карточки 27 уже имели признак. Изменено ровно 524 карточки: ArtMaks — 321, Империя ФФ — 191, FFAdam — 5, ИП Тестовый — 4, AVpack — 2, ИП Львова В.В. — 1. В Бамбуке все 16 подходящих карточек уже имели признак.

Операция обновила только `products.requires_honest_sign`. Перед записью сохранён полный состав `marking-manifest.json`, повторное чтение сравнило его с рабочими данными. Транзакция блокировала только изменяемые карточки с отказом при занятой строке, проверила исходный флаг, принадлежность принятому множеству, tenant и хеш остальных полей. После записи проверены 524 целевых флага, хеш остальных полей и неизменность флагов всех остальных товаров. После commit отдельное чтение подтвердило 524/524 изменённых карточек; дополнительное чтение полного множества подтвердило 551 true, 0 false.

Первый запуск завершился ошибкой psql (exit 3); точная диагностика stderr тогда не была сохранена. Перед повтором отдельное чтение подтвердило полное совпадение всех 551 записей с исходным manifest и 524 false, то есть первая попытка ничего не сохранила. Следующая попытка успешно завершила транзакцию и прошла отдельное перечитывание. Скрипт теперь сообщает диагностику psql; автоматических повторов нет.

Не включены обувь (ботильоны, кроссовки, лоферы, туфли), сумки, банты, резинки, косметические повязки и товары без категории: запрос касался одежды/шарфов. Остатки, поставки, заказы и сами коды ЧЗ не изменялись.
