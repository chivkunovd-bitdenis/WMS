# S-11 — хранение: браузерная приёмка

Проверено 23.08.2026 в Chromium/Playwright на фактическом React-экране
`/app/ff/inventory` с операторским viewport 1280 px.

- Навигация содержит отдельный вход «Хранение».
- При неполном покрытии складов тарифами администратор видит ровно одно действие
  «Задать тариф», даже когда строки расчёта уже есть.
- Развёрнутый блок подписан «Расчёт селлера Норд за июль 2026 г.», склад показан
  отдельной спокойной строкой. SKU и артикул продавца собраны в одной товарной
  ячейке и целиком доступны через общий `TextCell`/tooltip.
- Все восемь заголовков detail-таблицы читаются при 1280 px; таблица и страница
  не имеют горизонтального переполнения, глобальный UI-kit не менялся.
- Диалог истории сохраняет все пять колонок в пределах окна; длинный автор
  доступен целиком через tooltip.
- Превью повторной печати показывает ставку и сумму справа от длинного артикула;
  таблица не имеет горизонтальной обрезки. Отдельный Playwright-сценарий проверен
  с `media: print` и A4 viewport 794 x 1123.
