# WMS-673: evidence миграции контракта колонок WMS-680

Проверен коммит `5868c3b1300d0969bf4283b5df18635eec9481f2`. Он меняет только
два контракта WMS-673 и их PDF-помощник: структура листа подбора теперь
проверяется как 12 колонок — №, Фото, Товар, Артикул, Цвет, Размер, Ячейка /
тара, Заказы, Стикер, Взять, Подобрано, Маркировка. Это следует из R8–R10
WMS-680 и уточнения `683a820fd11a144f73e5743ebed201654308071c`; продуктовый
код не менялся.

## Реальный PDF

Локальный Chrome `154.0.8037.98` отрисовал точный HTML production-функции
`buildFbsPickingListPrintHtml`. Для одного длинного товара SHA-256 HTML:
`5fe828d0f96e4b69ad390c021f9d3312b7fb3b88c5321bf223305f2e27970b5e`, PDF:
`67022855221c2c9a4b4b6f11051552d456ee9c8fceee0a4d7841c0f805614a6d`; для
34 строк SHA-256 HTML:
`c307f3ae7d62ae84e5663e8c7c2836abe3de5345903291ffaaca509d31ba8029`, PDF:
`f17df548d9f7f553bbfdd4e734f3af29a064b55f1ba326afcff7d959fa707ef5`.

В обоих случаях Chrome вернул ровно 12 границ колонок. Все 34 строки имеют
по 12 ячеек; границы заголовков и ячеек совпадают, содержимое остаётся в своих
ячейках, соседние ячейки и строки не накладываются. Размер остаётся с шрифтом
20px, а A4 landscape и поля 10mm проверяются контрактом. Пиксельные 28/54/116
в исходном CSS сохранены для №/Фото/Стикера; их вычисленное значение в PDF
масштабируется браузером вместе со страницей, поэтому геометрическая проверка
подтверждает ненулевые фактические области, а CSS-проверка — исходные размеры.

Запуск с реальными артефактами завершился: `5 passed` в
`fbsPickingColor.wms673.pdf.test.ts`, включая C7 и C7/C11. Это не заменяет
полный CI.

## Ограничение локального DOM-прогона

Обычный PDF-прогон без `WMS673_RENDERED_ARTIFACTS_DIR` даёт 2 passed и 3
ожидаемых skipped: такой результат сам по себе не выдан за проверку реального
PDF. DOM-файл запускался адресно, но текущий Vitest завис до начала тестов на
трансформации тяжёлых React-экранов; после минуты был остановлен только
созданный этим запуском процесс. Поэтому DOM-проверка не заявляется пройденной
и остаётся для CI/следующего доступного рантайма.
