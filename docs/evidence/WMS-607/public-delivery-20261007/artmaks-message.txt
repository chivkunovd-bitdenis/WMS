Для АртМакс подготовлено обновление WMS Print для Mac. Проверены обе сборки — Apple Silicon (ARM) и Intel. Команда сама выберет нужную. Прежняя программа и история заданий сохраняются в резервной копии; подтверждённые и неизвестные результаты печати автоматически не повторяются.

1. Откройте Терминал в папке прежней программы, где находится файл wms-print. Если Терминал уже открыт, наберите cd с пробелом, перетащите в окно эту папку и нажмите Enter.
2. Вставьте целиком одну команду:

/bin/bash -c 'set -euo pipefail; test -x "$PWD/wms-print" || { printf "%s\n" "Откройте Терминал в папке прежнего WMS Print (где лежит wms-print), затем повторите команду."; exit 1; }; d=$(/usr/bin/mktemp -d "${TMPDIR:-/tmp}/wms-direct-update.XXXXXX"); /usr/bin/curl --fail --location --silent --show-error --proto "=https" https://github.com/chivkunovd-bitdenis/WMS/releases/download/wms-print-direct-v2026.10.07.1/updater-manifest.json -o "$d/manifest.json"; printf "%s  %s\n" "43719cac9902a3c24f33ace6a6c03332f43c7c80f8811a2dfea9ee045a222509" "$d/manifest.json" | /usr/bin/shasum -a 256 -c -; /usr/bin/curl --fail --location --silent --show-error --proto "=https" https://raw.githubusercontent.com/chivkunovd-bitdenis/WMS/a475a7342c0da72dd49b2990bd998c522ecc2c2b/tools/print-agent/update_macos_direct.sh -o "$d/updater.sh"; printf "%s  %s\n" "a8f91951b2fab957840b0c4861001d8aaa1ff69db794b446717dbc5be9d8a946" "$d/updater.sh" | /usr/bin/shasum -a 256 -c -; /bin/bash "$d/updater.sh" --app-dir "$PWD" --manifest "$d/manifest.json"'

3. После успешного обновления откройте WMS в Chrome и напечатайте одну обычную QR-этикетку. Если macOS или Chrome запросит разрешение для программы/доступа к локальной сети, подтвердите его штатно в настройках — защиту macOS отключать не нужно. Используется системный принтер по умолчанию; команда его настройки не меняет.

Пакеты и проверки готовы, установку на вашем Mac и результат на бумаге нужно подтвердить этим последним шагом. Если команда сообщит об ошибке, сохраните её текст: она не будет насильно останавливать чужую программу или обходить неопределённый результат.
