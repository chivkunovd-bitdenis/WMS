# WMS-503: план адресного исправления 22.09.2026

Поручение владельца: «срочно исправляй все остатки которые были таким образом созданы … сейчас эта дыра уже закрыта?»

Работающий API не содержит `_write_off_sold_order`; обработчик sold меняет статус, освобождает резерв и начисляет услугу, склад не списывает. Исторический механизм создан 29.08 и удалён 04.09 в 0c7d1f97. Прежняя отмена 384 единиц касалась чужих складов Фадина; она не была полным исправлением других селлеров.

## Область

Полное чтение старого журнала выявило 136 ещё не отменённых записей с заполненным source_mode, единичным fbs_shipment -1, без инициатора и WB-операции, в период 01–04.09, с совпадающим временем создания журнала и движения. Все связаны с done/sold. 381 запись того же механизма уже имеет обратное движение и пропускается. Более старые записи с пустым source_mode не смешаны с этим механизмом: поздние 12 движений созданы 04.09 для журналов от 21–29.08 при отдельной сверке; ещё одно датировано 31.08.

Все 34 затронутых остатка совпали с суммой журнала. Текущий packed=0. Для восстановления выбраны 113 единиц на 30 остатках: Бугаев45, Горячева25, Агишева26, Манкаев17. Ещё 23 записи относятся к четырём фактически пересчитанным позициям: Манкаев17, Рябов5, Фэшн1. Последний пересчёт каждой позиции создан после старых списаний, имеет заполненный факт и posted_delta=actual-expected. Поэтому эти23 помечаются сверенными без добавления товара. Строки инвентаризации с actual=NULL не считаются пересчётом.
