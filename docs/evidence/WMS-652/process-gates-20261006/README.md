# Проверка обязательного исполнения существующих процессов

Рабочая ветка `codex/wms652-process-gates`, база продукта d61805978b3e7878d1056c99b4e6e0823edf49a5.
Продуктовые файлы в этой дельте не меняются. Production остаётся BLOCKED.

Контракт `guards/PROCESS_CONTRACTS.json` сохраняет исходные тесты, их helpers,
fixtures, конфигурацию обнаружения, команды CI и проверяющие скрипты в существующих
путях. До установки принятой базы это bootstrap; собственное обновление хешей
в этой рабочей ветке не считается действующей защитой от последующих изменений.
После принятия сравниваются именно файлы и правила из предыдущей доверенной базы.

Проверка отчётов требует конкретные имена сценариев, успешный результат каждого,
отсутствие дубликатов и точный состав там, где выделен отдельный запуск. Сценарии
в полном наборе могут быть подмножеством, но ни один обязательный пропуск не принят.
Настоящий браузер дополнительно сообщает точный проверенный commit. Промежуточные
артефакты и итоговый отчёт имеют SHA, run id и attempt в имени; результат старой
попытки не заменяет недостающий результат текущей.

Печать проверяется отдельно на Linux и Windows. Два Unix-only опыта выполняются
на Linux, Windows CMD выполняется на Windows. Состав каждой платформы точный,
без обязательных skip. Суммарно сохранены все 31 уникальные проверки печатного агента.

В CI добавлены 33 сценария настоящего экрана FBS: QR-ввод, КИЗ и выходные PNG,
очередь следующего заказа, флаги печати, задержка/потеря подтверждения, восстановление
экрана, выбор строк, групповое создание и добавление в существующую поставку.
Они работают на искусственных HTTP/принтерных границах, без рабочих заказов.
Тестовый Chrome запускается с `--mute-audio`; громкость компьютера не меняется.

Изолированные шесть сценариев конкуренции PostgreSQL запрещают внешние соединения
до импорта приложения. Разрешено только соединение с собственной тестовой базой.
Тест инцидента 675 исполняется отдельно с исходными сохранёнными fixtures.
