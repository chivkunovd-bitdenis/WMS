Контракт `guards/PROCESS_CONTRACTS.json` сохраняет исходные тесты, их helpers,
fixtures, конфигурацию обнаружения, команды CI и проверяющие скрипты в существующих

После принятия сравниваются именно файлы и правила из предыдущей доверенной базы.

Проверка отчётов требует конкретные имена сценариев, успешный результат каждого,
отсутствие дубликатов и точный состав там, где выделен отдельный запуск. Сценарии
в полном наборе могут быть подмножеством, но ни один обязательный пропуск не принят.
Настоящий браузер дополнительно сообщает точный проверенный commit. Промежуточные
артефакты и итоговый отчёт имеют SHA, run id и attempt в имени; результат старой
попытки не заменяет недостающий результат текущей.
