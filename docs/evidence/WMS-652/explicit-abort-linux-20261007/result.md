The observed `Fetch.requestPaused` ID `interception-job-3.0` maps to Network request `3156.3` and frame `1DD331B6465D837EFCBD082834C9E57E`. Command 15 with a never-observed ID rejected with the identical native error and remains unexplained. The ledger saves both command identities and the full request/network/frame mapping.

In the single Node monotonic clock, the paused request was observed at 492.745126 ms, the abort command was sent at 492.907127 ms, matching cancellation arrived at 494.366975 ms, known-ID fulfillment was sent at 500.221151 ms, and its rejection arrived at 501.308822 ms. The raw events also carry UTC and browser timestamps; the ordering above uses one clock rather than subtracting unrelated browser/Node clock origins.

This demonstrates that a real, independently observed client cancellation can invalidate its Fetch interception ID. It also demonstrates that the native error text alone cannot distinguish that boundary from a malformed unknown ID. It does not establish the original full-CI failure's missing command/ID, does not prove a 30-second timeout caused the earlier roughly seven-second selected case, and does not turn the earlier navigation control into a canceled-request proof. There is no error suppression or fixture/product implementation in this checkpoint.

A minimal handling contract can be considered only for the exact observed paused request mapped to the same Network request in the same browser/session/case, with an independently observed canceled loading failure, and the exact native terminal Fetch command's -32602 Invalid InterceptionId refusal. It must preserve unknown IDs, missing/wrong mapping, noncanceled failures, unrelated protocol errors and duplicate/completed requests as failures. No broad string-match ignore is safe. Separate tests must freeze that boundary before handling code; the unchanged 43 business assertions and timeouts remain mandatory. Transport draining without suppressing errors remains a separate hypothesis; this probe does not demonstrate commands crossing a case/navigation boundary.
