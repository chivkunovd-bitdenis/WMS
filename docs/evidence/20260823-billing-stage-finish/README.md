# S-31 «Расчёты»: evidence

Проверен существующий экран S-31 без добавления соседних настроечных экранов. Экран использует общий UI-kit: `ScreenHeader`, `FilterBar`, `DataTable`, состояния, статусы и действия. На ширине Chromium Desktop Chrome страница не создаёт горизонтальную прокрутку; широкая таблица прокручивается внутри своего контейнера.

## Живой Chromium

- `billing-charges.png` — вкладка «Начисления», реальная production-like оболочка приложения, фильтры и строка начисления.
- `billing-invoice.png` — счёт, реквизиты сторон, строки в целых копейках, детализация исходного документа и штатные действия.
- Playwright production-preview: 16 из 17 сценариев прошли одним прогоном; оставшийся сценарий был специально добавленной геометрической проверкой и обнаружил выход страницы на 67 px за viewport. После добавления `minWidth: 0` в flex-main эта проверка отдельно прошла в Chromium. Остальные 16 сценариев продуктовый код не меняли.
- Два предыдущих таймаута были ошибками локаторов теста (MUI размещает `data-testid` на скрытом input, а accessible title иконки — на wrapper), исправлены без изменения поведения экрана; оба сценария после исправления прошли.
