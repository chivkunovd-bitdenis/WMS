## Ломающие кейсы

Заведено 15 ломающих кейсов в `S-03.md` и 1 в `S-04.md`.

### S-03 — «Показать ещё» (race conditions и граничные состояния)

| ID | Название | Что ломает |
|---|---|---|
| S-03-TC-021 | Двойной клик «Показать ещё» до блокировки — нет дублей строк | Два запроса до `disabled`, строки дублируются |
| S-03-TC-022 | Переключение вкладки «Новые» → «В работе» во время «Загружаем…» | Ответ «Новых» вставляется в «В работе», JS-ошибка unmounted |
| S-03-TC-023 | Ошибка подгрузки → повторный клик → успех → плашка уходит | Плашка остаётся навсегда, строки не добавились |
| S-03-TC-024 | Тик 30 с конкурирует с «Показать ещё» — нет дублей, скролл не прыгает | Ответ тика перезаписывает state второй страницы |
| S-03-TC-025 | Сервер вернул непустой next_cursor при пустом items — кнопка исчезает | Бесконечный цикл кнопки «Показать ещё» |
| S-03-TC-026 | Обновление страницы браузером во время «Загружаем…» | Зависшее состояние «Загружаем…» после перезагрузки |
| S-03-TC-027 | «Выбрать все» → «Показать ещё» → счётчик не сбрасывается | Счётчик выделения обнуляется при подгрузке |
