### Репро-1 · Галка «Без распределения» заблокирована при наличии любого короба

**Где воспроизвести:** `origin/etalon` / прод (фикс не влит).

**Шаги:**
1. Открыть `/app/ff/fbs` как FF-оператор.
2. Выбрать поставку WB в стадии сборки → перейти на вкладку «Короба».
3. Нажать «Добавить короб» — создать один пустой короб.
4. Попытаться щёлкнуть по чекбоксу «Без распределения».

**Видно сейчас:** чекбокс заблокирован (`disabled`), переключить нельзя.
Код: `disabled={workspace.boxes.length > 0}` в `FfFbsSupplyWorkspace.tsx`.

**Должно быть:** чекбокс доступен, пока ни один заказ не разложен в короб
(проверка по `FbsPackingBoxItem`, а не по `boxes.length`).

### Репро-2 · Признак режима теряется при пересоздании коробов

**Где воспроизвести:** `origin/etalon` / прод (фикс не влит).

**Шаги:**
1. Открыть поставку в стадии сборки, вкладка «Короба», коробов ещё нет.
2. Включить «Без распределения» (пока чекбокс доступен, т.е. пока список коробов пуст).
3. Создать короб.
4. Удалить этот короб.
5. Создать новый короб.
6. Проверить состояние чекбокса.

**Видно сейчас:** галка сброшена, режим выключен. Признак хранился в поле
`creation_idempotency_key` первого короба с префиксом `no-distribution:`;
при удалении и пересоздании ключ меняется — приписка пропадает.

**Должно быть:** галка остаётся включённой. Признак хранится на поставке
в поле `boxes_without_distribution_at` и не зависит от жизненного цикла коробов.

### Репро-3 · Шапка показывает «Распределено 0 из N» при включённом режиме

**Где воспроизвести:** `origin/etalon` / прод (фикс не влит).

**Шаги:**
1. Открыть поставку, вкладка «Короба», коробов нет.
2. Включить «Без распределения».
3. Посмотреть на шапку вкладки.

**Видно сейчас:** «Распределено 0 из 155 шт · осталось 155» с красной цифрой.
Источник истины — скан коробов (`boxes.some(b => b.without_distribution)`),
который при пустом списке всегда даёт `false`, и шапка идёт по ветке
счётчика распределения.

**Должно быть:** шапка не показывает «Распределено X из Y» при включённом режиме
ни при каком количестве коробов.
