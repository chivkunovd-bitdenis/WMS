## Примечания для судьи

**Контекст «настоящий склад»** — склад без признака `is_auto_fbs: true` в ответе
`GET /warehouses`. Служебные подстановки (код начинается с `fbs-wb-`) оператору не видны.

**Тестовые данные.** Для кейсов с двумя складами нужен тенант с вручную созданным
вторым складом («Дополнительный», код `second`). Кейсы с одним складом проходятся на
стандартном тенанте («Основной» + любые `fbs-wb-*`).

**Порядок прохождения:** TC-008 (S-03) → TC-001 (S-25) → TC-002 (S-25) → TC-004 (S-25)
— эти четыре связаны в цепочку (кросс-складской подбор → запись в журнале переносов).
Остальные независимы.

**Кейс S-14-TC-001** требует предварительного выполнения S-03-TC-008 (кросс-складской
подбор должен уже состояться). Допустимо объединить с ним в одну сессию.
