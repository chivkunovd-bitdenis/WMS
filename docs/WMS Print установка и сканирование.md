# WMS Print установка и сканирование

Инструкция для оператора склада ArtMaks · обновлено 7 октября 2026 года

WMS Print передаёт этикетки из WMS на системный принтер по умолчанию. Окно обычной печати не требуется. Сначала настройте программу на своём компьютере, затем проверьте одну этикетку. Дальше работайте по разделу «Сканирование» на последней странице.

## Mac подготовка к обновлению

Это обновление уже установленной WMS Print. Команда на следующей странице сама выбирает версию для Mac с чипом Apple или процессором Intel, сохраняет предыдущую программу и историю заданий. Пока вы находите папку, оставьте старую программу открытой: обновление само безопасно остановит её.

1. В меню Apple в левом верхнем углу откройте «Системные настройки» → «Принтеры и сканеры». В поле «Принтер по умолчанию» выберите принтер этикеток. Проверьте, что принтер включён и в нём есть этикетки нужного размера.

2. Нажмите значок Finder — сине-белое лицо в нижней панели. Откройте папку, из которой вы обычно запускаете WMS Print. Внутри неё должен лежать файл wms-print без расширения. Нужна прежняя установленная папка, а не новый скачанный ZIP-архив.

Если не помните, где папка: в Finder нажмите Command + F, выберите поиск «Этот Mac» и введите wms-print. Найдите папку с этим именем и откройте её. Если найдено несколько копий и вы не знаете, какую запускали, не выбирайте наугад: пришлите в чат снимок результатов поиска. Историю и старую папку не удаляйте.

3. В верхнем меню Finder выберите «Вид» → «Показать строку пути». Внизу окна появится цепочка папок. Нажмите ПРАВОЙ кнопкой на последнюю папку в этой цепочке — ту, внутри которой виден файл wms-print. Выберите «Открыть в Терминале» (Open in Terminal). Откроется окно, куда можно вставить команду.

На Mac, где пункт находится в подменю, выберите «Службы» → «Новый Терминал по адресу папки» (New Terminal at Folder). Если ни одного такого пункта нет, пришлите снимок меню в чат. Вводить путь вручную или перетаскивать папку в окно не нужно.

4. Не закрывая найденную папку, перейдите к следующей странице. Команду нужно вставить именно в новое окно, открытое из этой папки. Она проверит наличие прежней программы до обновления.

## Mac запуск обновления

5. Выделите весь блок ниже: от /bin/bash до последнего одинарного знака кавычки. Скопируйте Command + C, нажмите в окно Терминала, вставьте Command + V и нажмите Enter один раз. Ничего в блоке менять не нужно. Команда сама скачает и проверит файлы новой версии.

```bash
/bin/bash -c 'set -euo pipefail; test -x "$PWD/wms-print" || { printf "%s\n" "Откройте Терминал в папке прежнего WMS Print (где лежит wms-print), затем повторите команду."; exit 1; }; d=$(/usr/bin/mktemp -d "${TMPDIR:-/tmp}/wms-direct-update.XXXXXX"); /usr/bin/curl --fail --location --silent --show-error --proto "=https" https://github.com/chivkunovd-bitdenis/WMS/releases/download/wms-print-direct-v2026.10.07.1/updater-manifest.json -o "$d/manifest.json"; printf "%s  %s\n" "43719cac9902a3c24f33ace6a6c03332f43c7c80f8811a2dfea9ee045a222509" "$d/manifest.json" | /usr/bin/shasum -a 256 -c -; /usr/bin/curl --fail --location --silent --show-error --proto "=https" https://raw.githubusercontent.com/chivkunovd-bitdenis/WMS/a475a7342c0da72dd49b2990bd998c522ecc2c2b/tools/print-agent/update_macos_direct.sh -o "$d/updater.sh"; printf "%s  %s\n" "a8f91951b2fab957840b0c4861001d8aaa1ff69db794b446717dbc5be9d8a946" "$d/updater.sh" | /usr/bin/shasum -a 256 -c -; /bin/bash "$d/updater.sh" --app-dir "$PWD" --manifest "$d/manifest.json"'
```

6. Дождитесь результата. Успех начинается со слов «Verified native Direct target»; дальше будет указан путь резервной копии. При повторе уже выполненного обновления возможны строки «Verified target already running» или «Verified installed target restarted». Это означает, что нужная программа проверена и запущена. Вручную ещё одну копию запускать не нужно.

7. Если вместо успеха появилась ошибка, сохраните её текст или снимок окна и пришлите в чат. Не удаляйте журнал, резервную копию или очередь принтера и не запускайте разные версии одновременно. Две строки с «OK» внутри проверки файлов ещё не означают, что обновление завершено.

Если macOS запретила запуск файла wms-print: откройте Apple → «Системные настройки» → «Конфиденциальность и безопасность», прокрутите до «Безопасность» и разрешите именно этот файл кнопкой «Открыть» / «Всё равно открыть». После разрешения повторите тот же блок. Защиту компьютера отключать и дополнительные программы устанавливать не нужно.

8. После успешного обновления откройте WMS в Chrome и проверьте одну QR-этикетку по последней странице. После перезагрузки Mac можно открыть прежнюю папку в Finder и дважды нажать wms-print. Если открылось окно программы, оставьте его открытым; можно свернуть.

Для первого запуска на Mac, где WMS Print ещё не было: выберите архив по типу компьютера (Apple → «Об этом Mac»), распакуйте двойным нажатием, перенесите всю папку wms-print в «Документы» и дважды нажмите файл wms-print внутри неё. Команда обновления выше предназначена для прежней установленной программы.

## Windows установка и запуск

Для Windows используется опубликованная версия 30 сентября 2026 года. Обновление от 7 октября выпущено для Mac. Если WMS Print на Windows уже работает, заново скачивать её ради обновления Mac не нужно.

1. Выберите принтер этикеток по умолчанию. В Windows 11: «Пуск» → «Параметры» → «Bluetooth и устройства» → «Принтеры и сканеры». Выключите «Разрешить Windows управлять принтером, используемым по умолчанию», выберите принтер этикеток и нажмите «Использовать по умолчанию».

В Windows 10: «Пуск» → «Параметры» → «Устройства» → «Принтеры и сканеры». Выключите управление принтером по умолчанию, выберите принтер → «Управление» → «Использовать по умолчанию».

[Скачать WMS Print для Windows 64 бит](https://github.com/chivkunovd-bitdenis/WMS/releases/download/wms-print-direct-v2026.09.30.5/WMS-Print-Console-Windows-x64.zip)

2. Нажмите ссылку выше. Откройте Проводник — значок жёлтой папки в нижней панели — и слева выберите «Загрузки». Найдите WMS-Print-Console-Windows-x64.zip. Нажмите на него ПРАВОЙ кнопкой → «Извлечь всё…» → «Извлечь». Программу нужно запускать из извлечённой папки, а не из окна ZIP-архива.

3. Откройте извлечённую папку, затем папку wms-print внутри неё. Если старая версия уже открыта, сначала закройте её чёрное окно. Дважды нажмите wms-print.exe (при скрытых расширениях имя может отображаться как wms-print). Оставьте всю папку вместе с соседними файлами. Не заменяйте и не удаляйте старую папку: она остаётся запасной копией.

4. Если Windows покажет «Windows защитил ваш компьютер», для программы по ссылке из этой инструкции нажмите «Подробнее» → «Выполнить в любом случае». Если кнопки нет или сообщение говорит об угрозе, сохраните снимок и пришлите в чат; не отключайте защиту компьютера. Если система запросит доступ к сети, разрешите доступ для WMS Print.

5. Откроется чёрное окно программы. Не закрывайте его во время работы, можно свернуть. После перезагрузки компьютера снова откройте тот же wms-print.exe. Терминал и команды из раздела Mac на Windows не нужны. Сохранённую историю WMS Print не удаляйте.

## Chrome на обоих компьютерах

Работайте в WMS через Google Chrome. Если при первой печати сайт просит доступ к локальной сети или программе на этом компьютере, нажмите «Разрешить». Если раньше нажали «Запретить», откройте значок настроек слева от адреса сайта → «Настройки сайта», найдите разрешение локальной сети и разрешите доступ, затем перезагрузите страницу. Название пункта зависит от версии Chrome.

## Первая проверка

В WMS откройте поставку WB FBS → «Упаковка и маркировка». Выберите размер этикетки под рулон, включите «Печатать QR» и нажмите в поле скана. Сканируйте одну вещь; если WMS ждёт ЧЗ, следующим сканом считайте маркировку именно этой вещи. Проверьте, что вышла одна этикетка нужного размера и QR читается сканером. Сообщение программы о принятии задания само по себе не доказывает выход бумаги.

## Сканирование и непрерывная печать WB FBS

Откройте нужную поставку Wildberries, при наличии нажмите «Начать работу с поставкой» и перейдите в «Упаковка и маркировка». В режиме «Сборка» выбранная сборка определяет набор поставок. Перед сканированием нажмите на общее поле скана, выберите размер этикетки и галки. Сканер должен завершать ввод клавишей Enter.

Товарный штрихкод определяет товар; QR стикера WB — конкретный заказ; ЧЗ или КИЗ — индивидуальная маркировка вещи. Между сканами одной вещи не переводите курсор в поиск или другой заказ.

## Что включить

«Печатать QR» — стикер конкретного заказа WB. Для маркируемого товара без выдачи ЧЗ из пула: товарный штрихкод → дождаться выбора заказа → ЧЗ с этой вещи → печать QR и завершение упаковки. Для товара без маркировки отдельный скан ЧЗ не нужен.

«Печатать ЧЗ» — получить свободный код из заранее загруженных кодов этого товара, привязать к заказу и напечатать. Включите также QR, если нужен стикер заказа, затем сканируйте товарный штрихкод. Сначала выходит QR, затем выбранное количество этикеток ЧЗ. Дополнительный скан ЧЗ не требуется. Наклейте код именно на эту вещь. Если подходящего кода нет, нужны загруженные коды; случайный чужой код не подходит.

«Перепечатывать ЧЗ» — копия кода, который уже есть на вещи. После товарного штрихкода сканируйте её ЧЗ. При включённом QR сначала печатается стикер заказа, затем выбранное количество копий ЧЗ. Если отсканировать полный ЧЗ до выбора заказа, это только копия маркировки: заказ не выбирается и вещь не упаковывается.

«Печатать ЧЗ» и «Перепечатывать ЧЗ» выбирайте по задаче; не включайте оба режима одновременно. Количество экземпляров относится к этикетке ЧЗ. QR выбранного заказа печатается один раз.

По готовому стикеру WB: скан QR выбирает конкретный заказ; при необходимости затем сканируйте ЧЗ вещи. Этот путь не выдаёт ЧЗ из пула. Если печать не нужна, снимите все галки и начинайте со стикера WB. При снятых галках товарный штрихкод не заменяет выбор заказа по стикеру.

## Исправление и сбой

Поле ЧЗ в строке относится именно к этой строке. Escape снимает текущий выбор вещи. Стрелка «Назад» отменяет последнее завершённое действие сканирования; дождитесь результата. Крестик у ЧЗ очищает маркировку заказа, а не печатает её. Эти действия не уничтожают уже вышедшую этикетку. Не очищайте коды всей поставки ради одной ошибки.

Если WMS Print не отвечает, отложите текущую вещь, проверьте программу и разрешение Chrome. После восстановления продолжите ту же вещь. Если программа приняла задание, но бумаги нет, сначала проверьте принтер, рулон и системную очередь: задание может выйти после восстановления. При неизвестном результате не создавайте новую печать вслепую и не удаляйте историю; сохраните ошибку и сообщите в чат.

После упаковки проверьте соответствие QR и ЧЗ вещи. Статус «Упаковано» не заменяет подтверждение маркировки от WB: отдельную ошибку WB нужно учитывать. Если заказ выбран при включённой печати, восстановите его исходную операцию; снятие галки после ошибки не отменяет возможное уже отправленное задание.
