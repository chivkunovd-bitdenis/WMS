## Что сохранено

Android использует существующий ScanScaffold, Material3 и тему WMS. В очереди появилась кнопка создания, FF draft открывается отдельно от прежнего пересчёта. Новая форма выбирает склад и селлера, открывает каталог, добавляет товар/сканы через increment, редактирует общий факт, удаляет SKU и завершает прямо через complete-receiving. Редактор тары работает с коробом или грузоместом. Введённое общее количество хранится отдельно от сохранённого серверного факта, поэтому его можно применить после исправления конкретной тары.

Handwritten Retrofit DTO добавлен потому, что bundled generated jar не содержит происхождение документа и cargo_places. AuthStore дополнен только синхронным сохранением локального состояния приёмки; потоки входа не переписаны. UUID и точный body сохраняются до HTTP, контекст включает URL сервера, tenant, сотрудника и документ. Повтор неизвестного ответа использует прежний body. Создание пустой тары в существующем серверном API не имеет idempotency receipt: восстановление такого запроса перечитывает список и не отправляет создание слепо повторно.

Веб меняется внутри существующих карточки, выбора товаров и редактора тары: FF показывает один принятый факт, редактирует его через expected endpoint и завершает непосредственно в sorting. План селлера остаётся отдельным. Создание и мутации сохраняют точный запрос в localStorage до HTTP. Для нескольких выбранных товаров сохраняется остаток уже отправляемого набора; при повторе завершённые строки не отправляются заново. D6 оставляет введённое количество, предлагает раскрыть существующий список тары и выбрать конкретный короб/грузоместо; штатная кнопка «Сохранить» затем применяет ранее введённый общий факт.
