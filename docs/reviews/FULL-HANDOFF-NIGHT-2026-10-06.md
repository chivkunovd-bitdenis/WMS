## 4. Обязательные решения владельца

### Модели, процесс и параллельность

- Ведущий — модератор, следит за продвижением и отсутствием повторов.
- Новые аналитика, тесты, реализация и приёмка — **gpt-6.1-sol**.
- Независимое ревью — **gpt-6-astra, effort high, никогда выше high**.
  Самопроверка разработчика независимое ревью не заменяет.
- Opus через облачный `claude --remote --model opus` пробовали. CLI принял режим,
  но получил `401 OAuth access token expired`. Владелец прямо разрешил Astra high
  вместо недоступного Opus. Не ждать только Opus и не менять его авторизацию.
- **Не использовать skills.** Не создавать дополнительные пользовательские
  чаты для ролей. Фоновые роли и субагенты допустимы по прежнему поручению,
  но сначала проверить, нет ли действующего исполнителя той же задачи.
- Процесс: требования аналитика; отдельные тесты до кода; разработчик;
  независимое ревью; приёмка аналитика; полный CI точного опубликованного SHA.
  Не запускать рекурсивные цепочки для правки самого процесса.
- Не менять зафиксированные ожидания тестов ради зелёного результата.
  Разрешённые изменения бизнес-контракта отделять от исправлений фикстур.
  Не повторять полностью неизменные ревью, PDF-прогоны и CI без новой причины.

### Безопасность и production

- Обычное получение статусов WB/Ozon **не меняет остатки и начисления**.
- Прямое исключение владельца: если поставка создана в WMS, но действительно
  передана через кабинет площадки, можно провести только подтверждённую ранее
  не проведённую разницу, **ровно один раз**. Не списывать весь состав повторно.
- Обязательны сохранность резервов, остатков, всего FBS, непрерывной печати
  «сканирование — сразу печать», восстановление после потери ответа и отсутствие
  повторных внешних действий.
- Не проводить реальную отгрузку, внешнее списание КИЗ, подпись чужой ЭЦП или
  физическую печать ради теста без отдельного разрешения на конкретное действие.
- Не открывать кабинеты секретов, не создавать/заменять ключи, не выпускать JWT
  ради обхода авторизации и не обходить scoped SQL gateway. Использование
  штатным приложением существующих настроек не означает управление ключами.
- **Не запускать Chrome/Playwright на Mac.** Пользователь сообщил о расходе
  22 ГБ памяти. UI/PDF проверки делались на удалённых GitHub runners.
