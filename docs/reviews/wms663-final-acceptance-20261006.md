## Исходный запрос и добавленные аналитиком условия

Владелец прямо попросил проверить возможность передачи ГТД по API и дать оператору такую же галку, чтобы устранить проблему. R1–R4 выражают явный выбор в существующем заказе; R5–R11 и R13–R15 конкретизируют контракт, сохранность соседних сведений, доступ и продолжение после сбоя; R12 сохраняет существующую сборку. Это обоснование реализации, не дословный запрос всех тестовых сценариев.

C17/G2 — техническая проверка актуальности официального API, связанная с прямыми словами «проверить ... можем ли ... по API». [Свежая bounded проба](wms663-c17-official-20261006/report.md), commit `b6e404bb7feae4602bc2b7c6854265b6ab87b736`, run 37441530297: шесть HTTP 307, остановка на redirect limit, свежей схемы нет. Успех диагностического workflow означает сохранение UNKNOWN, а не PASS C17. Исторический официальный снимок подтверждает поля, но не текущую свежесть или enum document check_status.

C19 — ручной внешний цикл, добавленный аналитиком из R6/R8/R12; владелец не задавал его дословно и нынешнее поручение не разрешает внешние записи. Он сохранён как НЕ ВЫПОЛНЕНО/НЕ РАЗРЕШЕНО и препятствует полному PASS по действующему документу. FakeTransport, UI mocks и ревью не заменяют внешний результат.

Sonnet-макет/G3 — историческое решение аналитика о способе визуальной проверки, а не самостоятельное исходное требование владельца. Макет и deployed-экран не выполнены. Прямая замена модели на Sol 6.1 имеет приоритет; реальное доказательство документной геометрии C18 принято без выдуманного Sonnet-результата. Минимальные оставшиеся внешние условия: для C17 — актуальная доступная официальная схема либо относящийся к вопросу документированный ответ разрешённого тестового Seller API; для C19 — разрешённый тестовый контур/posting и сохранённые set→status→reopen→сборка, отказ→исправление. Новые стадии, повторные вопросы о поведении и широкие тестовые циклы не добавлены. Затем отдельно проверяется полный CI итогового SHA; интеграция исторического документа WMS-662 остаётся у её владельца.
