WMS-670. В той же Git-истории находятся инфраструктурная коррекция WMS-652 и

Кандидат не включает незавершённые WMS-517, WMS-658, WMS-662, WMS-663 и другие
параллельные задачи. Он также не объявляет готовой локальную Telegram-службу
WMS-676: проверенные и непринятые изменения installer/runtime не являются
предками продуктового SHA. Пакет `tools/support_agent` не входит в Docker build
context WMS API, worker, beat или web и не импортируется исполняемым API-путём.
Существующий `app.api.support_agent` читает обращения через
`app.services.support_agent_service`, но не запускает локальный пакет
`tools/support_agent`. Поэтому незавершённый R8 локальной службы не скрывается,
но и не подменяет состояние выпуска API/frontend.

Cloud Opus review не получен: сохранённый запуск завершился ошибкой 401 из-за
истёкшего OAuth access token. Секреты и вход не менялись. По прямому решению
владельца его заменило независимое Astra high ревью; отчёт сохранён в
`docs/reviews/night-candidate-astra-e7a8485.md`.

06.10.2026 в 10:10 Asia/Tbilisi на опубликованном кандидате с неизменённым
продуктовым деревом `e7a8485a08dbb4371d8d922f7832ed113c694fe1` выполнен точный
контракт:

```text

pytest -n 0 -vv tests/test_wms659_bulk_inbound_boxes.py::test_wms659_c7_same_mutation_is_concurrent_safe
```

Результат на PostgreSQL 17.10: `1 passed, 6 warnings in 17.15s`. Два
одновременных запроса с одним mutation id вернули один пакет из трёх коробов;
следующее осознанное подтверждение с новым id довело число коробов до шести.
Использовалась отдельная временная локальная база. После теста она удалена;
повторный запрос к `pg_database` вернул `ABSENT`. Базы WMS-517, WMS-662 и
production не использовались и не изменялись.

Стандартный workflow до этой правки запускал PostgreSQL только для трёх файлов
withdrawal/price snapshot/readiness, поэтому зелёный CI не был доказательством
C7. В существующий PostgreSQL-шаг добавлен отдельный запуск точного node id C7
без изменения теста, его ожиданий или продуктового кода. Итоговый коммит должен
пройти новый полный CI; результат старого SHA на него не переносится.
