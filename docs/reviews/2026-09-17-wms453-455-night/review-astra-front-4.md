## F5 — pending разрешает молча потерять отмеченную строку с пустым количеством

**Приоритет: средний. Блокирует: да.** Требования: R1/R9 и уточнение §4 о запрете молчаливой отправки неполного выбора. Оба воспроизведения используют **две позиции одного заказа**, P и Q, по 100 штук, поэтому правило одного заказа на короб не мешает действиям.

**А. Подтверждение старого запроса ошибочно закрывает изменённую форму.**

1. Отправить P = 5 с K1; сервер применяет 5, ответ теряется.
2. Оставить P = 5, отметить Q и очистить её поле количества настоящим обработчиком поля. Выбраны P и Q, значения `{P: "5", Q: ""}`.
3. «Добавить» доступна из-за pending. Оба массива `positions` и `typedPositions` содержат только P = 5: пустая отмеченная Q отброшена.
4. Повтор 5/K1 успешен; helper считает ввод неизменным. **Окно закрывается, выбор и поля очищаются; P = 5, Q = 0.** Новое намерение выбрать Q потеряно без сообщения.

**Б. После отказа старого запроса отправляется неполный новый выбор.**

1. P = 70/K1 не дошёл; другой оператор добавил P = 40.
2. Изменить P на 60, отметить Q, очистить поле Q. Выбраны две строки, новое тело содержит только P = 60.
3. «Добавить» повторяет 70/K1 и получает структурный 409 превышения остатка.
4. Проверка `positions.length === 0` не срабатывает: массив непустой. Автоматически уходит **P = 60/K2 без Q**. Итог P = 100, Q = 0; окно закрывается, весь выбор очищается, ошибка отсутствует.

Причина в `frontend/src/screens/v2/FfFbsSupplyWorkspace.tsx:1638–1640`: `typedPositions` исключает пустую отмеченную строку, хотя должен различать изменённый ввод. На `:1701–1703` pending отключает проверку полноты формы. В `frontend/src/screens/v2/fbsUx.ts:150–151` это даёт обычный успех для варианта А, а `:160–163` защищает только от полностью пустого тела, но допускает неполное тело в варианте Б. Обработчик на `FfFbsSupplyWorkspace.tsx:1060–1064` затем закрывает окно и стирает ввод.

Регресс подтверждён сравнением **настоящего выражения доступности кнопки из `c8be01ed`** на этих же состояниях: раньше `disabled=true`, сейчас `false`. Это не исходная F4 и не серверное удвоение. Разрешение повторить pending нужно сохранить, но неполный изменённый выбор нельзя считать неизменным или автоматически отправлять частично. После выяснения старого исхода форма должна сохранить этот выбор для заполнения; новых элементов не требуется. Перепроверка — оба варианта выше плюс F4/M1/M2/A/B/C.
