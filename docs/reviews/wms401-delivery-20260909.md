# WMS-401 — передача WB из Android, 09.09.2026

Статус: **ПЕРЕДАЧА ИЗ APK ПРОВЕРЕНА НА УЧЕБНОЙ ПОСТАВКЕ · ПОВТОР БЕЗ ВТОРОГО СПИСАНИЯ**.

## Что изменилось

В FbsSupplyScreen добавлена передача WB с предварительным подтверждением,
предупреждениями и перечнем отменённых заказов с коробами. Вызовы идут через
существующий FbsApi: delivery-preflight → deliver → sync-tracking. Сервер,
веб-дизайн, складской учёт, начисления и доступность трёх этапов не менялись.
Как в вебе, при недоступной предварительной проверке оператор может подтвердить
передачу без версии; окончательное решение принимает существующий сервер.

Перед отправкой сохраняются точный idempotency_key и confirmed_preflight_version
в уже существующих настройках устройства, отдельно по адресу сервера и поставке.
Потеря ответа, wb_timeout, wb_pending_confirmation и operation_in_progress сохраняют
запрос для повтора, включая повторное открытие приложения. Окончательный отказ WB
требует нового подтверждения и нового ключа. Только серверные in_delivery/done
показываются как подтверждённая передача. Повторное нажатие во время запроса
не отправляет второй запрос; поздний ответ другой поставки не подменяет текущую.
