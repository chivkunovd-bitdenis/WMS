## WMS-402 boundary

`tools/print-agent/` now contains an executable single configured CUPS-queue
transport adapter and focused tests. It validates an already-claimed BackgroundJob,
asset checksum/format, queue/copy count, does no shell execution, and treats OS
receipt only as `spooled`. Timeout/unconfirmed receipt never automatically repeats
printing. It creates no journal, model or credential.

explicit; no live invocation was attempted. Windows support, PC OS/model, remote
configuration, Android queue selection and physical 58×40 output remain unverified
or unimplemented. A new binding entity or broad staff-token workaround was not
introduced silently. Coordinator must retain this status in canon.
