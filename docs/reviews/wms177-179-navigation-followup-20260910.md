# WMS-177 / WMS-179 — сохранность ввода при навигации

Координатор дополнил существующие экраны и оболочку WMS. Data router оставляет
тот же App и дерево маршрутов; useBlocker перехватывает Back/Forward и переход
при несохранённом вводе приёмки/FBS, beforeunload — уход из страницы.
FBS открытие/закрытие сохраняет supply_id в URL, а чужой initialWorkspace
сбрасывается при выборе другого UUID. Вложенные окна добавления заказов и товаров
в короб спрашивают о потере ввода; отказ оставляет ввод, принятие очищает его.
Чат-ссылка приёмки использует фактический open_inbound. Новых экранов/редизайна нет.

Целевые TypeScript и production build прошли перед финальной проверкой seed UUID;
после этой строки выполняется повтор TypeScript.

организации: документ №000001 открывается со своим open_inbound и workspace;
ввод габарита123 → Back → Отмена сохраняет число123 и тот же URL; Back →
