# WMS-721 · исправление вкладки «Отгруженные» (дефект ручной проверки ведущего)

Исполнитель: Claude Haiku (effort xhigh) по решению владельца 09.10.2026 «разработку ведут дешёвые агенты».

**Причина.** Для вкладок поставок экран параллельно (Promise.all) грузит список поставок и список заказов; второй
нужен только для плашки «заказы видны в WB, но локальной карточки нет». Для новой группы shipped список заказов
запрашивался с status_group=shipped, бэкенд отвечал 400 invalid_status_group, Promise.all срывался, список поставок
не обновлялся — в таблице оставались строки прошлой вкладки.

**Решение — во фронте.** У «Отгруженных» нет своих статусов заказов (это этап поставки Ozon), плашка про WB на
вкладке только Ozon неуместна (решение A1 требований). Для shipped запрос заказов не отправляется — подставляется
пустой ответ, по образцу соседнего условного запроса задач сборки. Бэкенд не менялся.

**Изменено:** frontend/src/screens/v2/FfFbsOrdersScreen.tsx; новый тест
frontend/src/screens/v2/FfFbsOrdersScreen.wms721.shipped-tab.dom.test.tsx (существующий контракт wms721.dom не менялся).

**До исправления** оба новых теста падали: test_c2_shipped_tab_replaces_done_supplies_with_shipped_supply
(осталась строка «Завершённых»: expected ['supply-721-done'] to deeply equal ['supply-721-shipped']) и
test_c2_shipped_tab_sends_no_orders_worklist_request (уходил /fbs-orders/worklist?limit=500&status_group=shipped).
**После:** tsc без ошибок; vitest wms721.dom 67 + shipped-tab 2 + wms588 2 = 71/71; npm run build успешно.
Ведущий повторил: wms721.dom + shipped-tab 69/69.

**Замечание вне задачи (не исправлялось):** при любой ошибке загрузки вкладки поставок строки прошлой вкладки
не сбрасываются (catch выставляет только ошибку), и Promise.all связывает поставки с заказами для «В доставке» и
«Завершённых». Кандидат в отдельную задачу.
