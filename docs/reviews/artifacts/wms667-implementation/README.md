## Изменение

`GET /products/ff-catalog-page` принимает необязательный `has_stock`:
`true` оставляет товары с общим фактическим остатком строго больше нуля,
`false` и отсутствие параметра сохраняют прежнюю выборку. Условие включено
в существующие SQL-фильтры до `total`, сортировки, `limit` и `offset`.
Область `scope_total` и список категорий не менялись.

Сумма строк `InventoryBalance` вынесена в общий SQL-конструктор
`organization_on_hand_totals_statement` существующего сервиса остатков.
Его используют и прежний расчёт `organization_stock_totals_by_product`,
и новый фильтр: отдельного источника остатков нет. Сумма ограничена tenant,
не ограничена расположением и не вычитает резерв. Передача остатков FBS,
лимиты, связи площадок и внешние операции не изменяются.

В текущем блоке фильтров каталога добавлен штатный `FormControlLabel`
с `Checkbox` «С остатком». Обработчик одновременно устанавливает первую
страницу и состояние фильтра; запрос передаёт `has_stock=true` только при
включении. Остальные фильтры сохраняются; выбор строк очищается тем же
эффектом, который уже используется для смены фильтров.
