## Что должен реализовать разработчик

По WMS-673 передавать существующий цвет WB `product.color` и Ozon `position.color`
в оба построителя строк и общий шаблон. Добавить «Цвет» после «Размер», сохранить
группы/количества/порядок и непустой цвет группы при частично пустых данных.
Не менять тестовые ожидания ради реализации. Новый тест проверяет escape, пустую
строку, fallback мест, GET-only, блокировку/закрытие окна и повтор, доступность
общей печати WMS-610. Все исходные тесты сохранены без изменений.

В одиночном пути сейчас также отсутствует marketplace в вызове шаблона и используется
исторический WB order id. C2 требует семантику Ozon по согласованному R5; первые
утверждения на цвет блокируют достижение этих последующих утверждений на базе.
После реализации нужно проверить весь тест, а не только первое падение.

## Оставшиеся ограничения

Фактические PDF/переносы/геометрия C7, многостраничность C8, интеграция старого
контракта WMS-657 и ручной C12 не подтверждены. Размер 78px/20px, A4 landscape
и поля 10mm проверяются по настоящему HTML/CSS; jsdom не измеряет перенос строк.
Старый etalon содержит `nowrap` размера, поэтому интегрировать исправление WMS-657
отдельно, не объявлять его выполнение результатом WMS-673.

Новый `wms673PrintRenderer.ts` больше не запускает браузер. Сохранены ожидания
реальной геометрии/PDF из черновика. Они явно skipped без
`WMS673_RENDERED_ARTIFACTS_DIR`. В будущем разрешённый renderer должен предоставить
`<sha256 исходного HTML>.html`, `.pdf`, `.geometry.json`; проверка сравнивает точный
HTML, читает PDF через pdf-lib и координаты текста через pdftotext. Геометрия должна
происходить из реального рендера, а не синтетических координат. Skipped — не PASS.

Файлы `baseline-*.html/pdf` относятся к старым прерванным попыткам. Они сохранены
локально; из их наличия не делается заключение об успешном PDF-тесте. В новый
коммит входят отчёты завершённых запусков и этот документ, не старые PDF.
Полный контракт остаётся неполным до разрешённого PDF QA.
Приёмка, CI, реализация, merge и деплой не выполнены.
