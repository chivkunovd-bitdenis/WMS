## Удалённые элементы без прямого task ID

| Элемент | Причина | Bucket |
|---|---|---|
| Chip `Вручную` в строке товара | CAT-04 требует ручное создание как действие, но не требует label происхождения в строке. CAT-01 прямо запрещает chip, который не помогает и дублирует соседние данные. | Тормоз |
| Кнопка `Создать селлера` в каталоге | Создание селлера не входит в CAT-01..04; для селлеров есть отдельный раздел. | Тормоз |
| Редактирование/печать ТЗ упаковки из строки каталога | CAT-04 требует создание/Excel import, но не отдельные row-actions для ТЗ. | Тормоз |
| Габариты и checkbox `Нужен Честный знак` в ручном создании | CAT-04 про карточку каталога и Excel; CAT-03 про иконку ЧЗ в строке, не про ручное присвоение маркировки. | Тормоз |
| Колонка `Количество` и складское движение из Excel import | CAT-04 создаёт каталог товаров, не остатки; складское количество относится к другим процессам. | Тормоз |
| Поиск на основном экране каталога | В CAT-01..04 нет требования поиска по каталогу. Для 6а не оставлен как самостоятельный control. | Тормоз |
| Фильтр селлера на основном экране каталога | В CAT-01..04 нет требования фильтрации; селлер выбирается внутри ручного/Excel действия. | Тормоз |
| Кликабельная сортировка `Название` | В CAT-01..04 нет требования сортировки; заголовок оставлен plain text. | Тормоз |

## Предложения вне UI

- Отдельный поиск/фильтр по большому каталогу может понадобиться после замера реального объёма карточек, но это отдельная продуктовая задача, а не часть CAT-01..04.
- Массовое управление ТЗ упаковки из строки может быть полезным позднее, но сейчас не входит в CAT-04.

- В предыдущем live round был замечен HTML/DOM warning на странице карточки Честного знака. Это не экран каталога; фикс не делался в рамках catalog worktree.
