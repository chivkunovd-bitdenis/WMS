## Браузер

Проверка выполнена в настоящем внешнем Google Chrome, видимое окно ОС macOS, адрес `http://127.0.0.1:51831/app/ff/fbs/stock-sync`.

Способ управления: Chrome запущен через macOS `open -na "Google Chrome"` с временным профилем и `--remote-debugging-port=9223`; действия выполнялись через Chrome DevTools Protocol, подключенный к видимой внешней вкладке. Это не headless и не Playwright webServer acceptance. API использовался только для подготовки фикстур: селлеры, WB Marketplace token, физический WMS-склад.

Локальный стенд:

- UI: `http://127.0.0.1:51831`
- API: `http://127.0.0.1:18131`
- WB-склады: e2e mock `E2E Seller Warehouse`, `WB ID 501001`, город `Moscow`

## Что пройдено

- UI-регистрация FF-админа в видимом Chrome.
- Состояние ошибки/пустоты: селлер без WB Marketplace token и без WMS-склада показывает человеческую ошибку `Нет токена WB Marketplace` и предупреждение `Создайте WMS-склад перед сопоставлением складов WB`.
- FBS-13 success: WB-склад селлера загрузился строкой с названием, городом, адресом и WB ID.
- INFRA-01: до физического WMS-склада публикация недоступна; старый технический FBS-склад не создавался и не выбирался пользователем.
- Сопоставление WB-склада с физическим WMS-складом сохраняется и после read-back показывает `готов к публикации`.
- Публикация включается явно и после reload/read-back остаётся `публикация включена`.
- Действие синхронизации после fix показывает `Синхронизация: складов 1, товаров 0, подтверждено 0, ошибок 0`; внутреннего id job/`задача ...` в UI нет.
- Панель статуса открывается, показывает `Статус сопоставления: Подтверждено` и пустое состояние `Нет позиций синхронизации`.
- Отключение сопоставления требует подтверждения и после read-back возвращает строку в `склад не сопоставлен`.
- Дополнительная визуальная проверка 1280px viewport: основной функциональный сценарий проходит, но таблица шире видимой области; правые колонки и действия требуют горизонтального scroll. Это не блокирует операцию, но нарушает требование GLOBAL-02 про нормальную работу на 1280 px.
