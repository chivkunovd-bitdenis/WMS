## Что пройдено в live Chrome

- UI-регистрация FF-админа в видимом Chrome.
- No-token/no-WMS: селлер без WB Marketplace token и без WMS-склада показывает `Нет токена WB Marketplace` и `Создайте WMS-склад перед сопоставлением складов WB`.
- FBS-13 success: WB-склад селлера загружен строкой с названием, WB ID, городом, адресом и статусом `активен в WB`.
- INFRA-01: сопоставление идёт только с физическим WMS-складом, технический FBS-склад пользователю не показывался.
- Row/mapping: WB-склад сопоставлен с WMS-складом, read-back показывает `готов к публикации`.
- Toggle: публикация включается явно и после reload/read-back остаётся `публикация включена`.
- Sync feedback: действие синхронизации показывает `Синхронизация: складов 1, товаров 0, подтверждено 0, ошибок 0`; технического id job в UI нет.
- Status dialog: открывается `Статус синхронизации — WB 501001`, показывает `Подтверждено` и empty-state `Нет позиций синхронизации`.
- Disable/reload: подтверждение отключения работает, после read-back строка возвращается в `склад не сопоставлен`.
- 1280px: документ, таблица и действия помещаются без горизонтальной прокрутки.
