# Уточнение владельца: допустимый тест Ozon

06.10.2026 владелец сначала оставил реальный C19 до релиза и попросил разрешённый
тестовый объект. На последующий вопрос о конкретном объекте ответил:

> Если тебе это поможет, ты можешь у Виталика, у AVPAC точнее, создать тестовую поставку пустую, не используя никакие заказы, просто пустую, и посмотреть, что с ней будет. Если же тебе пустая поставка не нужна, то ничего мы создавать сейчас на проде не будем и проверим уже с оператором.

Это разрешение только на полезный тест пустой поставки AVPAC без заказов.
Оно не разрешает использовать рабочие заказы, отправлять их документы,
производить отгрузку, списание или вывод КИЗ.

Root прочитал `ozon_exemplar_documents_service.py` в ветке WMS-663:
`document_order` требует существующий FbsOrder и его external_order_id;
внешний create-or-get принимает posting_number, выбор относится к product_id
и exemplar_id. C19 проверяет set/status конкретного заказа и экземпляров.
Пустая поставка без заказов не воспроизводит этот сценарий. Поэтому Root ничего
на production не создавал. По условию владельца реальный сценарий остаётся
для проверки с оператором; это не PASS и не автоматическое разрешение отгрузки.

Ответ не задаёт явно дату операторской проверки относительно выпуска.
Не переименовывать его молча в отказ от всех прежних release-gates.
Аналитику WMS-663 передать это уточнение для точного обновления статуса C19;
не запускать бессмысленное создание пустой поставки и не запрашивать повторно
тот же объект, игнорируя ответ владельца.
