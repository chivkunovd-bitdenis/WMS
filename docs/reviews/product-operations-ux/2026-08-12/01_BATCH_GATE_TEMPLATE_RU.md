# Gate завершения продуктового батча

Батч не закрывается, пока для каждого пункта нельзя ответить «да» либо поставить явный `BLOCKED/NOT_RUN` с причиной.

- Все роли и физические задачи батча перечислены.
- Все routes, вкладки, dialogs, CTA, row actions и error states внесены в ledger.
- У каждой выполненной строки есть screenshot до/после; у сохраняющего действия есть reload/read-back.
- Эксперт лично открыл каждый screenshot и описал, что действительно видно.
- Empty state не использован как доказательство populated workflow.
- Проверены очевидность следующего шага, терминология, число решений и ручных действий.
- Проверены duplicate click/scan, reload, ошибка и recovery либо объяснено, почему это неприменимо.
- Проверено, где физически находится товар/короб до и после шага.
- Проверено, что следующая роль получает достаточный и понятный результат.
- Каждый finding содержит минимальное исправление без оверинжиниринга.
- Все неподтверждённые гипотезы отделены от findings.
- Handoff сохраняет только подтверждённые состояния, открытые связи и нужные fixtures следующего батча.

Результат gate: `ACCEPTED`, `RETURN_FOR_COVERAGE` или `BLOCKED_FIXTURE`.
