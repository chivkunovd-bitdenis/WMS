Класс всех шести случаев — **навсегда**. Каждый сценарий параметризован наружной
табуляцией и NBSP (неразрывным пробелом U+00A0):

- Категория: настоящие поля ответа очищены; три страницы по одной строке совпадают
  с полной выдачей, total=3 и /keys содержит все уникальные ключи. Равная видимая
  категория должна образовывать непрерывную группу. Нового порядка алфавитов нет.
- Импортированная карточка: числовой `techSize=148` не является размером; строковый
  `wbSize` с наружными символами отображается как 48 и обязан выбираться фильтром
  48 до count/limit/offset. Отдельные обычные 48 и строковый 148 служат контролем.
- WMS-товар: пустые wb_size/wb_barcode, собственный ProductBarcode(source="wb")
  выбирает вариант 48; чужой вариант со строковым 148 не попадает в фильтр.

HTTP идёт внутри процесса через настоящий ASGITransport (транспорт тестового
приложения), авторизацию, маршруты и реальный сервис/SQL. Сервисы, обогащение,
ответы и бизнес-логика не подменяются. Фикстура содержит только собственные
детерминированные tenant/seller/user, карточки и один товар со штрихкодом.
