## Границы браузерной проверки — честно

**Я не нажимал ни одной кнопки в браузере.** Инструмента управления браузером
в этой сессии нет, а зелёные тесты и ответы API интерфейсом не считаются.
Ранее координатор вручную прошёл ровно один сценарий — «поставка FBS →
компактная форма → полный чат → клик по карточке возвращает ту же поставку»
(`wms179-397-live-followup-20260910.md`). Всё остальное ниже — **не проверено
руками**.

Изолированный синтетический стенд для этого уже лежит в репозитории, новый
строить не нужно: `backend/scripts/wms397_chat_fixture.py` поднимает отдельную
базу и сервер на `127.0.0.1:8397`, заводит учебного тенанта, склад, товар и по
одному документу каждого вида, печатая их идентификаторы в JSON. Учётки в нём
синтетические, три роли (админ ФФ, селлер, сотрудник); пароль задан в самом
скрипте, здесь он намеренно не приводится. Ни одной живой учётной записи,
реального получателя и складского движения задействовать не нужно.

Что осталось прокликать:

1. **Приёмка, ссылка карточки.** Из документа приёмки открыть компактную форму,
   отправить текст. В полном чате нажать карточку — адрес должен стать
   `/app/ff/reception?open_inbound=<id>`, и должен открыться **тот самый**
   документ. Это единственное место, где сегодня менялся контракт ссылки.
2. **Отгрузка на маркетплейс и отгрузка со склада.** Те же два шага; адреса —
   `/app/ff/mp-shipments?open_mp=<id>` и `?open_outbound=<id>`.
3. **Точный заказ FBS.** Карточка ведёт на `/app/ff/fbs?order_id=…&seller_id=…`;
   в таблице должна остаться одна строка нужного заказа с рамкой и плашкой
   «Заказ из сообщения», а «Снять фильтр» и переключение вкладки — вернуть
   обычный список.
4. **Прокрутка ленты (сегодняшняя правка).** Открыть чат, где больше экрана
   сообщений: должно быть видно последнее. Отправить сообщение — оно видно без
   прокрутки. Прокрутить вверх, нажать «Предыдущие сообщения» — не должно
   бросать вниз.
5. **Вставка изображения.** Cmd+V/Ctrl+V **при курсоре в поле сообщения** —
   картинка встаёт превью и после отправки показывается изображением, а не
   ссылкой. Вставка при фокусе вне поля ввода не поддерживается — это
   осознанная граница, не дефект.
6. **Файлы и восстановление черновиков.** Прикрепить обычный файл, отправить,
   скачать у второго участника. Загрузить файл и не отправлять, перезагрузить
   страницу — он должен предлагаться в «Ваших неотправленных вложениях» с
   «Прикрепить» и «Удалить файл».
7. **Редактирование.** «Изменить» появляется только у своих сообщений; после
   сохранения появляется пометка «изменено».
8. **Дополнительный чат.** Админ ФФ создаёт чат, добавляет существующего
   сотрудника; посторонний сотрудник этого чата не видит, основной чат селлера
   остаётся на месте.

уже отправленных сообщений — по-прежнему вне контура этой задачи.
