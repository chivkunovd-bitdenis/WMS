# WMS-681: восстановление QR существующих коробов «Империи ФФ»

## Разрешение и границы

06.10.2026 владелец прямо поручил срочно руками запросить короба на проде,
чтобы QR распечатались, и исправить системную причину. Выполнена только операция
над пятью существующими коробами поставки WB-GI-288882803 (локальный ID
17141e9c-7f52-435c-887a-64efccb0760b), tenant
7b98a8aa-c03c-4649-9677-a645be45c622, seller
d1f26146-e99a-41af-9471-9c80ec990db3. Отгрузка, списание, физическая печать,
управление ключами, Telegram-сообщения не выполнялись.

## Что было установлено

Серверный checkout 8f11d912351e8de7633b4abcf74d195badaeb254 содержит WMS-681 и
WMS-683. SHA256 fbs_packing_box_service.py в работающем API и checkout совпал:
2ab55a6905bebeee37d9d3b17af3a6d0bfcd6a90fb7224f74d37681fc70adb7b.
В работающем web bundle присутствует диагностическая строка hotfix WMS-681.

Через штатный scoped SQL gateway установлены пять локальных коробов с временем
создания 07:54:34 UTC и пустыми trbx_id. Исходный cargo_places_create завершился
failed / wb_upstream_error_404. Supply-from-orders остался pending_confirmation /
wb_timeout; его состояние этим восстановлением не исправлялось.

Свежий WB GET непосредственно перед мутацией вернул пустой список грузомест.
Это не доказывает причину исходной 404. Соседние поставки этого селлера имеют
настоящие связанные грузоместа; утверждать общий отказ WB нельзя.

## Безопасное выполнение

[Скрипт](artifacts/wms-681/owner_recover_imperia_boxes.py) сохранён и опубликован
до выполнения: b73ce1d02. Отдельная Astra high проверила скрипт и установленный
путь сервиса по исходникам f7b1ae2c6: Safety PASS для одного контролируемого apply.
Это операционная проверка безопасности, не приёмка системного исправления.

Использован штатный create_boxes с исходным ключом создания, исходным actor и
режимом. Сервис повторно использовал существующие пять локальных коробов,
создал пять грузомест WB и получил их PNG. Новых локальных коробов не добавлено.
При неизвестном результате запрещены новый ключ и слепое повторное создание.

## Системная работа остаётся

Hotfix убрал ложную подмену WB QR внутренним FBS QR, но экран не восстанавливает
старые коробки после отказа и массовая печать не запрашивает отсутствующие
этикетки. Отдельный Sol-аналитик ведёт минимальное продолжение WMS-681 в
codex/wms681-qr-recovery; тесты до кода, независимое ревью и проверки обязательны.
Операционное восстановление не является выпуском системного исправления или
ночного пакета.
