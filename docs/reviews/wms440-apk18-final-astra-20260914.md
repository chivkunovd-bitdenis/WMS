## Код и границы

`UpdateInstaller.verify` получает PackageInfo, требует распознанный archive и applicationInfo; преобразует null signatures через `orEmpty()`, после чего вызывает общую `verifyIdentity`. Обязательная информация пакета/версии/minSdk не подменяется отсутствием подписи. Если PackageManager/метаданные дают исключение, оно не превращается в разрешение установить файл.

В `verifyIdentity` сначала проверяются package, точный manifest version и увеличение установленной версии, точный minSdk и поддержка текущим Android. На API24–27 два непустых signer-набора сравниваются и известное несовпадение отклоняется. Если один/оба набора пусты, только эта проверка передаётся ОС. На API28+ оба набора обязаны быть непустыми и одинаковыми. Нового общего разрешающего catch-all нет.

Прослежен фактический путь вызовов: `saveApk` проверяет полноту/размер/SHA до переименования `.part`; `UpdateRepository.verify` ещё раз проверяет файл/размер/SHA и вызывает `UpdateInstaller.verify`; `prepareInstall` повторяет verify перед каждым запуском; ошибка очищает installable state и не вызывает callback. Единственный конечный путь — `ACTION_INSTALL_PACKAGE` с FileProvider из cache/updates, read permission и `EXTRA_RETURN_RESULT`. Приложение не выключает системную проверку подписи и не выполняет unattended install. Отмена/не-RESULT_OK отображаются существующим сообщением «Установка не завершена»; сам возврат из installer не называется успешным обновлением.

От ранее принятого15 изменены только build/signing-конфигурация, узкая функция updater и её тесты. AuthStore, миграция профиля, складская логика, UI/навигация и хранение очереди не изменены. Release signing задаётся только существующей явной env-конфигурацией; выдаваемый **debug APK18** фактически имеет нужный прежний e343 сертификат. Чужие signer16/17 не являются кандидатом к этому допуску. Ни private key, ни кабинеты, ни секретные настройки ревьюером не использовались/не менялись.

**Заключение:** к выдаче допущен только перечисленный APK18/e343/SHA7306…21eddf, для прямого системного обновления поверх11.
