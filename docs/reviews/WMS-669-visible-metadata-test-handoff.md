## Что зафиксировано до исправления

`backend/tests/test_wms669_visible_metadata_regression.py` использует существующую
фикстуру `catalog`, реальную авторизацию, HTTP-маршруты `/seller-catalog/page`
и `/seller-catalog/keys`, настоящий SQL и существующее обогащение карточек.
Сервисы и результаты API не подменены. Собственная SQLite стандартного conftest,
один worker; внешние базы и сервисы не используются.

- R5/R6, F1: две проверки категории — наружные пробелы в `subjectName` и запасное
  поле `subject_name`. Подписи взяты из реальных полей `category` ответа, которыми
  пользуются заголовки экрана. Проверяются непрерывность равных категорий, ключи,
  total и совпадение полной выдачи с тремя страницами по одной строке.
- R2/R4/R6, F2: числовой `techSize=148`, строковый `wbSize=" 48 "`, рядом настоящие
  строковые размеры 148 и 48. Проверяются показанные `sizes`, точные фильтры обеих
  величин, total, page/keys. Дополнительно зафиксированы непрерывность показанных
  наборов размеров и стабильность страниц; в RED исполнение до этих последних
  утверждений не дошло из-за более раннего падения фильтра.
- R2/R6, F2: товар с пустым собственным размером и штрихкодом из существующего
  `ProductBarcode(source="wb")`. Два варианта карточки с кодами `review-code-148`
  и `review-code-48`; у своего варианта числовой techSize и строковый wbSize 48.
  Показанный `wb_size` равен 48. Фильтр обязан выбирать именно его, без
  совпадения по подстроке и без чужого варианта 148.
- R6/R9, контроль: `sizes` строкой/объектом, массив с null/строкой/числом и
  допустимым объектом. Неизвестные строки сохраняются без фильтра, допустимый
  размер находится точно. Существующая импортированная карточка Ozon сохраняет
  offer id, пустую категорию/размер, не получает размер из названия.

Четыре функции, пять исполняемых случаев из-за двух вариантов F1. Нового порядка
букв/цифр не задано: проверяется непрерывность равных показанных групп. Это
HTTP-регрессия метаданных, не DOM-прогон и не визуальная приёмка C11.
Старые замороженные тесты, фикстуры, требования и продуктовый код не менялись.
