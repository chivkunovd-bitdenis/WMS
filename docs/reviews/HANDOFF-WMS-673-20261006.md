# WMS-673 · Передача от аналитика тестировщику и разработчику

Контракт: [WMS-673](../requirements/WMS-673.md), версия 1 от 06.10.2026. База — свежий etalon `0f1460b023700a99f17b504d6af3934a02bc68cc`, аналитическая ветка `codex/wms672-673-analyst-20261006`. Прочитать AGENTS.md. Владелец прямо исключил навыки и назначил новые роли Sol 6.1; независимое ревью — отдельный Astra high. Не создавать новый номер/карточку и не возвращать цвет в узкий контракт WMS-657.

Тестировщику: отдельный коммит `WMS-673: контракт тестов` до продукта, ссылки на C1–C7/C9–C11, воспроизводимый отказ исходного etalon из-за отсутствующей колонки/данных. Не ограничиваться unit-тестом вручную заполненного HTML. Контракт проходит реальную кнопку/fixture и оба строителя строк (`fbsBuildPickingRows`, `fbsAssemblyPickingRows`): WB, Ozon с несколькими разноцветными позициями, общая сборка, отсутствующее значение и безопасное экранирование. Числа/порядок/идентификаторы сравнивать с прежними на том же fixture. PDF и проверка ячеек нужны для длинного цвета одновременно с «Универсальный»; C8/C12 — честные ручные проверки.

Разработчику: цвет уже есть в API product.color/position.color. Передать данные через оба строителя в общий `FbsPickingListPrintRow` и шаблон `buildFbsPickingListPrintHtml`; для позиции Ozon нельзя копировать корневой цвет первой позиции. Использовать точный существующий товар/группу, пустое поле показывать `—`, без дополнительного marketplace-вызова. Обычное решение — компактная колонка после «Размер»; экранные таблицы не менять.

Важная интеграционная разница: кандидат `23c65f86d` содержит WMS-657, удаляющую nowrap размера. Etalon его не содержит. Сохранить ширину размера 78 px/шрифт 20 px и перенос, не менять/ослаблять контрактные ожидания WMS-657. Добавление цвета явно разрешено только WMS-673; геометрия новых 11 колонок проверяется реальным A4 landscape/PDF. WMS-610 регулирует экранные количественные колонки и доступность общей печати, а печатный лист сохраняет свои «Взять / Подобрано».

После локальных проверок/сборки и перекрёстного ревью вернуть тому же аналитику для C1–C12, затем полный CI точного SHA. Исходные реплики 629–632 сохранены дословно; существование колонки «вчера» не доказано. Baseline браузера и фото клиента не просмотрены; будущая браузерная проверка обязательна.
