# WMS-483 · перекрёстное ревью фронта, проход 3

**Вердикт: FAIL.** После коммита `8eef8996` reviewer Astra high проверил исправление пересечения числовых номеров WB и Ozon. Остался случай неактивной привязки WB: её номер присутствует в каталоге WB с `wms_warehouse_id`, а активная привязка Ozon имеет тот же числовой номер. Текущая квалификация ключей принимает каталог WB за источник активных WB-привязок и ошибочно переписывает существующее значение Ozon `"123": 5` в `"wb:123": 5`. Затем сохранение `0` для другого WB-склада может завершиться `warehouse_not_found`.

Нужно брать множество номеров активных WB-привязок из сохранённых `/warehouse-bindings` по всем площадкам, не отфильтровывая только обслуживаемые склады; повторить проверку коллизии и сценария неактивного WB. Замечание передано тому же исполнителю Opus. Финальный вердикт требует повторного ревью исправленного коммита.
