# WMS-443 · реализация web и ТСД

## Изменения

Web использует основной вход `POST /auth/login-by-name` с ФИО и паролем. На той же форме есть компактный переходный путь через совместимый `POST /auth/login` для старой учётной записи. Шапки, карточки сотрудников, тарифы, упаковка и журналы ЧЗ выводят `display_name` или новые поля автора `*_name`; контактные email селлеров не менялись.

В существующих настройках ФФ и селлера добавлены редактирование собственного профиля через `PATCH /auth/me`, создание сотрудника с ФИО, необязательной должностью и паролем, а также правка ФИО/должности в строке соответствующего сотрудника. Роль и права остаются самостоятельными существующими полями. В шапках обоих порталов должность показана отдельной частью между ФИО и ролью.

ТСД использует те же новый и переходный входы. После токена он обязательно читает профиль; при ошибке профиль не создаёт сессию. Новый PIN-ключ включает нормализованный адрес сервера, `organization_slug` и `user_id`; перед PIN-входом профиль читается повторно, поэтому устаревшая или недоступная учётная запись не открывает сессию. Старые локальные PIN-записи сохранены зашифрованно, но не выводятся как имя до переходного входа, который подтвердит ФИО. На Home и в выборе сотрудника показаны подтверждённые ФИО и должность. Изменения Android сохранены отдельными commits `76babe2559d0e4603c690cbaebe9f36f291c9594` и `bfcc65b4ff3bb5cd203e60727ab16625627a4269`; переносимый исходный diff находится в `docs/reviews/artifacts/wms443/mobile.patch`.

## Проверки исполнителя

- `frontend`: `npx tsc --noEmit -p tsconfig.app.json` — успешно.
- `frontend`: `npm run build` — успешно.
- `git diff --check` для web и Android — успешно.
- На изолированном Playwright-контексте локального Vite 5205 выполнен вход по ФИО тестового сотрудника: существующая шапка ФФ отрисовала ФИО, должность и роль отдельными частями. У этой учётной записи нет прав seller-портала; переход туда корректно потребовал отдельный seller-вход. Seller-разметка передаёт ту же `job_title`, а legacy администратор остаётся переходным пользователем без должности.
- `:app:testDebugUnitTest --tests 'ru.wms.tsd.core.auth.*'`, `:app:assembleDebug` и `:app:lintDebug` — успешно с `--max-workers=2`, `-Xmx1200m` и Kotlin in-process. Lint: 0 ошибок, существующие предупреждения.
- Debug APK установлен в `emulator-5580`. На нём проверены переходный парольный вход, установка PIN, перезапуск и PIN-вход с повторным чтением профиля. Перед исправлением старые записи показывали исторические значения; после него открывается форма ФИО/пароля без email-плиток.

Это не заключение независимого ревью и не приёмка аналитика.
