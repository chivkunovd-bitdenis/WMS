## C18: найдено нарушение узкой геометрии

Синтетические данные ровно **2 SKU / 3 единицы (2+1)**, длинное имя >100 символов,
номера >60 символов с начальными нулями и разделителями. Продуктовая версия
**1fd2d92dc30eb376c1d8a8e27238e52d963a196e**: workflow доказал отсутствие diff
backend/app и frontend/src продукта; frozen тест исключён отдельно как оснастка.

На 1280 px проверенные поля/галки не перекрываются, контекст Ozon и действия
присутствуют — локальный предмет C18 **PASS**. На **390 px — FAIL**:
контейнер документов шириной 0px, контейнеры всех трёх полей 0px, input 28px;
подписи галок обрезаются, длинное имя переносится по одному символу.
Это воспроизводимое нарушение читаемости, не вывод из jsdom.
