# WMS-351 / WMS-357 / WMS-043 / WMS-396: объединение production и staging

`codex/wms-prod-stage-integrate` объединяет кандидат staging
`c4b54a41160ec31f0b083cd6cb8ca4bb0d3d448f` и уже выпущенную ветку production
`b4dc80f1fe7d3f245aa37f7046bac83dbd4a8cc5`. Корневая рабочая копия не менялась.
Источники: обе Git-ветки и существующие отчёты production для WMS-351, 357 и 043.
Это интеграция существующих исправлений, не подтверждение новой выкладки.

Разрешены 14 конфликтующих файлов. Сохранена совокупность поведения:

- Независимые переключатели WB/Ozon, их блокировки на время публикации,
  сохранение нетронутой галки каждого товара и адресный финальный ноль из production.
  От staging сохранено отделение обслуживания склада от публикации, одноразовый
  ноль по ранее подтверждённому положительному остатку и запрет обнулять чужие
  значения. Очистка учитывает одновременно выбранные товары и прежнюю успешную
  публикацию. Публикация выключенной площадки отсутствует в обычном payload.
- Упаковка остаётся фактом без складской конвертации для всех уже исправленных
  staging-процессов. Production-проверка старой packed-части для обычного задания
  не возвращена. Физический остаток и тара используются при передаче Ozon;
  оба разных теста выбора источника из веток сохранены.
- Сохранены WB-подтверждение неопределённого запроса, ключи повторного выполнения
  и узкий допуск внешнего физического кода из приёмки WMS-396. Из production
  добавлены фактический статус Ozon, несколько экземпляров ЧЗ, корректный поиск
  позиции и повторное чтение результата проверки.
- Экран сохраняет честные статусы WB из staging и несколько кодов Ozon из
  production. Отказ любого Ozon-кода имеет приоритет, неполное подтверждение
  не окрашивает заказ зелёным. Сохранены кнопка чтения ЧЗ, прокрутка к скану,
  список отменённых после упаковки заказов и обе добавленные функции API.
- Канонический бэклог взят из staging: все его номера сохранены, WMS-392/393
  не переименованы и не переиспользованы, WMS-396 сохранён. Для WMS-351/357
  перенесены сведения существующего production, WMS-043 дополнен его выпуском.
