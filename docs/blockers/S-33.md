# Блокировки · S-33

## Блокировки

### Выгрузка CSV при пустом срезе

**Что блокируется:** скачать отчёт, когда в текущем срезе нет строк.

**Каким условием:** в `frontend/src/screens/ff/FfReportsPage.tsx` у `PrimaryAction`
«Скачать CSV» задаётся `disabledReason`, когда `rows.length === 0`; серверная ручка
`/reports/inventory/export.csv` применяет тот же срез.

**Где живёт проверка:** экран; сервер является источником CSV и не подменяет файл HTML-выгрузкой.

**Что видит оператор:** действие недоступно, с объяснением «За выбранный период нечего выгружать».

**Как разблокировать:** изменить период или снять фильтры, чтобы в таблице появилась хотя бы одна строка.

**Зачем бизнесово:** контракт S-33 прямо запрещает пустую выгрузку, чтобы оператор не принял пустой файл за корректный отчёт.

### Период длиннее 366 дней

**Что блокируется:** загрузить сводку, таблицу или CSV для интервала больше 366 календарных дней.

**Каким условием:** в `frontend/src/screens/ff/FfReportsPage.tsx` вычисляется длина пользовательского периода; при значении больше 366 задаётся ошибка «Период не может быть длиннее 366 дней», а запросы не отправляются.

**Где живёт проверка:** экран; сервер также валидирует входной интервал.

**Что видит оператор:** ошибка «Период не может быть длиннее 366 дней» и недоступная выгрузка.

**Как разблокировать:** выбрать период длиной до 366 календарных дней.

**Зачем бизнесово:** контракт S-33 ограничивает срез годом, чтобы отчёт оставался предсказуемым по времени ожидания и объёму данных.
