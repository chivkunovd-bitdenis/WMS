# Блокировки · S-31

## Блокировки

### B-31-01 · Выпуск счёта ждёт покрывающий тариф

**Что блокируется.** Формирование месячного счёта для селлера.

**Каким условием.** В журнале есть строка без суммы (`unpriced`).

**Где живёт проверка.** Сервер: `billing_invoice_service.form_invoice`; экран получает
причину `unpriced` через API списка счетов.

**Что видит оператор.** «Нет тарифа» и действие «Открыть тарифы».

**Как разблокировать.** Добавить версию ставки, покрывающую дату операции; повторить
формирование тем же алгоритмом.

**Зачем бизнесово.** Нельзя выпускать неизменяемый коммерческий счёт с неизвестной ценой.

### B-31-02 · Выпуск счёта ждёт реквизиты ФФ

**Что блокируется.** Формирование месячного счёта для селлера.

**Каким условием.** Нет профиля реквизитов ФФ либо в нём не заполнено одно из обязательных
полей: юридическое наименование, ИНН, название банка, БИК, расчётный или корреспондентский
счёт (`missing_ff_profile`).

**Где живёт проверка.** Сервер: `billing_invoice_service.form_invoice` проверяет профиль
ФФ перед созданием неизменяемого счёта; API возвращает причину `missing_ff_profile` в
результате формирования и в списке проблем периода.

**Что видит оператор.** «Нет реквизитов ФФ» и действие, открывающее
`/app/ff/settings?tab=tariffs` с реквизитами ФФ.

**Как разблокировать.** Заполнить обязательные реквизиты ФФ на вкладке «Тарифы ФФ», затем
повторить формирование.

**Зачем бизнесово.** Снимок реквизитов исполнителя является обязательной частью
неизменяемого коммерческого счёта.

### B-31-03 · Выпуск счёта ждёт реквизиты плательщика-селлера

**Что блокируется.** Формирование месячного счёта для селлера.

**Каким условием.** Нет профиля плательщика-селлера либо в нём не заполнены юридическое
наименование или ИНН (`missing_seller_profile`).

**Где живёт проверка.** Сервер: `billing_invoice_service.form_invoice` проверяет профиль
селлера перед созданием неизменяемого счёта; API возвращает причину
`missing_seller_profile` в результате формирования и в списке проблем периода.

**Что видит оператор.** «Нет реквизитов селлера» и действие, открывающее диалог нужного
селлера с блоком «Реквизиты для счетов».

**Как разблокировать.** Заполнить юридическое наименование и ИНН плательщика в карточке
этого селлера, затем повторить формирование.

**Зачем бизнесово.** Снимок реквизитов плательщика является обязательной частью
неизменяемого коммерческого счёта.

### B-31-04 · Выпуск счёта ждёт закрытие хранения

**Что блокируется.** Формирование месячного счёта при действующем тарифе хранения.

**Каким условием.** В периоде нет опубликованных `storage_measurement` из зафиксированного
`StorageStatement` (`storage_period_not_closed`).

**Где живёт проверка.** Сервер: `billing_invoice_service.form_invoice`; карточка 08
публикует финальные строки ledger только после фиксации statement.

**Что видит оператор.** «Хранение не закрыто» и действие «Открыть хранение».

**Как разблокировать.** Зафиксировать StorageStatement по каждому операционному складу,
включая нулевой, затем повторить формирование.

**Зачем бизнесово.** Один неизменяемый счёт должен содержать и операционные услуги, и
хранение за тот же месяц.

## Без обоснования

Нет.

## Разошлись слои

API списка счетов возвращает проблемы отдельным массивом `issues`; экран должен показывать
этот массив над таблицей без создания фиктивного счёта.

## Отсеяно

Отмена счёта не является блокировкой: это окончательный переход `issued → cancelled`,
повторная отмена идемпотентна.
