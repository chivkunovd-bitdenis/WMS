## Gates, resume, artifacts, Git, missing safeguards

Runner applies each step’s policy: `fail` terminally fails, `continue` records advisory failure, `skip_remaining` stops but resolves outcomes only from present artifacts; this prevents skipped side-effecting steps faking success ([L266–344](https://github.com/aws-samples/sample-autonomous-cloud-coding-agents/blob/2cee8800c26ac33cfc3acd782be0da61727b548f/agent/src/workflow/runner.py#L266-L344)). Resume skips only verification steps, whereas clone/agent/PR/delivery rerun ([L181–196](https://github.com/aws-samples/sample-autonomous-cloud-coding-agents/blob/2cee8800c26ac33cfc3acd782be0da61727b548f/agent/src/workflow/runner.py#L181-L196)). `ensure_pr` requires clone and explicit strategy ([L577–612](https://github.com/aws-samples/sample-autonomous-cloud-coding-agents/blob/2cee8800c26ac33cfc3acd782be0da61727b548f/agent/src/workflow/runner.py#L577-L612)).
