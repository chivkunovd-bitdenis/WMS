# WMS-399 — финальная сверка исходного brief

Это дополнение к browser feedback, а не новый объём продукта. Прочитай
OPUS_BRIEF.md раздел requirements/concrete deliverables и своё REQUIREMENTS.
Координатор нашёл следующие несоответствия именно исходному заданию:

- Search UI в браузере имеет query/seller/attachment/document, но нет фильтра
  даты из исходного brief. Добавь минимум date-from/date-to, обеспечь работу
  фильтров на seed; свои дополнительные фильтры REQUIREMENTS §8 либо реализуй
  в макете, либо ясно пометь как будущий контракт, не утверждай, что они уже есть.
- Deleted-document написан в требованиях/handoff, но в демо нет переключателя,
  seed-документы не удалены. Сделай состояние доступным обычным UI/демо
  без ручной правки состояния через консоль.
- New-chat/empty-conversation/loading обязательны в brief. Инбокс с фильтром
  без результатов проверен, но пустой новый канал и загрузка списка/ленты
  из UI пока не найдены. Дай демонстрируемый путь и точно опиши его, используя
  локальные view-модели, существующие права и данные без backend.
- index.html всё ещё грузит Inter из fonts.googleapis.com/gstatic. Brief
  explicitly запрещает remote assets. Убери внешние font links, оставь
  локальный системный font stack с сохранением композиции. Не скачивай шрифты.

Админское приглашение в ParticipantsDrawer проверено: кнопка показывает
честное сообщение-заглушку. Не нужно реализовывать backend, но опиши это
как ограничение в handoff вместо общего утверждения, что все действия реальны.
Настоящий browser Notification permission запрос координатор не активировал;
если обязательный denied-state не доступен без изменения разрешений браузера,
добавь безопасную локальную демонстрацию состояний push без системного запроса.

Сохраняй свой дизайн. Все React правки — только ты, Claude Opus. Codex только
сборка/браузер/документация доказательств/Git. Bash/build/browser/git/network/
секреты/история/установки по-прежнему недоступны модели. Не меняй evidence
координатора. После прохода перечисли точные UI пути для проверки.
