# PSP-2 — кликабельный макет (WMS-490, 491, 497, 547, 548, 549)

Одноразовая ветка `mockup/psp2-clickable`: etalon + ветки задач пакета, сведённые
как есть на 27.09.2026. В etalon не идёт.

Макет — это настоящие `App` (кабинет фулфилмента) и `SellerApp` (кабинет селлера)
с настоящей темой и меню. Сервера нет: глобальный `fetch` подменён
`frontend/src/mockups/psp2/server.ts`, данные — `frontend/src/mockups/psp2/fixtures.ts`
(выдуманные, согласованные, меняются в памяти при сохранении). Полоса сверху
переключает кабинет — только макет. Печать (лист инвентаризации, счёт)
показывается окном предпросмотра вместо системной печати.

Сборка (статическая, относительные пути):

```bash
cd frontend
npx vite build --config vite.psp2-mockup.config.ts   # → dist-psp2-mockup/psp2-mockup.html + assets
```

В этой сборке иллюстрации базы знаний заменены пустой картинкой, а логотип
портала берётся по относительному пути (см. `vite.psp2-mockup.config.ts`);
продуктовый код не менялся.
