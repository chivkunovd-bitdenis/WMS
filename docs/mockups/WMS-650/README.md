# WMS-650 · макет «Раскладка по ячейкам» после приёмки

Кликабельный макет в React. Это не продукт: данные выдуманные (из objectsStub.ts), сервера нет,
всё состояние живёт в памяти страницы. Продуктовые файлы не менялись.

## Как запустить

    cd frontend && npx vite --port 5650

Страница: http://localhost:5650/wms650-mockup.html. Сервер не нужен.

Рендерится вариант настоящего экрана раскладки на настоящих компонентах и теме продукта
(ScreenHeader, ScannerField, DataTable, IconAction, StatusChip, QtyCell, AppDialog, muiTheme и др.).
Своей HTML/CSS-копии экрана нет.

## Что в макете

Файлы: frontend/src/mockups/wms650.tsx (точка входа и тёмная лента «ЭТО НЕ ЭКРАН»),
wms650Screen.tsx (вариант экрана), wms650Placed.tsx (список размещённого по ячейкам),
wms650Tree.tsx (копия ObjectsTree продукта, отличие одно: подсветка строки задаётся ключом).

- Основной список слева — только неразложенное. Поставленное из него уходит. Над списком
  счётчик «N штук осталось поставить из M принятых — K объектов и L позиций россыпью» и полоса прогресса.
- Справа в панели «Ячейки склада» каждая ячейка — заголовок группы, под ним то, что на ней стоит
  (как в разделе «Ячейки»). В шапке панели: «размещено N шт». Короб, палета, грузоместо на ячейке
  свёрнуты в одну строку; открытая сканом тара раскрыта. У строки на ячейке — «снять с ячейки»
  (минус), у вложенного — «вынуть из короба/палеты». Плюса здесь нет.
- Рядом с полем сканера — стрелка «назад» (значок и подсказка как у «Отменить последний скан»
  в упаковке FBS). Подсказка называет, что именно отменится. Отменяет последнее изменение склада:
  постановку короба на ячейку, добавленный сканом товар, снятие с ячейки, «вынуть из короба»,
  перенос через «+».
- Выделение при скане: открытая ячейка — полоса слева и заливка заголовка; открытая тара —
  рамка и заливка строки; только что положенное или вернувшееся — зелёная строка с полосой слева.
  Результат скана подписан под полем.
- Лента сверху содержит кнопки «Пикнуть» (то же, что набрать код в поле) и «Начать заново».

## Что сканировать

Код можно набрать в поле сканера и нажать Enter либо нажать кнопку в ленте.

| Что | Код |
|---|---|
| Ячейка А 1.1 | 2000000000114 |
| Ячейка А 1.2 | 2000000000121 |
| Ячейка А 1.3 | 2000000000138 |
| Ячейка А 2.1 | 2000000000213 |
| Ячейка Б 1.1 | 2000000000411 |
| Ячейка Б 1.2 | 2000000000428 |
| Палета П-000131 (внутри короба КР-000472, КР-000473) | 2100000001311 |
| Короб КР-000480 (носки, 90) | 2200000004807 |
| Грузоместо ГМ-000318 (ремень, 14) | 2300000003185 |
| Термокружка (россыпь, 12) | 4601122334455 |
| Футболка M (россыпь, 18) | 4680123456789 |
| Носки (россыпь, 40) | 4600987654338 |

Сценарий: пикнуть ячейку А 1.2, затем короб КР-000480 (он уходит из списка слева и появляется
под А 1.2, открытый), затем термокружку (одна штука россыпью уходит в короб, строка зелёная),
затем стрелка «назад» два раза: термокружка возвращается россыпью, потом короб возвращается
в список. Повторный скан открытой тары закрывает её, и товар идёт прямо в ячейку.
