## Замечания, отправленные в ту же облачную сессию

**A. Контекст известного кода.** `fboModel.ts:linkKiz` проверяет уже существующую
связь раньше несовместимого `target.productId`. Воспроизведено чистой моделью:
подобрать A с kA; подобрать B; создать B1; упаковать A, затем B;
`linkKiz(kA, { productId: B, boxId: B1 })` успешно привязывает kA к B1,
вместо отказа R6. Подтверждение/повтор существующего кода не должно обходить
явный контекст последнего ШК. Требуется вариант с уже связанным/напечатанным
кодом в модельных, API и DOM проверках; текущий C41 проверяет новый код подбора.

**B. Перепечать существующего кода.** `Controls.tsx` печатает при включённой
перепечати лишь `!already_linked`. Подтверждение КИЗа подбора и повтор
существующего кода в контексте проверки вообще не печатаются. Это нарушает
заданную перепечать существующего кода. C44 должен проверить код подбора
и код, уже выданный из пула, без повторного запроса нового кода.

**C. Отмена упаковки.** README признаёт, что `unpack-last` не определён
постановкой/контрактом. `packUndo` не запоминает подтверждение КИЗа подбора;
`unpackUnit` может удалить его связь целиком вместо снятия только короба,
потеряв достоверный факт подбора. Нужны определённая отмена конкретной
операции, сохранение связи подбора и отдельные проверки до корректировки
макета. `undo()` также убирает операцию из истории и показывает успех,
не проверяя `result.ok`: после сбоя история не должна пропадать.

**D. Полнота CI.** `contract_report.py` знает manifest только зелёных тестов.
Исчезновение обязательного RED-теста не меняет success. Запрошены полный
manifest всех ожидаемых тестов, проверка отсутствия/дублей/skip/error,
разделение предреализационного baseline и строгого режима после реализации,
доказательство, что сломанный импорт/пропавший тест/сломанная GREEN защита
дают BROKEN. Новые RED нельзя прятать в xfail или выдавать за готовый продукт.

**E. XLSX.** Кликабельная кнопка сейчас показывает пояснение вместо файла.
Запрошен локальный XLSX с прежними колонками/собственным ШК короба либо
честная отметка частичного сценария. Рабочий API не вызывать; первую
вкладку не менять.
