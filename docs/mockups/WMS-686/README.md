# WMS-686 · Узкий макет FBO

Существующий React-документ WMS с прежними вкладками и таблицами. Новое предложение ограничено сканером подбора: по товарам / товар + КИЗ / целый короб. Первая вкладка и упаковка не перепроектируются.

[Требования и сверка с обычным процессом](../../requirements/WMS-686.md). [Переписка](evidence/artmaks-transcripts.txt).

## Открыть

http://127.0.0.1:16866/?open_mp=demo-shipment&tab=pick

Исходный интерфейс: `?baseline=1&open_mp=demo-shipment`. Сброс вымышленных данных: `?reset=1&open_mp=demo-shipment&tab=pick`. Вторая отгрузка: `?open_mp=demo-shipment-kazan&tab=pick`. Прогресс сохраняется между обновлениями; параметр сброса удаляется после применения.

В способе «Товар + КИЗ»: `А-1-1` → `INB-DEMO-001` → `DEMO-P1` → `DEMO-KIZ-2` → `DEMO-P1` → `DEMO-KIZ-5`. Источник не нужно повторять для каждой единицы. «По товарам» оставляет исходное снятие по количеству. «Целый короб»: `А-1-1` → `INB-DEMO-001`, весь состав переносится без вскрытия.

## Локальный запуск

Из корня постоянного checkout с уже установленными зависимостями frontend:

```sh
frontend/node_modules/.bin/vite build --config docs/mockups/WMS-686/vite.config.ts
python3 -m http.server 16866 --bind 127.0.0.1 --directory docs/mockups/WMS-686/dist
```

Если зависимости ещё не установлены: `npm --prefix frontend ci`. Для разрешения импортов макета используется корневой `node_modules` (можно создать ссылку `ln -s frontend/node_modules node_modules`, если пути ещё нет).

Это сборка для отображения макета. Тесты, ревью и CI по прямому указанию владельца не запускаются. Не является реализацией рабочего процесса.

## Границы

Подмена компонентов выполняется только в сборке макета, production-файлы frontend/src не редактируются. Весь fetch отвечает локально; неизвестные маршруты отказывают. Демо-товары/КИЗ вымышлены. Рабочие API, WB, ЧЗ и принтер не вызываются; нативная печать перехвачена. Никакие новые услуги, формы дат, пропуска или экспорта не добавлены. Исходные диалоги упаковки и печати показывают текущий интерфейс; подключение их реальных серверных операций не входит в этот макет.
