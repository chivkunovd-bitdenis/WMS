# WMS-686 · кликабельный макет FBO: подбор и упаковка с необязательным КИЗ

Настоящий экран WMS «Отгрузки на МП» (`FfSuppliesShipmentsPage`) с прежними
вкладками «Товары / Подбор / Упаковка», таблицами, темой и компонентами. Предложение
постановки [`docs/requirements/WMS-686.md`](../../requirements/WMS-686.md)
(редакция 3) встроено точечно при сборке макета; `frontend/src` не редактируется.
Данные вымышленные, API локальный, печать — только предпросмотр.

Это демонстрация поведения, а **не** реализация в рабочем WMS и не приёмка.

## Как открыть

Из корня репозитория:

```sh
npm ci --prefix frontend                 # если зависимости ещё не установлены
ln -s frontend/node_modules node_modules # если ссылки ещё нет
frontend/node_modules/.bin/vite build --config docs/mockups/WMS-686/vite.config.ts
python3 -m http.server 16866 --bind 127.0.0.1 --directory docs/mockups/WMS-686/dist
```

Открыть: <http://127.0.0.1:16866/?reset=1&open_mp=demo-shipment&tab=pick>

- `tab=pick` / `tab=packaging` — сразу нужная вкладка; без параметра — «Товары».
- `open_mp=demo-shipment-kazan` — вторая отгрузка (другое направление из тех же коробов).
- `reset=1` — сбросить вымышленные данные; прогресс иначе сохраняется между обновлениями.
- `baseline=1` — исходный интерфейс без предложения (для сравнения).

Собранный макет также публикуется артефактом `wms686-mockup-dist-<sha>` целевого
workflow `.github/workflows/wms686-contract.yml`.

## Коды для сканера

В правом нижнем углу показаны машинно-читаемые штрихкоды ячеек, коробов, палеты и
товаров. КИЗ вынесены в отдельный PDF с крупными Data Matrix; откройте его кнопкой
«Открыть лист КИЗ (PDF)». Используйте физический сканер: клик по карточке ничего
не вводит. В подборе последовательность такая: ячейка `LOC-A11` или `LOC-A12`,
затем короб/палета, ШК товара и, если нужно, его КИЗ из PDF. Для целого короба нажмите
«Забрать целиком» у выбранного источника. На вкладке «Упаковка» сначала создайте
короб, затем сканируйте ШК товара и необязательный КИЗ; ШК созданного короба
переключает текущий короб. Данные учебные и хранятся локально в браузере каждого
оператора; они не отправляются в рабочий WMS.

## Как сканировать

**«Подбор»** — `LOC-A11` → `INB-DEMO-001` → `4600000000017` → один из КИЗ в PDF:
- каждый ШК сразу +1, источник держится; КИЗ — строка под товаром в строке короба,
  новая светло-зелёная; количество от КИЗ не меняется (R1–R3);
- у строки КИЗ: «Вернуть эту единицу» (атомарно, код становится «точно в таре»)
  или «Только отвязать код» (R9в); в строке «Снимаем с» — «КИЗ в таре: точно N,
  возможно M» или «состав КИЗ тары неизвестен» (R30);
- второй доступный КИЗ показан карточкой ниже первого; без КИЗ тоже можно работать;
- после `LOC-A11` можно сканировать второй короб `INB-DEMO-002`; кнопка «Забрать
  целиком» переносит всё его содержимое одним действием (R7).

**«Упаковка»** — создайте короб, затем сканируйте `4600000000017` и при желании
`010460000000001721P1X0001`:
- поле скана и галки как в FBS: «Печатать ШК», «Печатать ЧЗ − N +», «Перепечатывать
  ЧЗ − N +», «Отменить», размер этикетки, текущий короб и «Закрыть короб» (R12, R32);
- ШК → +1 в текущий короб, строка товара раскрывается; КИЗ → светло-зелёная строка
  во вложенности с коробом, источником и приёмкой; КИЗ подбора подтверждается в
  коробе без +1 (R13, R14, R29);
- «Печатать ШК» → уведомление и «Предпросмотр» настоящей этикетки WMS; «Отключить
  WMS Print» → ошибка, единица остаётся упакованной, «Повторить печать» — тот же
  ключ; «Печатать ЧЗ» — код из пула (у DEMO-TS-50 пул пуст) (R16, R31);
- блок «Короба» → «Убрать» у строки товара: единица с КИЗ (источник известен /
  неизвестен — выбор места из источников подбора) или без КИЗ (R28);
- «Пропуск: Прикрепить» рядом со «Скачать XLSX для WB» (R25).

## Допущения макета (не согласованы владельцем)

- «Забрать целиком» — кнопка после скана тары (Q1/D5).
- Короб не создаётся автоматически (D10); пропуск не обязателен (D11).
- Повтор печати — кнопкой, Escape снимает задание (D15).
- «Отменить последний скан» на упаковке вынимает единицу обратно в подобранные —
  для этого в продукте нужна новая серверная операция (в макете маршрут
  `boxes/{id}/unpack-last`, в постановке не закреплён тестом).
- «Скачать XLSX для WB» в макете показывает пояснение вместо файла: колонки в
  продукте не меняются (R24).
