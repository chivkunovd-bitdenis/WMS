# WMS-514 — кликабельный макет

Самодостаточный браузерный прототип текущего экрана упаковки WB FBS. Он не подключён
к API, не создаёт заданий на реальном принтере и не меняет код рабочего продукта.
Текущая компоновка и существующие действия сохранены; единственное визуальное
добавление WMS-514 — две галочки рядом с существующим полем сканирования.

В макете доступны:

- две независимые настройки автопечати по скану товарного ШК;
- все четыре комбинации QR/ЧЗ;
- выбор конкретной единицы одинакового товара;
- сохранённый путь `QR заказа → ЧЗ` без дополнительной автопечати;
- ручная печать и перепечать существующего QR/ЧЗ.

Для локального просмотра достаточно открыть `index.html` либо раздать каталог любым
статическим HTTP-сервером.
