# WMS-514 — кликабельный макет

Макет собран из настоящего `FfFbsSupplyWorkspace`, настоящей темы портала и
существующего подставного API сцены базы знаний. Отдельной HTML/CSS-копии экрана
нет. Единственное визуальное добавление WMS-514 — две галочки рядом с существующим
полем сканирования.

В макете доступны две кликабельные независимые настройки:

- «Печатать QR»;
- «Печатать ЧЗ».

Остальной интерфейс и существующие действия приходят непосредственно из текущего
компонента продукта. Макет не подключён к рабочему API и не отправляет задания на
реальный принтер.

Локальный запуск:

```bash
cd frontend
npm run dev -- --host 127.0.0.1 --port 4175
```

Открыть `http://127.0.0.1:4175/wms514-mockup.html`.
