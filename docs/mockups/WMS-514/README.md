# WMS-514 — кликабельный макет

Макет собран из настоящего `FfFbsSupplyWorkspace`, настоящей темы портала и
существующего подставного API сцены базы знаний. Отдельной HTML/CSS-копии экрана
нет. Единственное визуальное добавление WMS-514 — три галочки рядом с существующим
полем сканирования.

В макете доступны три кликабельные настройки:

- «Печатать QR»;
- «Печатать ЧЗ»;
- «Перепечатывать ЧЗ».

QR независима, а две настройки ЧЗ взаимоисключающие: чтобы сменить режим,
сначала нужно снять текущую галку. Все три настройки при открытии выключены.
Скан товарного ШК показывает все шесть допустимых комбинаций через существующую
область результата сканирования; сам товарный ШК никогда не изображается
напечатанным. Прямой полный ЧЗ в режиме перепечатки показывает одну точную копию,
а QR заказа → полный ЧЗ сохраняет прежнюю привязку и добавляет точную копию только
при включённой перепечатке.

Остальной интерфейс и существующие действия приходят непосредственно из текущего
компонента продукта. Макет не подключён к рабочему API и не отправляет задания на
реальный принтер, не вызывает print dialog и не является продуктовой реализацией.
Без специальной mockup-конфигурации настоящий компонент рендерит и выполняет
исходный путь без этих трёх галок и симуляции.

Точные коды для проверки:

- товарный ШК футболки `TSHIRT_M`, размер M: `4680123456789`; последовательные
  сканы выбирают только существующие строки того же товара/размера —
  `3941200018`, `3941200025`, `3941200032`, `3941200039`, после чего макет
  показывает исчерпание и не начинает список заново;
- QR заказа: `WB-3941200046`;
- прямой полный ЧЗ: `010460000000051421DIRECT51491ABCD92ABCDEFGHIJKLMNOPQRSTUVWXYZ123456789012345678`;
- ЧЗ после QR заказа: `010460000000051421BOUND51491EFGH92ZYXWVUTSRQPONMLKJIHGFEDCBA876543210987654321`.

Другие значения намеренно не угадываются как QR или полный ЧЗ.

Локальный запуск:

```bash
cd frontend
npm run dev -- --host 127.0.0.1 --port 4175
```

Открыть `http://127.0.0.1:4175/wms514-mockup.html`.
