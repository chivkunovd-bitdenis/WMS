# Макет ТСД · пакет ArtMaks 08.10 (WMS-736…741, связанные WMS-711 и WMS-713)

Кликабельный макет новых процессов мобильного ТСД (терминала сбора данных) по переписке с ArtMaks 08.10.2026. Слева — экран устройства, справа — пульт: кнопки «сканера», готовые сценарии и журнал того, что в этот момент сделала бы система. Данные вымышленные, сервер не вызывается, приложение ТСД не меняется.

## Как открыть

```sh
sh /Users/deniscivkunov/Projects/WMS/.worktrees/tsd-artmaks-analysis/docs/mockups/WMS-736/open.sh
```

Затем http://127.0.0.1:16736/ в обычном браузере. Скрипт ничего не устанавливает: он ставит ссылку node_modules на /Users/deniscivkunov/Projects/WMS/frontend/node_modules и запускает Vite. Сброс — кнопка «Начать»/«Заново» у сценария или обновление страницы.

Проверка сборки: из этой папки ./node_modules/.bin/tsc -p tsconfig.json и ./node_modules/.bin/vite build (папка dist в Git не попадает).

## Устройство

Экран 360 × 640 dp в портрете — эталон маленького экрана, принятый в WMS-711 (вопрос Q4). Из них 24 dp занимает строка состояния и 48 dp — системная навигация, приложению остаётся 568 dp: это самый тесный случай, на ТСД с большим экраном будет просторнее. Точная модель UROVO у ArtMaks не установлена. 1 dp макета = 1 CSS-пиксель; масштаб «по окну» только увеличивает картинку.

Цвета, размеры кнопок, шапка, полоса места, диалоги и нижние листы повторяют приложение (сборка 0.2.0, код 19, репозиторий WMS-TSD, коммит 41f0f33: ui/theme/Theme.kt, ui/patterns, features/fbs, features/inbound). Экраны, которые пакет не меняет, нарисованы как есть, со своими мелкими шрифтами и крупными карточками.

## Где ТСД сейчас отстаёт от веба (проверено по коду сборки 19 и origin/etalon)

1. **Подбор FBS** — плоский список товаров вместо маршрута по ячейкам; полностью подобранные товары уезжают вниз; плашки мест показывают «доступно» без учёта уже подобранного (так же путалась веб-таблица 08.10). Закрывает WMS-711.
2. **Создание поставок** — причина отказа группы без номера заказа; группы проверяются по одной с блокировкой окна; повтор после частичного создания ничего не делает, но звучит как успех. WMS-713, WMS-741.
3. **Упаковка** — нет ни слова о недоборе (WMS-737); короб нельзя очистить или удалить (в вебе — меню «Очистить»/«Удалить», WMS-738); передачи нет в упаковке, «Назад» водит через законченный подбор (WMS-739).
4. **Приёмка** — нет фильтров и поиска; в списке нет черновиков селлеров, сортировки и оприходованных; черновик селлера открывается и тут же закрывается (WMS-736).
5. «Короба внутри короба» в прочитанном коде подбора и упаковки FBS и приёмки нет: короба там плоские. В FBO-подборе ТСД (ветка wms686-fbo-pick, WMS-686) есть «перенос короба целиком» — этот пакет его не разбирал.

## Что в макете предложено сверх требований (на решение владельца)

- На подборе «Отменить последний» стоит в строке «Маршрут», а не отдельной строкой во всю ширину: на 360 × 640 так маршруту остаётся место на 2–3 товара при открытом блоке. Само действие и правило WMS-584 R10 не меняются.
- Строки маршрута и блок места набраны шрифтом 15–16, числа — 21. В текущей ветке WMS-711 (feat/wms711-713-tsd-fbs, features/fbs/FbsScreens.kt) название в строке маршрута набрано 13 sp, а штрихкод и строка «Остаток · взять · собрано» — 10 sp; правило UX ТСД 6 требует не меньше 16 sp (mobile/docs/02_UX_SPEC.md).

## Наблюдения без задачи (вопросы владельцу, если сочтёт нужным)

- После скана товара источник запоминается; следующий товар из другого места даёт «Недостаточно неупакованного остатка в ячейке», пока не нажать «Сменить место». Для товара «Без ячейки» отсканировать место нечем — нужно именно «Сменить место». Так работает и сборка 19.
- Плитку «Отгрузка» на главном экране партнёр трижды переспрашивал (1230, 1252–1254, 1335): это FBO-отгрузки, но подпись этого не говорит.
- Экран упаковки FBS показывает одну карточку заказа на экран (7 строк текста, номер 36 sp, кнопка печати 56 dp). На 50 заказах это долгая прокрутка. Пакет экран не меняет.

## Что проверено в макете (09.10.2026, встроенный браузер, вручную по шагам)

Пройдены все семь сценариев, «Весь путь» — от главного экрана до кнопки передачи. Найдено и исправлено по ходу: нижний лист фильтров перекрывал только часть экрана и оставлял видимой кнопку «Создать приёмку»; строка выбранных фильтров уезжала за край вместе с «Сбросить»; маршрут не возвращался вверх к ранней ячейке из-за «липких» заголовков; полоса места показывала служебный код __SORTING__ вместо «Без ячейки»; блок места обрезал вторую строку посередине; ошибка React в журнале при проверке групп. Снимки ключевых состояний лежат локально в docs/mockups/WMS-736/evidence этой рабочей копии; по правилу .gitignore картинки в docs в Git не хранятся.

Не проверено: физический ТСД, реальный сканер и клавиатура Android, печать, Ozon (переключатель есть, заказов нет), полный путь ЧЗ (показаны только QR → код ЧЗ).
