# Куда делись картинки и другие тяжёлые файлы проверок

30.08.2026 из репозитория вынесены все скриншоты, PDF, записи трасс Playwright
и файлы баз, которые лежали в `docs/`, `tasks/` и `output/`.

## Зачем

Их было 1096 штук на 179 МБ, и лежали они в самом репозитории. Из-за этого:

- каждая рабочая копия проекта обязана была выложить около 170 МБ картинок,
  нужны они ей или нет — а копий на машине бывает по два десятка;
- склад истории git раздулся до полугигабайта, и любое создание копии,
  клонирование и поиск по проекту становились ощутимо медленнее;
- бинарные файлы в истории остаются навсегда: удаление из текущей версии
  историю не уменьшает.

## Где они теперь

```
/Users/deniscivkunov/Projects/WMS/.archive/media-20260830/
```

Пути внутри архива сохранены один в один, как были в репозитории. Например,
файл, который лежал в `docs/reviews/wms-wave1/2026-08-15/evidence/foo.png`,
находится в архиве по тому же пути от корня архива.

Папка `.archive/` находится вне гита и не попадает ни в одну рабочую копию.

## Что делать дальше

Владелец решает, в какое внешнее хранилище их положить и какие ссылки оставить
в отчётах. Пока это не сделано — архив на диске, не удалять.

## Как не вернуть обратно

В `.gitignore` добавлены правила: картинки, PDF, архивы трасс и файлы баз в
`docs/`, `tasks/` и папка `output/` целиком больше не попадают в репозиторий.
Если проверка снимает скриншот — он остаётся на диске и в отчёте описывается
словами, а сам файл кладётся в архив или во внешнее хранилище.

## Чего эта уборка НЕ сделала

История git не уменьшилась: файлы удалены из текущей версии, но остаются во
всех прошлых коммитах, и склад по-прежнему весит около полугигабайта. Чтобы
сжать историю, нужно её переписывание — операция, которая меняет все коммиты и
ломает существующие клоны. Это отдельное решение владельца, здесь оно не
принималось.
