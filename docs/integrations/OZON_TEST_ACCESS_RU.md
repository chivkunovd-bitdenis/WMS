# Тестовый доступ к Ozon

24 августа 2026 года владелец проекта прямо указал сохранить выданный ключ и использовать его для разработки и интеграционного тестирования будущего модуля Ozon.

Само значение намеренно не записано в отслеживаемые Git-файлы. Оно лежит внутри общего служебного каталога этого репозитория и поэтому доступно из основного checkout и всех его worktree:

```text
$(git rev-parse --git-common-dir)/codex-secrets/ozon-test.env
```

В файле определена переменная `OZON_TEST_API_KEY`. При начале любой задачи по модулю Ozon сначала следует использовать этот тестовый доступ для интеграционных проверок, а не запрашивать новый ключ.

Ограничения:

- доступ предназначен только для разработки и тестов, не для production;
- ключ нельзя менять, перевыпускать или отзывать без отдельного прямого указания владельца;
- одного API-ключа может быть недостаточно: если конкретный метод Ozon требует `Client-Id` или другой идентификатор кабинета, его нужно запросить отдельно;
- в логах, отчётах, коммитах и скриншотах значение ключа печатать не нужно.

Проверять наличие ключа следует без вывода его значения: файл должен существовать, быть непустым и после загрузки определять непустую переменную `OZON_TEST_API_KEY`.
