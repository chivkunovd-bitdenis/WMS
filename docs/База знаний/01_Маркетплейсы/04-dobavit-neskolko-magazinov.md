# Как добавить несколько магазинов в WMS

*Порядок создания отдельного кабинета WMS для каждого магазина и связывания кабинетов с одним владельцем*

> **Назначение.** Создать по отдельной записи WMS на каждый магазин, настроить подключения в соответствующих кабинетах и проверить доступ владельца к назначенным магазинам. Создание записи ещё не гарантирует, что пользователю настроено переключение между ними.

## Когда нужна эта инструкция

Используйте этот порядок, если у одного владельца несколько магазинов Wildberries или Ozon и для каждого магазина нужно отдельно настраивать каталог, подключение площадки и передачу остатков. Каждый магазин добавляется в WMS как отдельный селлер. Это позволяет не смешивать товары и настройки разных кабинетов.

## Перед началом

- Подготовьте отображаемое название каждого магазина и отдельный email, который будет использоваться для входа в соответствующий кабинет WMS.
- Добавлять селлеров может администратор фулфилмента. Если пункта «Селлеры» или формы добавления нет, попросите администратора выполнить этот шаг.
- Пароль при создании не задаётся. Пользователь нового кабинета устанавливает его при первом входе.
## Создайте запись для каждого магазина

1. Откройте раздел «Селлеры». В боковом меню WMS фулфилмента выберите «Селлеры». Убедитесь, что открыт именно кабинет фулфилмента, а не портал селлера.

2. Заполните форму «Добавить селлера». В поле «Название / бренд» укажите понятное имя магазина. В поле «Email для входа» внесите email пользователя, который будет входить в этот кабинет. Проверьте, что это правильная пара «магазин — email».

3. Добавьте кабинет. Нажмите «Добавить селлера» и дождитесь сообщения об успешном создании. Если WMS сообщает, что email уже используется, не меняйте email на случайный: проверьте, существует ли уже кабинет для этого адреса, и обратитесь в поддержку.

4. Повторите действия для остальных магазинов. Каждому магазину создайте отдельную запись селлера с его названием и предназначенным для него email. Не создавайте дубликат, если нужная запись уже есть.

## Подключите площадку в каждом кабинете

1. Войдите в WMS под email этого магазина. Перед настройкой проверьте отображаемое название селлера. Подключение будет относиться к выбранному кабинету.

2. Откройте «Настройки». В настройках выберите нужную площадку и подключите кабинет этого магазина. Если магазин работает только с Wildberries, подключите Wildberries; если работает с Ozon — подключите Ozon. Для магазина на обеих площадках настройки выполняются отдельно для каждой.

3. Введите данные подключения только в форме WMS. Используйте данные кабинета соответствующего магазина. Не отправляйте API-ключи, пароли или PIN в Telegram, общий чат, скриншоты или документ. Настройка одного магазина не подключает автоматически остальные.

4. Проверьте статус подключения. После сохранения убедитесь, что WMS показывает подключённый статус для нужного магазина и нужной площадки. Затем переключите селлера и убедитесь, что открываются отдельные настройки другого магазина.

## Свяжите кабинеты с учётной записью владельца

Если владелец должен переключаться между несколькими магазинами в WMS, после создания записей обратитесь в согласованный канал поддержки и перечислите только названия созданных магазинов. Команда поддержки свяжет эти записи с учётной записью владельца. Не передавайте поддержке пароль, PIN или ключ площадки.

## Как проверить, что всё настроено

- В разделе «Селлеры» видна отдельная строка для каждого магазина.
- У каждого магазина свой адрес для входа, если так предусмотрено организацией доступа.
- В настройках каждого кабинета подключены только нужные этому магазину площадки.
- В портале селлера в боковой панели видны магазины, доступные этой учётной записи; выбор магазина меняет активный кабинет. Проверьте, что после переключения отображается ожидаемое имя и его каталог/настройки. Если других магазинов нет, сами созданные записи не дают доступ автоматически: попросите администратора/поддержку проверить привязку пользователя к нужным записям.
## Если что-то не получилось

- Раздел «Селлеры» не виден — попросите администратора фулфилмента проверить доступ.
- Email уже используется — проверьте существующую запись и не создавайте дубликат.
- Площадка подключилась не к тому магазину — остановитесь и проверьте выбранного селлера до публикации остатков.
- После переключения магазин не виден владельцу — передайте поддержке только название созданной записи, чтобы проверить её связь с учётной записью.
## Основание и границы

Источник запроса — сообщение поддержки Korob_support от 9 октября 2026 года в Telegram-чате «Короб BMC-Фулфилмент Бамбук» (02:34): для нескольких магазинов предлагалось создать отдельного селлера на каждый магазин, подключить нужные площадки в настройках каждого и связать созданные магазины с учётной записью владельца. Названия полей формы сверены с кодом экрана «Селлеры» ветки origin/etalon. Успешное создание кабинетов и связь с учётной записью конкретного владельца этим не подтверждены.
