# Проверка итогового экспорта руководства WMS

## Состав выпуска

Все три финальных файла собраны из пяти актуальных глав. Текстовый PDF и Word созданы полным запуском `python3 docs/База знаний/Руководство/build_manual.py --illustrated`; затем после визуальной проверки изменена только высота кадра входа на Android-ТСД и отдельно пересобран иллюстрированный PDF. Контрольные суммы текстовых PDF и Word совпадают с принятыми версиями:

- `docs/База знаний/WMS_Руководство_текст.pdf` — 39 страниц;
- `docs/База знаний/WMS_Руководство_текст.docx` — Word-версия того же текста; пакет из 21 части совпадает с пятиглавым DOCX-превью, ранее отрендеренным на 39 страниц и принятым по макету;
- `docs/База знаний/WMS_Руководство_с_иллюстрациями.pdf` — 79 страниц.

Иллюстрированный PDF содержит все 64 кадра из трёх согласованных манифестов: 55 актуальных снимков Stage G, 6 кадров из исходного FBO-руководства и 3 исторических кадра Android-ТСД. Все исходные кадры и выноски приняты по отдельности. Шесть FBO-кадров относятся к подбору, отказу по коробу, упаковке, извлечению товара, маркировке и пропуску. Физический вывод бумаги на принтер этим документом не подтверждается.

## Паритет текста и навигация

По пяти главам сборщик формирует 644 текстовых элемента: 122 заголовка, 171 абзац и 351 пункт списка. Проверка по исходному порядку нашла все элементы в Word, текстовом PDF и иллюстрированном PDF — 644/644 в каждом файле. Для PDF сравнивался извлечённый текст после удаления колонтитулов и нормализации пробелов; внутренние ссылки сверялись по заголовку целевой главы, который виден читателю в экспорте. Извлекатель `pdftotext` не возвращает отдельные знаки ₽, ³, ÷ и ✓ из встроенного шрифта, поэтому эти знаки исключались из текстового сравнения; визуальный просмотр PDF выполнен отдельно.

В каждом PDF есть 113 закладок для заголовков уровней H1–H3; все 113 совпадают с заголовками глав по порядку. Word сохраняет стили Heading 1–3 для панели навигации.

В первой сборке ведущий нашёл, что некоторые заголовки отделялись от первой иллюстрации, а заключительный список разбивался так, что на последней странице оставался один пункт. Сборщик изменён только для иллюстрированного PDF: заголовок и первая фигура с подписью размещаются одной группой с резервом высоты, а последний короткий список удерживается с заголовком. Дополнительно кадр прямого входа на Android-ТСД уменьшен на 45 pt, чтобы поясняющий абзац поместился под ним. После правок проверены все 49 якорей первой фигуры: заголовок и подпись первой фигуры находятся на одной странице в 49/49 случаях. Заголовок заключительного подраздела и все пять пунктов списка находятся вместе на странице 79. Текстовые PDF и DOCX после принятия не менялись.

Ранее сообщённые десять пропусков не воспроизводятся на текущих трёх экспортах. При строгом сравнении сырого текста PDF отдельно отмечается абзац, который пересекает разрыв страницы: между его частями извлекатель вставляет колонтитул. После удаления колонтитулов и перечисленных выше знаков, не возвращаемых `pdftotext`, абзац и все остальные элементы находятся в исходном порядке; других пропусков текста не обнаружено.

## Постраничное визуальное ревью

Все 79 страниц иллюстрированного PDF и 64 изображения визуально приняты ведущим; кадры также проверялись по отдельности.
