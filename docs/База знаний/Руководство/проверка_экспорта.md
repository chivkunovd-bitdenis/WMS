# Проверка итогового экспорта руководства WMS

## Состав выпуска

Финальные файлы собраны из пяти актуальных глав командой `python3 docs/База знаний/Руководство/build_manual.py --illustrated`:

- `docs/База знаний/WMS_Руководство_текст.pdf` — 39 страниц;
- `docs/База знаний/WMS_Руководство_текст.docx` — Word-версия того же текста; пакет из 21 части совпадает с пятиглавым DOCX-превью, ранее отрендеренным на 39 страниц и принятым по макету;
- `docs/База знаний/WMS_Руководство_с_иллюстрациями.pdf` — 80 страниц.

Иллюстрированный PDF содержит все 64 кадра из трёх согласованных манифестов: 55 актуальных снимков Stage G, 6 кадров из исходного FBO-руководства и 3 исторических кадра Android-ТСД. Все исходные кадры и выноски приняты по отдельности. Шесть FBO-кадров относятся к подбору, отказу по коробу, упаковке, извлечению товара, маркировке и пропуску. Физический вывод бумаги на принтер этим документом не подтверждается.

## Паритет текста и навигация

По пять глав сборщик формирует 644 текстовых элемента: 122 заголовка, 171 абзац и 351 пункт списка. Проверка в исходном порядке нашла все 644 элемента в Word, текстовом PDF и иллюстрированном PDF — 644/644 для каждого файла. Внутренние ссылки сверялись по заголовку целевой главы, который виден читателю в экспорте.

В каждом PDF есть 113 закладок для заголовков уровней H1–H3; все 113 совпадают с заголовками глав по порядку. Word сохраняет стили Heading 1–3 для панели навигации.

В первой сборке ведущий нашёл, что некоторые заголовки отделялись от первой иллюстрации, а заключительный список разбивался так, что на последней странице оставался один пункт. Сборщик изменён только для иллюстрированного PDF: заголовок и первая фигура с подписью теперь размещаются одной группой с резервом высоты, а последний короткий список удерживается с заголовком. После исправления проверены все 49 якорей первой фигуры: заголовок и подпись первой фигуры находятся на одной странице в 49/49 случаях. Заключительный заголовок и все пять пунктов последнего списка находятся вместе на странице 80. Текстовые PDF и DOCX после этого исправления не менялись.

Ранее сообщённые десять пропусков не воспроизводятся на текущих трёх экспортах. При сыром извлечении PDF отдельно отмечается один абзац, который пересекает разрыв страницы: колонтитул вставляется между его частями. После исключения повторяющихся колонтитулов он совпадает; других несовпадений нет.

## Постраничное визуальное ревью

Иллюстрированный PDF отрендерен целиком в 80 PNG при 100 dpi. Контакт-листы собраны по шесть страниц в сетке 3×2; полноразмерные страницы и 14 листов находятся в `docs/База знаний/Руководство/.qa/illustrated_export_review_v2/`. Все страницы переданы ведущему для общей визуальной проверки; покадровое принятие изображений выполнено отдельно.
