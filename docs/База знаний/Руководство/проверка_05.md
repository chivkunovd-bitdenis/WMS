# Проверка 05: обычная отгрузка и календарь

## Область и состояние

- Текущий код сверялся по заданному базовому commit `61012808c26ba8dabcd271ef21bbbc362caaffaa` (`origin/etalon`).
- Проверены клиентский текст, активный маршрут, роли, поля заявки, частичная и полная выдача, движения, календарные плитки и назначение даты.

## Оставшиеся границы проверки

1. Видимая подсказка на Stage говорит «Резерв при отправке», но backend текущего etalon синхронизирует резерв сразу при добавлении строки в черновик и снимает резерв при удалении строки черновика. Клиентский текст следует подтверждённой логике backend; расхождение подсказки зафиксировано для модерации.
2. В календаре октября 2026 на Stage были видны четыре плитки FBS, но не было плитки обычной складской отгрузки. Нажатие на плитку FBS открыло карточку существующей поставки FBS. Поэтому текущие кадры подтверждают наличие событий, их маркировку и переход для FBS; открытие обычной заявки из календаря проверено по коду, но не на живом обычном документе.
3. Плитка обычной заявки визуально называет сумму плановых штук «коробами». Пользовательскую инструкцию ограничили сопоставлением плана и факта по строкам заявки; пояснение о расхождении оставлено только в этом внутреннем файле.
