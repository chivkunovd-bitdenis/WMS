Папка собирает инструкции для операторов и селлеров: перенесённые статьи приложения и материалы, подготовленные по разбору обращений поддержки.

## Период проверки

Переписку поддержки проверяли за **1–8 октября 2026 года** по сохранённым локальным Telegram-выгрузкам и сводке обращений. Это обзор сохранённых материалов, а не подтверждение текущего состояния всех чатов или операций в кабинетах маркетплейсов.

## Текстовые черновики без подходящих скриншотов

У этих материалов пока нет подходящих реальных снимков нужных экранов с проверенными выносками. **Не выдавайте их клиентам**, пока визуальная часть не будет дополнена и проверена.

- [01_Маркетплейсы](01_Маркетплейсы/) — три пары черновиков Word/PDF: [подключение Ozon](01_Маркетплейсы/01-podklyuchenie-ozon.docx), [связь товаров и складов Ozon](01_Маркетплейсы/02-svyaz-tovarov-i-skladov-ozon.docx), [публикация остатков WB/Ozon](01_Маркетплейсы/03-publikacziya-ostatkov-wb-ozon.docx). Соответствующие PDF имеют те же имена и расширение `.pdf`.
- [03_ТСД_и_подключение](03_ТСД_и_подключение/) — пара черновиков [входа на ТСД по существующему логину и PIN](03_ТСД_и_подключение/01-вход-на-tsd-po-sushchestvuyushchemu-loginu.docx) и PDF с тем же именем. Скриншоты пока не подтверждают последовательность действий.

## Что не оформлялось как готовые инструкции

По сохранённым обращениям не стали превращать в клиентские инструкции вопросы, для которых причина или результат не были установлены:

- причина отказа **403** при публикации остатков;
- неактивная кнопка коробов;
- история движений товара, которую не удалось проверить;
- незавершённые запросы по новым функциям ТСД и неразобранным сбоям;
- приёмка QR-кодов, которая не была подтверждена.

Для этих случаев инструкция могла бы ошибочно представить предположение как установленную причину или рабочее решение.
