## Дополнительная FBO-инструкция из локальных материалов

Визуально это захваты экранов отгрузки WMS: подбор с ячеек/коробов, отказ при превышении плана, упаковка, привязанный КИЗ/перепечатка, извлечение товара из короба и форма пропуска. Это отдельный источник, не одна из 16 пар выше. По виду это захваты самого интерфейса, а не иллюстрации, нарисованные поверх пустого макета; доступная файловая provenance не позволяет в этом отчёте независимо подтвердить, был ли кадр снят именно на staging. Владелец разрешил использовать эту инструкцию как Stage G/staging-only после очистки исходных реквизитов доступа; значения логина/пароля из исходного файла не извлекались в отчёт и не должны переноситься в Git или общую инструкцию. Содержимое самой инструкции не объявляется включённым в набор без отдельной редакционной сборки.

## Текущие ограничения и несоответствия

1. Старые восемь новых пар DOCX/PDF — архив ранних материалов. В семи нет встроенных иллюстраций; у одной осталась статичная демонстрационная картинка с номерами, не Stage G. Эти пары не смешиваются с новым единым руководством.
2. У старых статей приложения 20 исходных PNG сохранены и побайтно соответствуют их вложениям. Замечание к подписи/выноске старой статьи остаётся историческим замечанием к старому материалу и не описывает новый иллюстрированный PDF.
3. Три манифеста текущих глав содержат 40 + 21 + 3 записей. Все 64 фигуры и подписи приняты модератором; происхождение кадров раздельно указано выше. Все страницы собранного PDF просмотрены и приняты.
4. Текстовые Word/PDF пяти глав приняты после просмотра 39 страниц каждого файла. Канонический иллюстрированный PDF собран на 79 страниц; его страницы также визуально приняты.
5. В тестовом документе при съёмке создана одна тестовая строка и один пустой короб для снимка формы наполнения. Это не доказывает сканирование КИЗ, печать, проведение документа или изменение остатка. Для обычного сканирования отдельного текстового поля интерфейсом не требуется: путь использует общий сканер; тестовые коды в кадре не вводились.
6. Источники Telegram ограничены доступными локальными архивами шести чатов и выборочным чтением UI; это не полный экспорт всех чатов аккаунта. Общая инструкция не подтверждает исход конкретной жалобы.

Проверенные ссылки на исходники статей и сохранённые артефакты приведены относительными путями, чтобы отчёт оставался читаемым в checkout. Визуальный обзор не удостоверяет поведение production, права доступа пользователя, успешность реальной операции или состояние установленной версии.
