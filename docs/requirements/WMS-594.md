# WMS-594 · Отдельные права сотрудников на разделы

## Исходный запрос и уточнения

30.09.2026: Отдельные права: Расчёты, Хранение, Инвентаризация (создание и просмотр/работа), FBS, Честный знак, Настройки. Без права раздел не виден и операции недоступны.

Владелец поручил срочную параллельную реализацию Sol/Terra без навыков и отдельной аналитической цепочки, затем изолированное ревью. Деплой и внешние операции этим пакетом не выполняются.

## Требования

**R1.** Независимые разрешения на Расчёты, Хранение, Инвентаризацию, FBS, Честный знак и Настройки в существующей модели сотрудников.

**R2.** Меню и прямые маршруты учитывают право; API запрещает чтение и изменения запрещённого раздела.

**R3.** Администратор сохраняет доступ. Переход существующих сотрудников не расширяет их прежние эффективные права и не лишает разрешённой работы без изменения настройки.

**R4.** Разрешения действуют на веб и ТСД; сохраняются границы клиентов. Инвентаризация включает просмотр, создание и работу с документом; отдельное разделение просмотра/создания владелец не потребовал.

## Проверки

| Проверка | Вердикт |
|---|---|
| C1: проверить R1 на собранной реализации | Локально выполнено: четыре новых поля БД и API вместе с прежними `settings` и `inventory`; интерфейс настроек меняет каждое право отдельно. `tsc` и production build прошли. |
| C2: проверить R2 на собранной реализации | Локально выполнено: скрытие меню и запрет прямых маршрутов в коде; API-тест с прежним токеном проверяет выдачу и отзыв всех шести прав. Работа в реальном браузере передана на отдельную проверку. |
| C3: проверить R3 на собранной реализации | Частично проверено: администратору возвращаются все права; миграция переносит старое `inventory` в `storage`, `packaging` в `fbs`, сохраняя прежний эффективный доступ. Ведущий агент применил миграции 0566/0567 к отдельной локальной PostgreSQL-базе; действующие аккаунты в production не затрагивались. |
| C4: проверить R4 на собранной реализации | Частично проверено: тест API подтверждает изоляцию разделов FBS и ЧЗ, хранения и инвентаризации, а API инвентаризации использует одно право на просмотр, создание и работу. Контракт `/auth/me` передан мобильному исполнителю; ТСД и отдельное ревью ещё проверяются. |

## Заключение

Локальная реализация и автоматические проверки выполнены. Окончательная приёмка требует просмотра разделов в браузере, проверки мобильного клиента и изолированного ревью. Выкладка и работа с настоящими заказами в эту проверку не входят.
