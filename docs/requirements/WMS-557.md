# WMS-557 · FBS: план и остаток товара при распределении по коробам

## Запрос

Рядом с числовым полем количества при добавлении товара в короб показывать план
по этому товару и нераспределённый остаток. При плане 10 и пяти единицах в первом
коробе следующий короб показывает остаток 5. Учитывать сохранённые короба и текущий
ввод; не менять количественную бизнес-логику, сохранение и ограничения.
По прямому указанию владельца выполняется узкая frontend-правка без отдельной
ролевой цепочки и навыков.

## Требования

- R1. В существующем WB FBS-окне «Добавить товары в короб» рядом с числовым полем
  показывать компактную подпись «План: N · Осталось: M».
- R2. План — число заказов этого товара в составе текущей поставки; остаток —
  заказы, ещё не назначенные ни одному коробу, за вычетом текущего ввода для этого товара.
- R3. При изменении ввода или повторном открытии окна после сохранения расчёт
  обновляется из существующих данных. Другие товары считаются независимо.
- R4. Не менять API, сохранение, прежние ограничения количества, Ozon и другие действия.

## Проверки

| ID | Проверка | Вердикт |
|---|---|---|
| C1 | План 10, сохранено 5: остаток 5; введено ещё 2: остаток 3; ввод очищен: остаток 5. | PASS: адресные тесты арифметики. |
| C2 | Несколько товаров, удаление назначения, отсутствие product id и существующее округление ввода. | PASS: адресные тесты независимых количеств и пересчёта. |
| C3 | Целевые frontend-тесты, TypeScript, production build и просмотр diff. | 54 теста PASS, diff проверен. TypeScript и build выполняются. |

## Заключение

Подпись реализована без изменения сохранения и ограничений, 54 целевых теста проходят.
TypeScript и build выполняются. Деплой и браузерная проверка нового экрана не выполнялись.
