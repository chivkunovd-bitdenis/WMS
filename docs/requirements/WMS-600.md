# WMS-600 — сортировка FBS по ячейкам

## Исходный запрос

30.09.2026: «агрегация по ячейкам на сортировке, а не по товарам — чтобы можно было собираться последовательно, сверху вниз по номерам ячеек ... речь про экран сортировки в ФБС ... сейчас верхний уровень — товар, а будет верхний уровень — ячейка и в ней тара и всё что есть».

## Требования

| ID | Требование |
|---|---|
| R1 | На существующем экране сортировки FBS верхний уровень группировки — ячейка, внутри показаны тара и все находящиеся в них товары. Товар больше не служит верхним уровнем. |
| R2 | Ячейки следуют сверху вниз по номеру в естественном порядке (2 перед 10), пригодном для последовательного обхода. Использовать имеющееся обозначение ячеек. |
| R3 | Товары без тары показываются внутри своей ячейки. Позиции без назначенной ячейки не теряются; сохранить существующее представление отсутствующего размещения. |
| R4 | Состав, количества, доступные действия, выбранный основной ШК, сканирование и состояние сортировки сохраняются; меняется организация существующего экрана, без новой складской логики. |
| R5 | Сохранить существующие компоненты, тему, tenant/seller/warehouse scope. Проверить реальный экран и отсутствие потерь/дубликатов при одном товаре в нескольких ячейках и тарах. |

## Проверки

| Проверка | Требования | Вердикт |
|---|---|---|

Служебная зона API «Без ячеек» уходит после физических адресов. |
| Реальный экран, сканирование/действия и неизменные итоговые количества | R4,R5 | Локально в браузере: FBS «В работе» → сборка №000001 → «Подбор»: сначала A-01, затем A-02 и следующие ячейки; «Без ячеек» в конце, товары внутри ячеек читаемы без наложения колонок, общий остаток 53 из 83 не изменился. DOM-тест подтвердил ручное снятие с конкретного места и отмену только последнего места при одном SKU в двух ячейках. Физический сканер не проверялся; обработчик скана не изменён. |

При переносе в общую ветку stable patch-id продуктовых изменений сохранён. |

## Заключение

Локальная реализация покрывает организацию списка по ячейкам и сохраняет существующий путь снятия/сканирования. Целевые проверки, просмотр реального FBS-экрана и независимое ревью итогового исходного коммита прошли. Физическое сканирование, принтер и работа на production не проверялись. Позднее владелец отдельно разрешил точечный выпуск WMS-600 вместе с WMS-601 и WMS-603; остальные задачи остаются вне этого выпуска. До фактической выкладки production-поведение не подтверждено.
