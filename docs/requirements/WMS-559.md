# WMS-559 — Дополнительные ШК в сортировке

## Запрос

Владелец: «2039751597840 говорит не в текущей приёмке… делали механизм хранения нескольких ШК… на проде заполни по всем таким товарам из приёмки».

## Требования

R1. Принимать сохранённые дополнительные ШК конкретного варианта WB в текущей приёмке.
R2. Сохранить основные ШК, остатки, количество, защиту повторных сканов и границы клиента/селлера/размера.
R3. Сверить все товарные строки исходного Excel ArtMaks; добавлять только реально отсутствующие коды. Не менять фронт.

## Установленная причина

Все 323 товарные строки файла (321 SKU), включая 18 несовпадений с основным ШК, уже покрыты production-карточками WB. Дополнительные коды находятся в sizes[].skus нужного chrtID. Дозаполнение данных не требуется. Сортировка сравнивала только products.wb_barcode.

При отсутствии основного совпадения читать только карточки товаров текущей приёмки и сопоставлять точный seller/nm/chrtID. Основной путь остаётся без дополнительного запроса. Не загружать весь каталог селлера.
