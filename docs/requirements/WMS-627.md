# WMS-627 · ArtMaks: пропущенные списания переданных WB FBS поставок

## Исходный запрос и уточнения

Владелец: почему WB-GI-285910955 показывает 16 неподобранных из 358 после отгрузки; товары пересканировали; почему отгруженные товары остаются в ячейках. Красную строку просил исключить из разбора. После подтверждения отсутствующих списаний: «чини эту дыру ... срочно ... остатки ... доступны для заказов ... срочно надо править».

EMERGENCY_BYPASS_USER_APPROVED: срочное исправление производственного инцидента. Сначала подтверждение WB и ограниченная сверка данных, затем устранение серверной причины. Это не продуктовая приёмка.

## Требования

- R1. Подтверждённая передача WB должна приводить к однократному складскому списанию также при обнаружении передачи синхронизацией, без повторного запроса передачи в WB.
- R2. Исправить пропущенные списания ArtMaks по WB-GI-285910955 и WB-GI-285911018 только после живого подтверждения done=true и точного совпадения состава 358/23 заказов. Существующие списания не повторять; сохранять источники и аудит.
- R3. Проверить повторные сканы после технического сброса; восстановление прежнего учёта не выдавать за новый физический скан. Не менять КИЗы и стикеры.
- R4. Проверить физический остаток по ячейкам, общий остаток и доступность для публикации после ремонта; отделять запись WMS от факта публикации WB.
- R5. Не менять фронт, лимиты оператора, секреты, чужую работу. Красная строка исключена из отдельной диагностики. Сохранять права и границы tenant/seller/warehouse.
