# WMS-609 · Очистка ЧЗ без оставшегося хвоста

## Исходный запрос

Владелец попросил срочно очистить все ЧЗ в текущей объединённой упаковке селлера
«Фабрика» и исправить production-поведение: после действия «Очистить ЧЗ» в строке
не должен оставаться хвост удалённого кода.

## Требования

- **R1.** Очистка удаляет значение `sgtin` у Wildberries и локальную привязку ЧЗ.
- **R2.** Вместе с привязкой удаляется сохранённый снимок `sgtin`; остальные виды
  метаданных заказа сохраняются.
- **R3.** Если полноценная локальная привязка уже потеряна, но снимок ещё содержит
  значение `sgtin`, очистка всё равно удаляет значение у WB и очищает снимок.
- **R4.** После очистки открытая упаковка перечитывается сразу, поэтому старый хвост
  исчезает без ожидания фонового обновления.
- **R5.** При удалении полноценной привязки сохраняется прежняя логика освобождения
  кода из пула и пересчёта счётчиков упаковки.

## Проверки

| ID | Проверка | Вердикт |
|---|---|---|
| P1 | Две активные поставки «Фабрики» перечитаны после очистки: непустых значений ЧЗ у WB, локальных привязок и ключей `sgtin` не осталось | Пройдено на production |
| P2 | Сборка backend/frontend | Не запускалась отдельно по прямому требованию владельца о срочном hotfix; production image build обязателен при выкладке |
| P3 | Экран перечитывает workspace сразу после массовой очистки | Подтверждено чтением итогового diff |

## Заключение

Данные двух текущих активных поставок «Фабрики» очищены и повторно сверены с WB.
Кодовый hotfix подготовлен к срочной production-выкладке без отдельного тестового
прогона по прямому указанию владельца.
