# WMS-563 · Вывод КИЗ из оборота в портале селлера: вкладка, загрузка списка, «Выбрать все» на все КИЗ

## Исходный запрос

28.09.2026, владелец: «и ещё момент - на проде у авпак сейчас при попытке открыть раздел с выводом кизов из оборота - просто перекидывает его на вкладку товары и всё»

## Уточнения владельца

После разбора: «Да, именно в документы выкидывать. Надо закрыть это нахуй. Нужно, чтобы это работало четко. Сколько бы там не было кизов у него, хоть тысячи, все должно отображаться. По кнопке, кстати, что очень важно, да? Если там будет отображение по странично, если, то галка «Выбрать все», она должна не только на эту страницу действовать, а вообще. Ну, понял, да? Потому что иначе, если тысячи кизов, ты заебешься листать страницы.»

Затем: «отъебись от аналитиков, пожалуйста, сделай это быстро сам, это элементарная правка, тебе нужно путь починить, чтобы он, блядь, не падал. И выбор, все, это здесь не нужны никакие скиллы». Аналитик и навыки не используются; ведущий делает правку сам.

## Что было на бою (5c57de2a, проверено 28.09.2026)

- Вывод разрешён одному селлеру — «ИП Горячкина Т.И.» (AVpack).
- Портал селлера смонтирован с basename `/seller`, а вкладки «Пулы КИЗ» / «Вывод из оборота» дописывали ещё `/seller` → `/seller/seller/honest-sign/withdrawals` → неизвестный путь → редирект в «Документы». Воспроизведено в браузере на локальном стенде из 5c57de2a.
- По прямому адресу экран открывался, но список не грузился: `limit=50` из адреса запроса приходил строкой, параметр был объявлен как `Literal[50, 100, 250]` → 422. Воспроизведено на стенде и на боевых версиях pydantic/fastapi в боевом контейнере.
- «Выбрать все» действовало только на видимую страницу, смена страницы сбрасывала выбор; сервер принимал не больше 250 КИЗ в одной операции.

## Требования

- R1. Вкладки «Вывод из оборота» и «Пулы КИЗ» в «Честном знаке» портала селлера открывают свои экраны и не выбрасывают в другой раздел.
- R2. Экран вывода загружает список КИЗ с размерами страницы 50/100/250; все КИЗ по фильтрам доступны для просмотра по страницам.
- R3. Галка «Выбрать все» в заголовке таблицы выбирает все доступные для вывода КИЗ по текущим фильтрам на всех страницах (в том числе из частичного выбора); при полном выборе нажатие снимает выбор. Выбор сохраняется при листании страниц и смене размера страницы; смена фильтров сбрасывает его, как и раньше.
- R4. Выбранные на разных страницах КИЗ уходят одной операцией вывода. Предел одной операции — 10 000 КИЗ (технический: Postgres принимает до 32 767 параметров в запросе, выбор попадает в IN-списки дважды); сверх него показывается понятное сообщение.
- R5. Остальной экран (фильтры, колонки, статусы, подпись КриптоПро, повтор и возобновление операций) не меняется. Убрана только ставшая неверной подпись «Выбор действует только на текущей странице».

## Заключение

Правка сделана ведущим без аналитика и навыков по прямому указанию владельца; перекрёстное ревью не проводилось. Вкладки и загрузка списка исправлены, «Выбрать все» действует на все КИЗ по фильтрам и отправляет их одной операцией. Реальная подпись и отправка в Честный знак не проверялись: на стенде нет КриптоПро, реальные КИЗ ради проверки не выводились. Выкладка на бой — отдельно, по команде владельца.
