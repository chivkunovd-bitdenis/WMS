## Что проверено при заведении

- Код прода 694de0413: у документа отгрузки FBO вкладки «Товары», «Подбор», «Упаковка»
  (FfSuppliesShipmentsPage.tsx); печати листа подбора в FBO нет. Общей вкладки подбора по
  нескольким отгрузкам FBO в разделе нет.
- В FBS лист подбора уже печатается с вкладок «Состав» и «Подбор» карточки поставки, печати
  только по выбранным ячейкам нет и там.
- Отгрузку FBO сейчас переделывает WMS-686 (подбор по ячейкам, КИЗ, упаковка по коробам; на стенде,
  в etalon не влито) — эту задачу делать поверх неё, не в обход.
- Экран в браузере при заведении не открывался: во встроенном браузере нет входа на прод.

## Требования (предварительно, аналитик уточняет по экрану)

R1. В разделе FBO есть общая вкладка «Подбор».
R2. Лист подбора печатается с вкладки «Подбор».
R3. Лист подбора можно напечатать только по выбранным ячейкам.

## Открытые вопросы аналитику

1. «Общая вкладка» — подбор сразу по нескольким отгрузкам FBO (как групповая сборка FBS) или
   иное — уточнить у владельца.
2. Строки 2 и 3 относятся только к FBO или и к FBS (в FBS вкладка «Состав» убирается задачей
   WMS-723) — уточнить у владельца.
