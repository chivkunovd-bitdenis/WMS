## 2. Существующий процесс (проверено чтением кода 09.10.2026)

- Отгрузка FBO — полноэкранный документ «Отгрузки на МП» (FfSuppliesShipmentsPage.tsx), вкладки
  «Товары», «Подбор», «Упаковка». «Подбор» открывается после «Утвердить»: сервер отдаёт данные
  подбора только в статусах confirmed и collecting (marketplace_unload_status.EXECUTION_STATUSES).
- Переключатель «По ячейкам / По товарам», раскрываемые ячейки и короба, столбцы «План»,
  «Осталось», «КИЗ», «Остаток в коробе», «Собрано» есть только в ветке WMS-686
  (claude/wms686-fbo-impl, выложена на стенд, в etalon 61012808c не влита). В etalon и на проде
  694de0413 подбор FBO — вид «от товара» без переключателя.
- Данные экрана подбора — GET /operations/marketplace-unload-requests/{id}/pick-options: по
  каждому товару ячейки (location_code, quantity, available, picked) и источники в ячейке
  (container_path — короб/тара, is_loose «Россыпью», quantity, available, picked).
- Печати листа подбора в FBO нет ни на проде, ни на стенде. В FBS лист печатается отдельным
  шаблоном (fbsUx.ts) — для FBO его структура не подходит.
- Галок выбора ячеек и коробов на экране подбора FBO нет.

## 3. Требования (предварительно, аналитик уточняет)

R1. На вкладке «Подбор» отгрузки FBO есть кнопка «Печать листа подбора».
R2. Если ничего не выбрано, печатается полный лист подбора по отгрузке.
R3. Вид листа следует выбранному переключателю. «По товарам» — разлинованная таблица: товар
(название) → ячейки, где он лежит → короба с номерами в этих ячейках → количество штук.
«По ячейкам» — та же таблица наоборот: ячейка → короб → товар → количество.
R4. На вкладке «Подбор» у ячеек и коробов (тары) есть галки выбора.
R5. Если что-то выбрано, печатаются только выбранные строки, структура листа та же (пример
владельца: под товаром только две ячейки с двумя коробами).
R6. Ячейку отдельно от содержимого выбрать нельзя: выбирается ячейка с коробом. Если в ячейке
есть тара и конкретная тара явно не выбрана — печатается вся тара этой ячейки; если выбрана
конкретная — только она.
R7. Печать и выбор не меняют остаток, расположение и подбор.

## 4. Решения и вопросы аналитику

1. Задача строится поверх WMS-686 (переключатель есть только там): база разработки — ветка
   WMS-686 или etalon после её влития; аналитик фиксирует это до тестов.
2. «Количество штук» в листе — остаток в коробе, «взять» или оба — решить по экрану подбора;
   владельцу вопрос, только если экран не даёт однозначного ответа.
3. Как печатать «Россыпью» (товар в ячейке без короба) и товар без ячейки.
