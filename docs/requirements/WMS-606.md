# WMS-606 — доступность основной печати при ЧЗ = 0

## Исходный запрос

30.09.2026 владелец приложил экран окна «Печать ЧЗ, ШК и QR заказа» с ЧЗ = 0, ШК ВБ = 1, готовым макетом QR и штрихкода и отключённой кнопкой «Печать»: «блядь ты поломал основную печать? почему там не доступна кнопка печати».

Исправление выполняется срочно без аналитика в продолжение прямого указания владельца «убери аналитика, просто сделай быстро».

## Причина и требования

Последнее изменение WMS-605 не меняло компонент основной печати. Дефект находится в прежнем условии доступности: любой товар, которому в принципе нужен Честный знак, требовал ненулевой пул даже после удаления блока ЧЗ из текущего макета.

| ID | Требование |
|---|---|
| R1 | В ленте FBS с ЧЗ = 0 и хотя бы одним QR или штрихкодом кнопка «Печать» доступна независимо от остатка кодов ЧЗ. |
| R2 | Макет, который содержит хотя бы один блок ЧЗ, сохраняет действующую проверку пула и нехватки кодов. |
| R3 | Печатаются только выбранные QR и штрихкоды; установка ЧЗ = 0 не выпускает и не списывает код ЧЗ. |
| R4 | Исправление не меняет печать коробов Ozon из WMS-605 и публикуется с проверенным Git SHA. |

## Проверки

| Проверка | Требования | Вердикт |
|---|---|---|
| ЧЗ = 0, ШК = 1, QR есть, пул = 0. | R1,R3 | Подтверждено целевым тестом: пул не требуется, доступна 1 печатаемая единица. |
| ЧЗ = 1, ШК = 1, пул = 0. | R2 | Подтверждено целевым тестом: пул требуется, доступно 0 печатаемых единиц. |
| Целевые тесты, TypeScript и production-сборка. | R1,R2,R4 | Подтверждено: 15 тестов, `tsc --noEmit` и `npm run build` завершились с кодом 0. |
| Версия и публичный веб-файл production. | R4 | Ожидает выпуска. |

## Заключение

Локальные проверки пройдены. Фактическая версия production и доступность публичного веб-файла проверяются после выпуска; физическая печать оператором пока не подтверждена.
