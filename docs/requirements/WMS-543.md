# WMS-543 · Инвентаризация: «Создать короб/палету/грузоместо» ставит тару в пикнутую ячейку

## 1. Запрос и уточнения

Владелец 27.09.2026 перед первичной инвентаризацией ArtMaks: «короба, тара будет создаваться, всё …
сейчас всё готово к тому, чтобы много товара принять в систему, правильно?»
Ведущий на стенде нашёл: после пика ячейки «Создать короб» создаёт короб без ячейки (в «Без ячеек»).

## 2. Требования

| № | Требование |
|---|---|
| R1 | Если в таблице не выделена строка, а сканером открыта ячейка (пик ячейки), «Создать короб», «Создать палету», «Создать грузоместо» создают тару в этой открытой ячейке. |
| R2 | Если выделена строка ячейки или тары — поведение как сейчас (выделение важнее). |
| R3 | Ничего не открыто и ничего не выделено — как сейчас (тара без ячейки). |
| R4 | Интерфейс не меняется, новых блокировок нет. |

Принято ведущим по проверкам C1–C3 на стенде. Перекрёстное ревью не проводилось — по указанию владельца без лишних кругов (правка на 3 кнопки и одну чистую функцию).
