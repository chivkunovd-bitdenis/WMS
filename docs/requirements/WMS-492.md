# WMS-492 · Общий подбор FBS-заказов разных селлеров

## Исходный запрос

Встреча 21.09.2026, пункт 6: «общий подбор FBS-заказов разных селлеров с приоритетом срока и опциональным фильтром». Источник — приложенная к диалогу аудиозапись `PSP.m4a`; временная рабочая расшифровка в репозиторий не добавлялась.

## Текущий процесс

В `FfFbsOrdersScreen` можно видеть заказы всех селлеров или фильтровать селлера. Но выбранные заказы для поставки должны совпадать по селлеру, площадке и складу. Общий межселлерский процесс подбора не подтверждён. Живой UI не проверялся.

## Требования

**R1.** Оператор может начать один подбор по готовым к сборке FBS-заказам разных селлеров.

**R2.** Без фильтра очерёдность задаётся ближайшим сроком отгрузки; оператор может ограничить подбор одним селлером.

**R3.** Остаются границы селлера, площадки, склада и заказа; общий подбор не объединяет сами поставки.

## Открытый вопрос

Общий подбор смешивает WB и Ozon или ведётся отдельно по площадке? Это меняет состав очереди и должно быть решено до реализации.
