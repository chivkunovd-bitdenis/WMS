# WMS-608 — мгновенное выделение отсканированной строки упаковки

## Исходный запрос

30.09.2026: после скана строка слишком долго не становилась зелёной. Владелец
попросил не прокручивать список к ней, а сразу поднимать отсканированную строку
на первое место. Правка нужна срочно и только для текущего веб-экрана упаковки.

## Требования

R1. После успешного распознавания скана соответствующий заказ сразу становится
первой строкой списка упаковки.

R2. Эта строка сразу получает зелёную подсветку, не ожидая печати и фонового
перечитывания вердикта WB. Текст статуса WB продолжает показывать фактический
ответ площадки.

R3. Экран не прокручивается к прежнему положению отсканированной строки.

R4. Сохранение ЧЗ, упаковка, печать и обработка ошибок не меняются.

## Проверки

| Проверка | Требования | Вердикт |
|---|---|---|
| TypeScript | R1-R4 | Пройдено: `npx tsc --noEmit -p tsconfig.app.json` |
| Последовательный сканер упаковки | R1,R4 | Пройдено: 15 целевых тестов |
| Production build фронта | R1-R4 | Пройдено: `npm run build` |
| Реальный скан на экране production | R1-R4 | Не проверено |

## Заключение

Последний распознанный заказ поднимается первой строкой и сразу получает зелёную
подсветку. Три вызова прокрутки к строке удалены. Статус WB остаётся отдельным
фактическим статусом и обновляется прежним фоновым запросом. Сервер, печать и
сохранение упаковки не менялись. Реальный скан на production ожидает выкладки.
