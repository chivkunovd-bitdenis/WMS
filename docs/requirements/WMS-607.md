# WMS-607 — запуск и прямая печать QR без настройки подключения

## Исходный запрос
30.09.2026: срочно исправить WMS Print. Windows и Mac: запустить программу,
сканировать из Chrome, сразу печатать QR системным принтером по умолчанию.
Без адресов, кодов сопряжения, выбора очереди, навыков, агентов и большого набора тестов.
Последнее указание владельца отменяет агентную цепочку для этой задачи.

## Требования
R1. Запуск отдельной программы без вопросов о сервере/складе/коде/принтере.
R2. Прямой приём подготовленной QR-этикетки из Chrome без window.print.
R3. Использовать текущий принтер ОС по умолчанию для каждого нового задания.
R4. Сохранить последовательность и не дублировать задание после потери ответа/перезапуска.
R5. Самостоятельные пакеты Windows x64 и macOS; исходники и SHA сохранены в Git.
R6. Программа открывает готовую локальную страницу проверки в Chrome.
R8. Уточнение владельца: «важно работать должно мгновенно прям за секунду».
Цель — скан → квитанция ОС менее 1000 мс; механика физического принтера измеряется отдельно.
R7. Не менять настройки безопасности ОС/Chrome. Первое системное разрешение
для загруженного приложения или обращения сайта к localhost нельзя обещать устранить.

## Заключение
Прямая печать реализована, закоммичена и опубликована в codex/wms607-instant-print.
На Mac подтверждена передача из обычного Chrome в системную тестовую очередь
менее секунды, включая упакованное приложение; физическая бумага и Windows-принтер
не проверены. Для интеграции создана ветка от актуального staging d811ae78 с уже сохранёнными
исправлениями WMS-604. Перенесены только файлы транспорта и программы WMS-607;
выкладка подтверждена Railway SUCCESS и чтением опубликованного FBS bundle. Полной складской приёмки нет.
Отдельного ревью/приёмки агентами нет по прямому указанию владельца.
Доказательства: [print-proof.json](../evidence/WMS-607/print-proof.json).

## Совместимость с параллельной WMS-604
Владелец предупредил о соседней правке. Проверены незакоммиченные изменения
`.worktrees/wms604-staging`: общий список, загрузка стикеров, выбор размера и
исследование признака ЧЗ остаются в соседней задаче. Эти файлы не изменены.
Сохранён экспорт `dispatchPreparedQrInKiosk`, используемый staging-версией
WMS-604; он направляет печать в локальную программу без вызова Chrome print.
Точный origin текущего staging разрешён программой. Наш транспорт выложен на staging поверх сохранённой WMS-604; production не менялся.

Интеграция выполнена от origin/staging d811ae78 отдельным переносом файлов WMS-607,
без слияния старого дерева WMS-604. Чужие незакоммиченные изменения не затронуты.
