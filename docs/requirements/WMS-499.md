# WMS-499 · Выгрузка FBS-заказов в Excel по статусам

## Исходный запрос

Встреча 21.09.2026, пункт 18: «выгрузка FBS-заказов в Excel». В расшифровке отдельно названы доставка, завершённые и просроченные заказы. Источник — приложенная к диалогу аудиозапись `PSP.m4a`; временная рабочая расшифровка в репозиторий не добавлялась.

## Текущий процесс

В `FfFbsOrdersScreen.tsx` уже есть «Скачать Excel»: выгружаются выбранные строки или весь текущий список. Но кнопка показывается только для группы `new`; имя файла также `fbs-new-orders-...xls`. На названных вкладках выгрузка не подтверждена.

## Требования

**R1.** Выгрузка Excel доступна как минимум для FBS-заказов в доставке, завершённых и просроченных, а не только на вкладке «Новые».

**R2.** Файл содержит тот же набор, который видит оператор после текущих фильтров; если выбраны строки, выгружаются они.

**R3.** Выгрузка сохраняет разделение арендаторов и права доступа.

## Открытый вопрос

Какие обязательные колонки нужны именно для исторических/доставляемых заказов сверх текущих восьми? Без ответа можно расширить географию текущего формата, но не придумывать новый состав.

## Проверки

| ID | Требование | Проверка | Вердикт |
|---|---|---|---|
