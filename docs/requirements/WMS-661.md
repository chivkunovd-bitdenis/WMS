## Исходный запрос и требования

R1. Бот ищет существующую тему по смыслу, объекту и процессу; связывает сообщение с ней. Новый ticket/документ/карточка только при отсутствии дубля.

R2. Сохранить существующие права и границы клиентов, связать с той же канонической темой. Тесты, PR, установка бота, стенд и production подтверждаются отдельно.
