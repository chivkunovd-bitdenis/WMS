# WMS-605 — одна лента для печати коробов Ozon

## Исходный запрос

30.09.2026: «Сейчас печать всё, кнопка печать всё на Озоне показывает полную хуету, когда печатаешь короба. Потому что она, блядь, открывает тебе каждый, нахуй, каждую пару QR и коробка, блядь, в отдельных, нахуй, в отдельных, нахуй, вкладках. А должна это быть всё сплошная лента, блядь. Исправь это без киллов срочно на проде.»

Уточнение владельца: «блядбь уюери аналитика сука / просто сделай быстро». Применён аварийный путь `EMERGENCY_BYPASS`; аналитик остановлен по просьбе владельца.

## Существующее поведение и требования

На вкладке «Короба» поставки Ozon кнопка «Печать всех QR» собирает готовые PDF-этикетки и открывает окно предпросмотра. При печати код вызывает `window.open` для каждого PDF, поэтому браузер открывает много вкладок и не даёт одной непрерывной ленты. Сервер уже сохраняет все страницы этикетки отправления в одном PDF; их нельзя терять или изменять размер.

| ID | Требование |
|---|---|
| R1 | Нажатие «Печать готовых» после «Печать всех QR» открывает одну вкладку с одним PDF, содержащим все страницы готовых этикеток Ozon по порядку коробов. |
| R2 | Страницы каждой этикетки остаются рядом и сохраняют размер и содержимое. Выбранное число копий повторяет каждую полную этикетку перед переходом к следующему коробу. |
| R3 | Отказ загрузки или сборки PDF показывает ошибку в окне предпросмотра; пустое окно закрывается. Одиночная печать и печать изображений WB продолжают работать. |
| R4 | Исправление не вызывает операций с заказами или коробами, не останавливает процессы вручную и публикуется только после проверки Git SHA и версии продакшена. |

## Проверки

| Проверка | Требования | Вердикт |
|---|---|---|
| Два PDF по две страницы, две копии: итоговый PDF содержит восемь страниц в порядке 1,1,2,2 и с исходным размером каждой страницы. | R1,R2 | Подтверждено локальным тестом `fbsPdfPrintTape.test.ts`; реальный принтер не проверен. |
| Обработчик PDF открывает одно окно для всей пачки; одиночный PDF использует тот же путь; изображение WB использует прежний печатный документ. | R1,R3 | Подтверждено чтением итогового кода; браузерный сценарий с живой поставкой не проверен. |
| TypeScript, целевой тест и production-сборка фронта. | R1,R2,R3 | Подтверждено локально: `npx tsc --noEmit -p tsconfig.app.json`, `npx vitest run src/screens/v2/fbsPdfPrintTape.test.ts`, `npm run build` завершились с кодом 0. |
| Неготовый или ошибочный PDF, повтор печати и фактическая вкладка браузера. | R3 | Не проверено на реальной поставке Ozon; не выполнялся вызов Ozon. |
| Commit, push и чтение версии prod после публикации. | R4 | Ожидает публикации. |
