# WMS-633 — Упаковка WB: число экземпляров ЧЗ при печати по скану

Дата: 02.10.2026. Мелкая задача по прямому поручению владельца: без аналитика,
реализация и проверка — разработчик (Opus, фронт).

## Исходный запрос

> Если включены галки Печать ЧЗ или Перепечать ЧЗ, при включении галочки рядом с ней
> появляется маленькая цифра, которую можно просто вверх-вниз кликать: один, два, три.
> Если выбрано три, то когда я делаю скан ШК, у меня вылазит честный знак именно в трёх
> экземплярах.

Уточнения ведущего: числовое поле MUI (small, ~56 px, 1–10, по умолчанию 1), видно
только при включённой галке; значение хранится в тех же предпочтениях отдельно для ЧЗ
и для копии; старые предпочтения без поля = 1. N экземпляров — N отдельных заданий
WMS Print; ключ первого — прежний, i-го (i ≥ 2) — прежний + `:c<i>`. N фиксируется в
момент скана. QR всегда 1; порядок: QR, затем N этикеток.

## Требования

- R1. Рядом с «Печатать ЧЗ» и с «Перепечатывать ЧЗ» в общем компоненте галок
  (обычная поставка WB и «Сборка») — узкое числовое поле 1–10, по умолчанию 1, видно
  только при включённой соответствующей галке. Значения сохраняются в предпочтениях
  печати по скану отдельно для ЧЗ и для копии; сохранённые ранее предпочтения без
  поля дают 1. Других изменений интерфейса нет.
- R2. Скан при N > 1 печатает N этикеток ЧЗ из пула (или N точных копий при
  «Перепечатывать ЧЗ») отдельными заданиями WMS Print. Ключ первого — прежний
  (`<scan>:chz` / `<scan>:copy`), остальных — `…:c2 … :cN`. N берётся из снимка галок,
  сделанного в момент скана. QR печатается один раз, до этикеток ЧЗ.
- R3. Повтор того же скана после сбоя не печатает уже принятые WMS Print экземпляры
  (идемпотентность по ключу) и допечатывает недостающие.
