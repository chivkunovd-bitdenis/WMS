## 2. Проблема и цель

В живом проходе ТСД на скан чужого штрихкода сервер отказал с кодом
`product_not_in_seller_catalog`, а экран показал этот сырой код. Кладовщик не
понимает, что товар отсутствует в каталоге селлера, и может принять отказ за
сбой приложения. Источник: `/Users/deniscivkunov/Projects/WMS/.worktrees/_night-20261010/lanes/live-intake-sort.md`, P1-3.

В проверенной версии `741c564` общий словарь ошибок уже переводит шесть
перечисленных кодов. При отказе скана операция остаётся отклонённой: проверка
входящего скана подтверждает, что фактическое количество не увеличивается.

## 3. Требования

### R1. Понятное сообщение при отказе

Когда API отклоняет скан или связанную операцию одним из перечисленных кодов,
на каждом экране, который показывает этот отказ, ТСД отображает соответствующий
русский текст вместо сырого кода. Меняется только формулировка: статус отказа,
исходный код и существующие решения приложения о повторах или неопределённом
результате сохраняются.

| Код | Текст для пользователя |
|---|---|
| `product_not_in_seller_catalog` | Товара нет в каталоге селлера |
| `barcode_ambiguous` | Штрихкод подходит нескольким товарам |
| `product_seller_mismatch` | Товар относится к другому селлеру |
| `product_not_found` | Товар не найден |
| `mutation_payload_mismatch` | Эта операция уже отправлена с другими данными |
| `mutation_result_deleted` | Сохранённый результат операции больше недоступен |

Основание: запрос владельца и live P1-3. Формулировки нейтральны к экрану,
поскольку общий словарь используется несколькими потоками приложения.

### R2. Коалесценция отложена

Коалесценция очереди сканов не входит в эту приёмку. По решению модератора
измерение скорости и решение о коалесценции перенесены на период после выпуска;
ветка `tsd/wms747-intake-scan-speed` сохранена (remote ref
`64ce26083a14aa8269b195f411968b0c1d90d816`). Причина: живой проход выявил
последовательные запросы с перечитыванием приёмки на скан, но проход выполнялся
на перегруженном хосте и не даёт пригодного замера для выбора оптимизации.
