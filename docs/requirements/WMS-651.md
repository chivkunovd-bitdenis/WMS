# WMS-651 · Переименовать счётчик «Упаковано» в списке упаковки FBS

Источник: чат 689889703, сообщения #28, #29.
Версия описания: `a38a4faeb08a362b6ee0`. Подтверждение автора: #29.

## Ожидаемое поведение

На вкладке поставки FBS «Упаковка и маркировка» переименовать подпись счётчика в строке прогресса: вместо «упаковано X из Y» показывать «Принято WB X из Y». Меняется только пользовательская подпись существующего счётчика workspace.progress.packed; расчёт, действие «Всё упаковано», статусы, API и остальные элементы экрана не меняются. Использовать существующий компонент и оформление строки прогресса, не добавлять новые сущности, блокировки или отдельный экран.

Требования:
R1. В заголовке списка упаковки FBS рядом со счётчиком печати отображается текст «Принято WB X из Y» вместо «упаковано X из Y».
R2. Значения X и Y остаются теми же, что сейчас берутся из workspace.progress.packed и workspace.progress.total.
R3. Кнопка «Всё упаковано», логика упаковки, запросы к Wildberries и навигация по этапам не меняются.

Проверки:
P1. Открыть поставку WB FBS на вкладке «Упаковка и маркировка» и убедиться, что строка показывает «Напечатано … · Принято WB X из Y».
P2. Убедиться, что слово «упаковано» в этом счётчике больше не отображается.
P3. Убедиться, что до и после переименования числовые значения счётчика совпадают и действие «Всё упаковано» работает без изменений.
