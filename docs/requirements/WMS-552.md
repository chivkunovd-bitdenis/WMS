# WMS-552 · Привязка QR ячеек ArtMaks

## Запрос и требования

Владелец предоставил `wms_codes.csv` и `WMS — привязка QR к ячейкам.xlsx`,
поручил привязать коды и исправить сканирование. Отдельно подтвердил создание
шести отсутствующих ячеек А/Б/В/Г/Д/Е-5-22. Потребовал выполнить лично, без
дальнейшего участия агентов и без усложнения.

- R1: 882 строки обоих файлов совпадают. Привязать barcode строго по адресу;
  сохранить ID и адрес 876 существующих ячеек, добавить только шесть согласованных.
- R2: Сканер сортировки сначала ищет сохранённый barcode среди всех ячеек,
  затем название. `V-1-1` открывает В-1-1, не М-1-1. Поддержать раскладку и AIM.
- R3: Не менять остатки, товары, короба и логику размещения. Обновление в одной
  транзакции после проверки адресов и уникальности кодов в пределах tenant.

## Проверки

| Проверка | Вердикт |
|---|---|
| CSV и XLSX, уникальность адресов/кодов | PASS: 882 одинаковые строки, дублей нет |
| Production preflight | PASS: 876 адресов, только шесть согласованных отсутствуют; старые barcode LOC |
| Поиск ячеек, тара, товар, повторный скан | PASS 6/6: все 882 кода в обеих раскладках, с AIM и без, открытие и повторное закрытие |
| Привязка, уникальность, сохранность данных | Dry-run PASS: 876 обновлений и ровно шесть согласованных добавлений, конфликтов barcode нет; parser test PASS |
| Типы и frontend build | PASS на двухстрочной правке production-кода |
| Данные и production после применения | Ожидает применения и проверки |

## Заключение

Узкая правка поиска и разовая привязка данных. Перекрёстная приёмка не проводится
по прямому требованию владельца работать без агентов; Opus ранее недоступен.
До выкладки и контрольного чтения результат не считается проверенным на production.
