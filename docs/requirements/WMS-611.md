# WMS-611 — ФБС: не блокировать печать снимком свободного пула ЧЗ

## Исходный запрос и уточнение

«у империи львов не работает снова печать - не активна кнопка печать в модалке печати из ФБС
вчера уже был такой баг
надо срочно поправить».

Уточнение: «убери назуй скиллы блядб быстро правь». Выполнено напрямую, без цепочки навыков, аналитика и перекрёстного ревью.

## Причина и границы подтверждения

Вчерашний WMS-606 присутствует в production checkout da80c12d и публичном JS:
макет без блока ЧЗ уже не требует пула. Осталась другая клиентская блокировка:
при наличии блока ЧЗ кнопка зависит от `markingAvailable` и `markingShortage`,
полученных при открытии упаковки. Эти данные могут устареть; свободный пул также
не учитывает уже привязанные к заказу коды. Сервер печати уже проверяет актуальную
нехватку по товарам и существующие привязки перед выдачей новых кодов.

Конкретный заказ оператор не сообщил. Точная причина его текущего случая пока
не подтверждена. Устранён воспроизводимый дефект общей формы, не меняя данные
поставок, коды и серверные правила печати.

## Требования

- R1. При выбранных заказах ФБС снимок свободного пула и нехватки не выключает кнопку печати; текущую возможность проверяет сервер.
- R2. При реальной нехватке сервер возвращает причину в открытой форме; без выбора частичной печати соответствующий параметр остаётся false.
- R3. Во время выполнения и при пустом выборе кнопка недоступна. Проверки пула вне ФБС сохраняются.
- R4. Печать QR/штрихкодов без ЧЗ из WMS-606 сохраняется.
