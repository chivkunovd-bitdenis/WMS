# WMS-689 — Срочно отключить автоматическую синхронизацию каталога WB

Исходное поручение владельца 07.10.2026: «Убей нахуй эти процессы синхронизации каталога 56 тысяч товаров нахуй. Выруби их».

R1. Прекратить выполняющиеся и ожидающие автоматические задачи `wms.wb_catalog_hourly_sync`.
R2. Убрать повторный запуск `wb-catalog-hourly` из рабочего расписания production.
R3. Сохранить остальные фоновые расписания, API, базу и данные каталога.
R4. Сохранить конфигурацию отключения в Git и проверить фактическое состояние сервера. Полный выпуск новой версии продукта и merge в main не входят в поручение.

Операционная конфигурация `deploy/ops/wb-catalog-disabled.compose.yml` применяется последней после production и host overlay. Она меняет только команду планировщика, удаляет одну запись перед запуском Celery beat и позволяет пересоздать только этот сервис без сборки образов. Включение обычного production Compose без этого файла может вернуть исходное расписание: следующая полная выкатка должна сохранять этот override до отдельного решения владельца.

## Заключение

Автоматический полный обход каталога WB операционно отключён 07.10.2026 в 09:04:51 UTC (13:04:51 Asia/Tbilisi). Пересоздан только `wms_prod-celery_beat-1`, с прежним образом, новым override и без сборки/API-деплоя. Применённый файл: `/opt/wms-maintenance/wms689/wb-catalog-disabled.compose.yml`, SHA-256 `4f9f2809d0e1166e37b98ff669e5f146dc310de18f7027172731f7b7b9b9e63e`.

После применения worker CPU составил 2,49%, API 6,05%, PostgreSQL 0,07% в одном контрольном замере. Это подтверждает низкую текущую нагрузку, но не является доказательством исчезновения всех задержек операторов или причинного эффекта именно отключения: длинный проход завершился до адресного revoke.

Для следующей полной выкатки использовать последний аргумент `-f /opt/wms-maintenance/wms689/wb-catalog-disabled.compose.yml`. Обычный скрипт выпуска пока автоматически не подхватывает этот файл. В main/etalon изменения не вносились; отдельная продуктовая приёмка и полный CI не заявляются для операционного отключения.
