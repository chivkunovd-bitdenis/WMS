# WMS-701 · Рабочий бумажный подбор FBS: источники, количество и расход из тех же коробов

Обращение №5 `imperiya-picking-sources-895`, чат «Короб / ФФ Империя Львов»
(`-4899527415`). Требование уже связано с открытой

Видео Telegram 411 / материал 899 добавляет бизнес-результат: собрать физически

Настоящий документ регистрирует постановку по поручению владельца через модератора.
Реализация, изменение складских данных и выпуск этим поручением не разрешаются.

## Существующий процесс и подтверждённая причина

[WMS-528](WMS-528.md) задавала короткий бумажный список источников, покрывающих
оставшееся количество подбора. Это не контракт о списании товара из напечатанного
распределения без ручного заполнения подбора.

Сохранённый разбор `var/support-conversations/moderator/imperiya-successor4-result.json`
подтвердил причину свежего расхождения: печать сначала получает короткие источники,
затем подменяет их полной историей приходов и всеми местами. Печатный список
предпочитает эту полную группировку. В текущем экране «Собрать» повторяет общий
план товара у каждого места, поэтому его нельзя выдавать за доказанный отдельный
план для каждого короба. Бумажный выбор и автоматический расход без сохранённого
подбора используют разные порядки выбора источников.

Источники этого разбора: `FfFbsSupplyWorkspace`, `FfFbsSupplyAssembly`, `fbsUx`,
`fbs_picking_print_service`, `FbsCellPickTable`, существующий сервис определения
источников отгрузки; точные ссылки и кадры находятся в сохранённом результате.
Повторная проверка рабочей системы этим документом не заявляется.

Поэтому изменения только шаблона недостаточно: согласованное распределение должно
сохранять смысл между экраном, бумагой и последующей передачей. Технический способ
определяется при реализации из существующих механизмов подбора и отгрузки.
Новый обязательный режим, скан, блокировка, журнал или независимый учёт остатка
не являются требованиями этой постановки.

## Требования

**R1. Рабочий источник на бумаге.** Для оставшегося к подбору количества товарной
позиции лист показывает конкретный текущий источник: ячейку, если она есть,
уникальный короб или другую тару либо россыпь. Приёмка или возврат показываются,
когда нужны для однозначного узнавания источника. Это указание, куда идти и откуда
брать, а не перечень всей истории товара.

**R2. Количество взять.** У каждого выбранного источника явно указано «взять N шт.»
именно из него. При нескольких источниках сумма N равна оставшемуся к подбору
количеству, если товара достаточно. Свободный остаток в коробе не выдаётся за N.
При нехватке видна реальная нехватка; ненайденный товар не дорисовывается.
Если всё уже подобрано, лист не рекомендует повторно брать те же единицы.

**R3. Альтернативы и согласованность.** Остальные фактические места доступны по
необязательному раскрытию на существующем экране компьютера. Основное рабочее
указание на экране и на бумаге отражает один согласованный выбор источников и N.
Общий план товара у каждой строки короба не подменяет количество из этого короба.
Исторический документ без текущего рабочего товара не показывается как место,
куда следует идти; сами документы и их история не удаляются.

**R4. Сборка по бумаге и передача.** Оператор может собирать по бумажному листу без
обязательного ручного заполнения подбора. При «Передать в WB» проводится расход
из тех же согласованных коробов и в тех же количествах. Нельзя независимо выбирать
другие источники на момент передачи только потому, что алгоритм авторасхода имеет
иной порядок. Если оператор использовал другой короб, существующий процесс должен
учесть фактический источник и сохранить согласованность; технический способ
подтверждения выбирается при реализации без навязанных дополнительных сканов.

**R5. Остаток, конкуренция и восстановление.** Печать, подбор и упаковка не списывают
остаток. Расход происходит при проведении передачи по существующим правилам.
Повтор одного запроса или восстановление после сбоя не создают второе списание
уже проведённого состава. При изменении расположения или одновременной работе
другого оператора нельзя молча выдавать устаревшее распределение за фактическое
или расходовать одну единицу дважды. Сохраняются существующие права, границы
клиентов и способы восстановления отгрузки; новые пользовательские блокировки
не вводятся без отдельного подтверждённого требования.

**R6. Охват печати и сбои.** Одинаковое рабочее указание действует для обычной
поставки и группового сборочного задания. Повторная печать учитывает уже выполненный
подбор. При сбое чтения данных лист и экран не выдают непроверенное место за
достоверное и не объявляют отсутствие остатка по сетевой ошибке. Сохраняется
существующая возможность продолжить работу с понятным предупреждением.

**R7. Границы изменения.** Существующий дизайн, данные вариантов товара,
маркетплейс, заказы, стикеры, маркировка и остальные колонки сохраняют смысл.
Текущая постановка не повторяет старые задачи о ширине колонки, ЧЗ или стикерах.
Частный вопрос физического короба 226 и приёмки 96 относится к отдельной карточке
обращения №8 и отложен клиентом; его исправление сюда не включается.
Также сюда не входит корректировка уже проведённой поставки `WB-GI-289512840`.
