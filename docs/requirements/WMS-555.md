# WMS-555 · Переход в основном списке и полный сброс ArtMaks

## Запрос и требования

Владелец отверг отдельный блок ячейки: нужен переход непосредственно к коробу
в основном списке, к ячейке в её списке, строго без анимаций. Поручил вернуть
весь товар приёмки #000007 в нераспределённую россыпь и оставить пустые короба.
Назвал 4039 приблизительно; read-only повторно подтвердил 4139, о расхождении
сообщено владельцу. Списания разницы не разрешены и не выполняются.

- R1: Удалить отдельный блок состава ячейки. Использовать существующий allRows
  в основной таблице, чтобы размещённый короб оставался доступным для перехода.
- R2: Сканы перемещают вид к реальной строке короба/плитке ячейки через instant.
  Убрать анимации, оставить обычную подсветку открытой тары. Без нового дизайна.
- R3: Сбросить только эту приёмку: 321 SKU, 4139 единиц в россыпи, 60 пустых
  коробов с прежними UUID/barcode, posted_qty=0, старое распределение очищено.
- R4: Сохранить все товарные итоги и журнал движений. Снимок перед сбросом
  приватный; проверка изменившихся данных прерывает транзакцию. Не запускать
  навыки/агентов и не выполнять тестовых сканов на production.
