## Ожидаемое поведение

В существующем процессе отгрузки WB FBO оператор собирает товары по накладной, затем распределяет их по коробам, созданным в WMS.

Для каждого короба WMS генерирует и позволяет напечатать штрихкод самого короба для приёмки в WB. Один и тот же код используется в WMS и передаётся в WB. Сохранить существующий уникальный идентификатор и механизм кодов коробов, не создавая второй независимый код для того же короба.

После распределения товаров нужны оба способа передачи состава коробов:
1. Выгрузка из WMS файла для загрузки в кабинет WB.
2. Прямая передача из WMS в соответствующую поставку WB.

В обоих способах должны совпадать коды коробов, товары и количества из WMS; данные относятся к соответствующей отгрузке и селлеру.
