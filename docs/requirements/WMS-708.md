# WMS-708 · Инструкции базы знаний по обращениям поддержки

## Исходный запрос

За 1–8 октября 2026 года разобрать сохранённые Telegram-обращения клиентов: вопросы и процессы, по которым поддержка давала объяснения или инструкции; найти уже существующие материалы; собрать инструкции в каталоге `docs/База знаний` в форматах Word и PDF, с действительными скриншотами интерфейса и проверенными последовательными выделениями. Не запускать продуктовый цикл, аналитиков, разработчиков, CI или тесты. Для подготовки использовать отдельных недорогих исполнителей, ведущий проверяет общий результат.

## Требования

| ID | Требование |
|---|---|
| R1 | Источники поддержки за 01–08.10.2026 просматриваются на предмет объяснённых клиентам процедур. Для каждого кандидата подтверждается содержание по сохранённым сообщениям; незавершённые обращения и неподтверждённые причины не описываются как готовое решение. |
| R2 | Существующие пользовательские инструкции проекта собраны в `docs/База знаний` вместе с используемыми изображениями и исходными редактируемыми материалами. Для каждой существующей инструкции доступны DOCX и PDF. |
| R3 | Для каждой новой инструкции, предназначенной клиентам или операторам, доступны парные DOCX и PDF с одинаковым содержанием. PDF содержит подлинные снимки экранов нужного безопасного demo/staging-процесса. Все номера и выделения идут по порядку, совпадают с текстом и указывают на соответствующие действия. Весь PDF просматривается после сборки. |
| R4 | Если правильный безопасный экран недоступен, соответствующий DOCX/PDF явно помечается как черновик и не выдаётся за завершённую инструкцию. Подходящие по смыслу скриншоты не подменяются снимками другого экрана. |
| R5 | В материалы не попадают значения ключей/паролей/PIN и не нужные для инструкции персональные, клиентские или складские данные. Ошибки и причины, которые не установлены перепиской или экраном, не угадываются. |
| R6 | Выполняются только подготовка документов и визуальная проверка этих документов. Код, данные и внешние рабочие системы не меняются; тесты и CI не запускаются согласно прямому поручению владельца. |
| R7 | Материалы и их фактический статус сохранены отдельным коммитом WMS в именованной ветке. Ветка может быть опубликована без создания PR, если это не запускает CI; CI и merge не выполняются по прямому поручению владельца. |

## Заключение

В базу знаний перенесены восемь существующих статей с исходными изображениями и парами Word/PDF. По обращениям подготовлены шесть новых пар DOCX/PDF: четыре по подключению/настройке маркетплейсов и магазинов, одна по подбору при отгрузке и одна по входу на ТСД. Все шесть остаются черновиками: реальных снимков текущего тестового стенда для них нет. В паре по подбору сохранён старый демонстрационный снимок приложения; его номера 1–3 визуально проверены, а отсутствовавшая ссылка на «шаг 4» удалена. Это не закрывает требование о снимках действий на стенде.

Обзор поддержки частичный: индекс использует 84 карточки локального журнала и выборочные проверки Telegram; полного экспорта всех чатов не было. По обращению №26 фото экрана «Подбор» и печатного листа подтверждают перестановку позиций 2 и 3; жалоба на списание остаётся без данных, позволяющих установить причину. Полный исходный запрос не принят до полного разбора доступных чатов и получения, вставки и визуальной проверки реальных снимков. Тесты и CI не запускались по прямому поручению владельца; код, данные и внешние настройки не менялись.
