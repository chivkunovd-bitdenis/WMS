# WMS-538 · Авария 26.09.2026: сайт ФФ стоит у ArtMaks и «Империи ФФ» из-за каталога

Запись задачи: [канонический бэклог, WMS-538](../KANONICHESKIY_BACKLOG.md#wms-538).

## 1. Исходный запрос

Владелец, 26.09.2026, дословно:

> Че у нас за пиздец с системой ? Не работают вход у клиента и попали нахуй все селлеры … ФФ арт
> у меня фул большой стоит не может работать
> блядь мне надо прямо сейчас на проде это всё починить

## 2. Установленные факты (бой, логи и замеры ведущего 26.09)

- GET /products/ff-catalog отвечает 500 у ArtMaks (18 раз) и «Империи ФФ» (9 раз): у «Империи» —
  `stack depth limit exceeded` на запросе `(seller_id, nm_id) IN (...)`; у ArtMaks после вчерашнего
  импорта 55 тыс. карточек ООО «Фабрика» — превышение 65 535 параметров psycopg.
- Замер на бою: без фильтра каталог ArtMaks (55 313 товаров) занимает 12–16 с чистого CPU, «Империи»
  (25 029) — ~11 с. API работает одним процессом uvicorn, поэтому на это время стоят все запросы всех
  клиентов (вход, профиль, селлеры). Сайт ФФ запрашивает этот каталог при каждом открытии
  (App.tsx refreshProducts), а селлеров грузит только после него.
- Фронт при не-ok ответе каталога продолжает работу (показывает товары без доп. ШК и грузит селлеров).

## 3. Требования

- **R1.** Полный каталог ФФ без фильтра (без seller_id и search) у арендатора больше 20 000 товаров
  отвечает сразу (HTTP 413 `catalog_too_large`) по одному count(*), не загружая каталог.
- **R2.** С фильтром по селлеру или поиску каталог работает как раньше.
- **R4.** Тяжёлый запрос одного клиента не останавливает API для остальных: API работает двумя процессами.
- **R3.** Запросы с длинными IN-списками в каталоге и связанных выборках идут порциями, результат
  не меняется.

## 5. Заключение

Экстренный хотфикс аварии по прямой команде владельца «прямо сейчас на проде починить». Реализация —
Claude Sonnet (Codex недоступен: 401), проверка диффа и тестов — ведущий. Перекрёстное ревью Astra
недоступно (Codex 401) — будет проведено после восстановления; приёмка аналитиком — после выкладки.
Полный каталог без фильтра для крупных арендаторов временно недоступен (экраны, которым он нужен, должны
использовать фильтр по селлеру или постраничный каталог) — развитие отдельной задачей.
