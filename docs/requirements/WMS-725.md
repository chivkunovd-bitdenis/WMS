# WMS-725 · FBS: печатный лист подбора — без нумерации, крупное фото, пустая «Подобрано», итог, шапка в одну строку

Статус: заведена 09.10.2026, не начата. Делается по полному процессу (аналитик → тесты до кода →
разработка → ревью → приёмка → CI). Пакет поручений владельца от 09.10.2026: WMS-716…WMS-732.

## Исходное поручение

09.10.2026, сообщение владельца в чате (дословно, с опечатками оригинала):
«из листа подбора убрать нумерацию + фотку большую сделать + граыа подобрано пустая + общее кол-во
по листу подьора + квадратики в шапке они были на одной строке с номером чтобы экономить место».

## Что проверено при заведении

- Код прода 694de0413 и etalon 61012808c, печатный лист подбора FBS (fbsUx.ts, «Лист подбора FBS»):
  первая колонка «№» с номерами позиций (1, 2–4 …); фото 42×42 px; колонка «Подобрано» печатает
  «подобрано / нужно»; общего количества по листу нет; под заголовком и строкой с названием
  поставки и номером идёт отдельный ряд из четырёх рамок «Селлер», «Склад WMS», «Маршрут»,
  «Сдать до».
- Этот же лист недавно меняли: WMS-673 (колонка «Цвет»), WMS-657 (колонка «Размер»), WMS-710
  (порядок печати для «Империи ФФ», хотфикс на проде). Их результат не должен потеряться.
- Бумажный лист при заведении не печатался; экран в браузере не открывался (нет входа на прод).

## Требования (предварительно, аналитик уточняет по экрану)

R1. В листе подбора нет нумерации позиций.
R2. Фото товара в листе крупнее нынешнего.
R3. Графа «Подобрано» печатается пустой — для отметки рукой.
R4. В листе есть общее количество по всему листу подбора.
R5. Четыре рамки шапки стоят на одной строке с номером поставки, чтобы экономить место (по словам
владельца, раньше так и было).

## Открытые вопросы аналитику

1. Насколько крупное фото — подобрать так, чтобы лист оставался читаемым на A4 альбомной.
2. Общее количество — сумма «Взять» по листу (единицы) или ещё и число позиций.
