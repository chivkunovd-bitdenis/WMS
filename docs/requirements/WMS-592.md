# WMS-592. Срочное восстановление непрерывного входа операторов

## Исходный запрос и уточнения

Владелец прислал экран FBS кабинета фулфилмента с ошибками и пустыми заказами. Затем прямо потребовал: «Никаких аналитиков ... Срочно на проде это правь ... У тебя 2 минуты».

## Причина и требования

Сегодняшний 5e08e6f1 вернул 24-часовой срок и ретроактивно применил его к старым токенам без exp вопреки WMS-513. На проде массовые 401 на worklist и sync.

- R1. Вернуть поведение WMS-513: новые входы без календарного окончания; ранее выданные подписанные токены без exp не отклонять по возрасту.
- R2. Сохранить проверку подписи, существующего exp и актуальных прав пользователя в базе.
- R3. Не менять заказы, остатки, привязки складов и секреты. Выкладывать только эту правку.

## Проверки

| Проверка | Вердикт |
|---|---|
| Старый подписанный токен без exp принимается, новый без exp | Не проверено: проверяется перед выкладкой |
| Неверная подпись и истёкший явно заданный exp отклоняются | Не проверено: проверяется перед выкладкой |
| Прод использует сохранённый файл исправления | Не проверено: ожидает выкладки |

## Заключение

Срочный возврат явно согласованного поведения WMS-513. Аналитика отменена прямым требованием владельца. Результат проверок и выкладки будет дописан после выполнения; восстановление экрана оператора пока не подтверждено.
