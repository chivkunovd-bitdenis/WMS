# WMS-491 · Переход из карточки селлера к его товарам

## Исходный запрос

Из расшифровки встречи 21.09.2026, пункт 5: «быстрый переход из карточки клиента к его товарам». Источник — приложенная к диалогу аудиозапись `PSP.m4a`; временная рабочая расшифровка в репозиторий не добавлялась.

## Подтверждённый текущий процесс

Экран `frontend/src/screens/v2/SellersScreen.tsx` показывает строки селлеров, реквизиты и статус WB. Кнопки/ссылки на каталог с уже установленным `seller_id` в прочитанном коде нет. Каталог ФФ уже имеет фильтр «Селлер». Живой экран не проверялся.

## Требования

**R1.** В строке или карточке селлера есть явное действие перехода к товарам этого селлера.

**R2.** Переход открывает существующий каталог с применённым фильтром этого селлера; товары других селлеров не попадают в результат до снятия фильтра оператором.

**R3.** Новая копия каталога или отдельный экран под этот переход не создаётся.

## Открытые вопросы

Существенных вопросов для минимального сценария нет: запрос совпадает с уже существующим фильтром каталога.
