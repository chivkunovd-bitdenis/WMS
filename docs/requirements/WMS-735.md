**Статус:** ОБЪЁМ ЭТОГО PR. Полное ТЗ WMS-735 лежит в ветке docs/wms735-release-process (файл docs/requirements/WMS-735.md там); при слиянии эти два документа нужно свести.

## Что делает этот PR

Возвращает в etalon состояние прода cb7b4a913: хотфиксы 702, 709, 710, 714 и интеграцию WMS-666 (ветка прода codex/wms666-prod-integration-1009). Делается по правилу R8 (а) полного ТЗ: код хотфиксов возвращается в etalon без новых тестов, чтобы выпуск из etalon их не стёр. Конфликты разрешены по смыслу; подробности в описании PR.

## Заключение

Слияние для возврата выполнено, прод является предком итоговой ветки. До выпуска из etalon нужны три решения: по области WMS-666 (тест wms666ChangeScope), по перепечати после передачи и догон хотфиксов по R8 (б). Зелёный CI на GitHub этим PR пока не подтверждён.
