# WMS-739 · ТСД FBS: подбор → упаковка → передача без кругов

Запись задачи: [канонический бэклог, WMS-739](../KANONICHESKIY_BACKLOG.md#wms-739).
Пакет ТСД по переписке ArtMaks от 08.10.2026 (WMS-736…WMS-741), [макет пакета](../mockups/WMS-736/README.md).
Документ постановки аналитика. Реализации, ревью и приёмки ещё не было.

## 1. Исходный запрос

**Поручение владельца (09.10.2026, через ведущего, почти дословно).** «В ТСД вечно ляпают какую-то хуету: то процессы ходят по кругу… посмотри в целом текущий процесс ТСД — где он отстаёт от нормальной работы, которая есть в основной системе (веб)… Работник склада должен пройти весь путь до конца: нажать сюда, туда… Процесс максимально короткий и понятный, все нужные функции есть».

**Уже действующее решение владельца (WMS-584, уточнение 29.09.2026)** — не меняется: после полного подбора внизу две кнопки «К упаковке» и «Завершить подбор»; «Завершить подбор» возвращает во «В работе»; шаги не блокируются. Экран поставки — «как был» (WMS-584 R8: владелец отклонил перестановку кнопок на нём).

## 2. Как сейчас

Код ТСД — сборка 0.2.0 (код 19), коммит 41f0f33 репозитория WMS-TSD. Пройдены по коду два пути до конца — до передачи поставки в WB.

**Одна поставка.** «В работе» → карточка поставки → экран поставки (название, состав карточками, кнопки «Подбор», «Упаковка и этикетки», ниже «Передать поставку в WB») → «Подбор» → полный подбор → «К упаковке». Переход «К упаковке» кладёт упаковку поверх подбора (Navigation.kt, строка 122), поэтому «Назад» с упаковки возвращает в уже законченный подбор с теми же двумя кнопками, и только второе «Назад» — на экран поставки. На экране упаковки передачи нет (FbsScreens.kt, строки 615–855): чтобы передать, нужно вернуться на экран поставки и пролистать весь состав до кнопки (строки 473–495). Итог: упаковка → «Назад» → подбор → «Назад» → поставка → прокрутка → «Передать».

**Сборочное задание (массовая сборка).** «В работе» → карточка задания: если подбор полный, открывается список поставок задания на упаковке, иначе — общий подбор (FbsScreens.kt, строки 174–178). Список упаковки показывает только «Упаковано X из Y» (строки 929–966), о передаче — ничего. Зайти в поставку → упаковка → передачи нет. Чтобы передать: «Назад» → список → «Назад» → «В работе» → найти карточку этой поставки под заданием → экран поставки → прокрутка → «Передать». Для каждой поставки задания — снова этот круг.

**Веб.** Передача стоит в контексте упаковки: «Передать в WB/Ozon» внизу панели коробов поставки (FfFbsSupplyWorkspace.tsx, строки 5160–5171) и в рамке каждой поставки окна групповой сборки (строки 5225–5228). Подтверждение с предпроверкой — то же окно «Передать поставку в WB?».

**Где ТСД отстаёт.** Передача оторвана от упаковки; «Назад» водит через законченный подбор; в группе не видно, какая поставка уже передана.

## 3. Требования

**R1. Передача на экране упаковки.** Условие: открыт экран «Упаковка FBS» поставки (одиночной или из задания), поставка ещё не передана, и упаковано всё (progress.packed == progress.total > 0). Результат: внизу экрана — крупная кнопка во всю ширину «Передать поставку в WB» (для Ozon — «в Ozon»). Нажатие открывает то же окно подтверждения с предпроверкой, что на экране поставки; после успеха экран показывает «Поставка передана в WB», кнопка исчезает. Основание: поручение владельца («пройти весь путь до конца»); веб держит передачу в контексте упаковки; AGENTS.md, раздел 3 («действие над документом размещай в его контексте»).

**R2. До полной упаковки передача остаётся там, где была.** Пока упаковано не всё, нижней кнопки на упаковке нет; передача по-прежнему доступна на экране поставки, без новых запретов. Предпроверка сервера показывает свои замечания как сейчас. Основание: тот же принцип, что R18 WMS-584 (нижние кнопки появляются по завершении этапа); AGENTS.md, раздел 3 (нет новых блокировок); решение аналитика D1.

**R3. «Назад» не ведёт в законченный подбор.** Условие: из подбора одной поставки нажато «К упаковке». Результат: экран упаковки заменяет экран подбора; «Назад» с упаковки ведёт на экран поставки. Основание: поручение владельца («процессы ходят по кругу»).

**R4. Список поставок задания показывает передачу.** В списке поставок задания на упаковке у переданной поставки вместо прогресса — «Передана в WB» зелёным; у остальных — «Упаковано X из Y» (и «Не подобрано N шт.» по WMS-737). После передачи и «Назад» список перечитан и показывает новое состояние. Основание: поручение владельца («пройти весь путь»); веб показывает переданность в рамке поставки.

**R5. Остальное не меняется.** Экран поставки (вид WMS-584 R8, передача на нём остаётся), «Завершить подбор» во «В работе», общий подбор, упаковка, короба, ЧЗ, окно подтверждения и его предпроверка, восстановление неизвестного результата передачи («Проверить результат передачи»). Основание: WMS-584 R8, R13, R18.

**R6. Повтор передачи безопасен.** Кнопка на упаковке пользуется тем же действием и тем же сохранённым состоянием неизвестного результата, что экран поставки: если ответ передачи потерян, на упаковке вместо «Передать» — «Проверить результат передачи», второй передачи не отправляется. Основание: AGENTS.md, раздел 3; разобранный сбой B09.

## 4. Решения аналитика и вопросы

**D1. Кнопка передачи на упаковке — только после полной упаковки.** На экране 360×640 dp постоянная нижняя кнопка забрала бы 96 dp у карточек заказов на всё время упаковки и подталкивала бы передать раньше времени. Появление по завершении этапа — уже принятый владельцем приём (две кнопки после подбора). Передача до полной упаковки не запрещена: она есть на экране поставки, как сейчас.
**D2.** Автоматического перехода после передачи нет: оператор видит результат там же и сам идёт «Назад».

Вопросов владельцу нет.

## 5. Чек-лист: путь работника по экранам

**Одна поставка.** «В работе» → поставка → «Подбор» → сканы → полный подбор → «К упаковке» → упаковка (QR, ЧЗ, короба, «Отметить упакованным») → всё упаковано → внизу «Передать поставку в WB» → подтверждение → «Поставка передана в WB» → «Назад» → экран поставки (тоже «Поставка передана в WB») → «Назад» → «В работе».
- Нельзя: ничего нового не запрещено. До полной упаковки нижней кнопки нет — передать можно с экрана поставки.
- Ошибка передачи: в окне подтверждения текст сервера и «Проверить ещё раз»; обрыв связи — «Проверить результат передачи».

**Сборочное задание.** «В работе» → задание → общий подбор → «К упаковке» → список поставок → поставка A → упаковка → «Передать поставку в WB» → «Назад» → список: A «Передана в WB» → поставка B → …
