# WMS-721 · FBS Ozon: после передачи — «Отгружено», а не «В доставке»

Статус: заведена 09.10.2026, не начата. Делается по полному процессу (аналитик → тесты до кода →
разработка → ревью → приёмка → CI). Пакет поручений владельца от 09.10.2026: WMS-716…WMS-732.

## Исходное поручение

09.10.2026, сообщение владельца в чате (дословно, с опечатками оригинала):
«озон статус - не в доставке, а в отгружено передать».

## Что проверено при заведении

- Код прода 694de0413: поставка после передачи попадает на вкладку «В доставке», статус поставки
  в списке подписан «В доставке» (supplyStatusLabel: in_delivery), статус заказа — тоже «В доставке»
  (FbsChips.tsx). Кнопка передачи у Ozon — «Передать в Ozon».
- Синхронизация Ozon относит к доставке статусы Ozon delivering, driver_pickup, sent_by_seller,
  к собранным — awaiting_deliver (ozon_fbs_sync_service.py).
- Остаток FBS Ozon списывается при сдаче Ozon в WMS (AGENTS.md, раздел 3) — задача этого не меняет.
- Экран в браузере при заведении не открывался: во встроенном браузере нет входа на прод.

## Требования (предварительно, аналитик уточняет по экрану)

R1. Для Ozon поставка (отправления) после передачи показывается как «Отгружено», а не
«В доставке».
R2. Для WB поведение не меняется.

## Открытые вопросы аналитику

1. Что меняется: только подпись статуса Ozon, вкладка, на которую уходит поставка Ozon, или
   название вкладки — уточнить у владельца.
2. Какие статусы Ozon считать «Отгружено».
