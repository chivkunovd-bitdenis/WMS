# WMS-718 · FBS: в списке заказов уползает заголовок

Статус: заведена 09.10.2026, не начата. Делается по полному процессу (аналитик → тесты до кода →
разработка → ревью → приёмка → CI). Пакет поручений владельца от 09.10.2026: WMS-716…WMS-734.

## Исходное поручение

09.10.2026, сообщение владельца в чате (дословно, с опечатками оригинала):
«уполозает в спритске закзаов заголовок».

## Что проверено при заведении

- Код прода 694de0413, экран «Заказы FBS»: таблица заказов объявлена с закреплённой шапкой
  (stickyHeader). Почему на деле заголовок уползает, по коду не установлено.
- Экран в браузере при заведении не открывался: во встроенном браузере нет входа на прод.
  Воспроизвести на экране — первый шаг аналитика.

## Разбор кода 09.10.2026

Таблица заказов лежит в контейнере с ограниченной высотой и закреплённой шапкой
(TableContainer maxHeight, Table stickyHeader); высота контейнера меняется при появлении панели
выбора заказов. Причину по коду не установить — нужно воспроизвести на экране.

## Требования (предварительно, аналитик уточняет по экрану)

R1. При прокрутке списка заказов FBS заголовок (шапка таблицы) остаётся на месте и совпадает
с колонками.

## Открытые вопросы аналитику

1. Какой именно заголовок уползает: шапка колонок таблицы, заголовок экрана с вкладками или
   фильтры; на какой вкладке и при каком размере окна.
