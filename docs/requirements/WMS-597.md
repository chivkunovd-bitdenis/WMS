# WMS-597 · Проверка процесса Ozon на ТСД

## Исходный запрос и уточнения

30.09.2026: Нужно проверить, что с Ozon всё работает точно так же в ТСД.

Владелец поручил срочную параллельную реализацию Sol/Terra без навыков и отдельной аналитической цепочки, затем изолированное ревью. Деплой и внешние операции этим пакетом не выполняются.

## Требования

**R1.** Проверить существующий процесс Ozon FBS в ТСД: заказы, подбор, упаковка, количество/короба, маркировка и этикетки с учётом отличий API Ozon.

**R2.** Воспроизвести на тестовом контуре; исправить подтверждённые отличия/дефекты, не подменять идентификаторы Ozon полями WB.

**R3.** Сохранить сценарии восстановления/повторов и отделить эмулятор от непроверенного физического сканера/принтера.

## Проверки

| Проверка | Вердикт |
|---|---|
| C1: проверить R1 на собранной реализации | Выполнено на synthetic-контуре для ordinary Ozon FBS: поставка `3b79fa69-b529-41b7-8538-d18953b75a19`, заказы `445-a-0/1/2`, 6 единиц подобраны и упакованы. Созданы три короба на 1/2/3 единицы; API штатно запретил смешать разные Ozon-заказы, но принял две позиции одного заказа. Сборка короба №3 подтверждена Ozon-эмулятором, этикетка открыта в Android Print Spooler. |
| C2: проверить R2 на собранной реализации | Выполнено: коробам передаются `order_product_ids`; товарные этикетки берут текущий `positions[].barcode`/`product.barcode`; ЧЗ разбирает `printed_codes.order_product_id` и сопоставляет с `positions[].id`. Адресный тест сформированного HTML-документа доказал `CIS-A → товар A`, `CIS-B → товар B`. Реальных provider/prod-вызовов не было. |
| C3: проверить R3 на собранной реализации | Выполнено для локального recovery/очереди сканов и debug APK. Физический ТСД, печать на принтере и удалённое развёртывание принтера не проверялись; это отдельный, не подключённый к приложению путь. Маркированного Ozon-заказа в synthetic fixture не было, поэтому ЧЗ проверен mock/fake-контрактом и реально формируемым документом, а не физической печатью. |

## Заключение

Локальная реализация и доступный acceptance-проход выполнены. Два P2 финального
read-only Sol-review исправлены; повторное независимое ревью прошло, а пять хешей из его
заключения совпали с файлами коммита `8f9f4b35a9eab3d52d9422ae15b1f58e1d7859c0`. Публикация намеренно остановлена владельцем: push, merge,
deploy, release и загрузка APK не выполнялись.

Локальный экран Ozon в Android-эмуляторе: [снимок карточки](WMS-597-ozon-emulator.png). Снимок подтверждает отображение карточки; результаты подбора и сборки подтверждаются описанным выше проходом и чтением тестовой БД.
