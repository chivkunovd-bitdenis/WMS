# WMS-752 · Лист подбора Империи ФФ: в строке место, «Взять» из него и стикеры этих штук

**Статус:** ХОТФИКС, ДОГОН НЕ ЗАВЕРШЁН. Ветка hotfix/wms-752 от прода 3ee6383c5.

## Запрос владельца (10.10.2026)

Скриншоты листа подбора Империи: в части строк «Стикер — », заказов нет. Владелец: «если тебе нужно 5 курток собрать, значит у тебя 5 QR-кодов»; «у тебя вот строка с курткой верхняя нормально оформлена… возврат номер, короб такой-то, три заказа и три стикера. Почему так же нельзя сделать?»; «сделай хотфиксом быстро».

## Баг

WMS-710 печатал лист Империи маршрутом вкладки «Подбор» (ячейка → тара → товар) и выводил товар во всех местах, где он лежит. В каждой строке стояло общее «Взять» по товару, заказы, стикеры и маркировка — только в первой строке товара. Поставка Фадина WB-GI-291004731: 229 строк на 68 штук, 179 строк без стикера, Chin-2329Black 54/56 (нужно 2) — 24 строки по «Взять 2»; у Chin-56005black 54 «Взять 3» у короба №15, где лежит 1 штука.

## Требования

- R1. Порядок листа — маршрут вкладки «Подбор» (как WMS-710). В лист идут только места, которые покрывают «Осталось» товара; из места берётся не больше, чем в нём можно снять.
- R2. «Взять» в строке — сколько брать из этого места. В строке заказы и стикеры именно этих штук и маркировка товара. У неподобранного товара нет строк без стикера; для WB число стикеров в строке равно «Взять».
- R3. Каждый заказ поставки (или сборки) печатается ровно один раз. Уже подобранные штуки — строкой «Подобрано», нехватка мест — строкой «Нет текущего остатка», обе со своими заказами.
- R4. Отправление Ozon с несколькими штуками товара — одна строка заказа на эти штуки, не дробится по штукам без нужды.
- R5. Карточка поставки и групповая сборка печатают одинаково. Остальные клиенты печатают как раньше.
