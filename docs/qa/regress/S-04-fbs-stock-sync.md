# S-04 — Остатки FBS

Маршрут: `/app/ff/fbs/stock-sync`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «FBS».
- Значимый элемент «Склад WB».
- Основное действие «Обновить».
- Пустое состояние «У этого селлера нет складов Wildberries».

## Кейсы

- **TC-S04-P01.** Открываю /app/ff/fbs/stock-sync → жду заголовок «FBS» и рабочий каркас портала.
- **TC-S04-P02.** Открываю экран → нахожу «Склад WB» → элемент видим и доступен оператору.
- **TC-S04-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «У этого селлера нет складов Wildberries», без пустой белой страницы.
- **TC-S04-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S04-R01.** Открываю экран → дважды быстро жму «Обновить» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S04-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S04-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S04-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
