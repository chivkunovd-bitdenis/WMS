# S-16 — Каталог ФФ

Маршрут: `/app/ff/products`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Каталог».
- Значимый элемент «Короба и грузоместа».
- Основное действие «Создать товар».
- Пустое состояние «В каталоге пока нет товаров».

## Кейсы

- **TC-S16-P01.** Открываю /app/ff/products → жду заголовок «Каталог» и рабочий каркас портала.
- **TC-S16-P02.** Открываю экран → нахожу «Короба и грузоместа» → элемент видим и доступен оператору.
- **TC-S16-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «В каталоге пока нет товаров», без пустой белой страницы.
- **TC-S16-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S16-R01.** Открываю экран → дважды быстро жму «Создать товар» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S16-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S16-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S16-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
