# S-26 — Документы селлера

Маршрут: `/seller/documents`. Портал: селлер.

## Что видно на живом экране

- Заголовок «Документы».
- Значимый элемент «Тип документа».
- Основное действие «Создать заявку на поставку».
- Пустое состояние «Нет документов».

## Кейсы

- **TC-S26-P01.** Открываю /seller/documents → жду заголовок «Документы» и рабочий каркас портала.
- **TC-S26-P02.** Открываю экран → нахожу «Тип документа» → элемент видим и доступен оператору.
- **TC-S26-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Нет документов», без пустой белой страницы.
- **TC-S26-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S26-R01.** Открываю экран → дважды быстро жму «Создать заявку на поставку» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S26-R02.** Задерживаю ответ основного API → сразу ухожу на /seller/documents → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S26-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S26-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
