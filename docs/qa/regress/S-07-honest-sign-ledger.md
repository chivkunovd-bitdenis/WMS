# S-07 — Лента расхода КМ

Маршрут: `/app/ff/honest-sign/ledger`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Лента расхода».
- Значимый элемент «Событие».
- Основное действие «Экспорт».
- Пустое состояние «События не найдены».

## Кейсы

- **TC-S07-P01.** Открываю /app/ff/honest-sign/ledger → жду заголовок «Лента расхода» и рабочий каркас портала.
- **TC-S07-P02.** Открываю экран → нахожу «Событие» → элемент видим и доступен оператору.
- **TC-S07-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «События не найдены», без пустой белой страницы.
- **TC-S07-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S07-R01.** Открываю экран → дважды быстро жму «Экспорт» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S07-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S07-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S07-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
