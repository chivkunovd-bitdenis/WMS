# S-28 — Черновик поставки селлера

Маршрут: `/seller/inbound/:requestId`. Портал: селлер.

## Что видно на живом экране

- Заголовок «Заявка на поставку».
- Значимый элемент «Добавить товары».
- Основное действие «Отправить».
- Пустое состояние «Нет товаров».

## Кейсы

- **TC-S28-P01.** Открываю /seller/inbound/:requestId → жду заголовок «Заявка на поставку» и рабочий каркас портала.
- **TC-S28-P02.** Открываю экран → нахожу «Добавить товары» → элемент видим и доступен оператору.
- **TC-S28-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Нет товаров», без пустой белой страницы.
- **TC-S28-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S28-R01.** Открываю экран → дважды быстро жму «Отправить» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S28-R02.** Задерживаю ответ основного API → сразу ухожу на /seller/documents → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S28-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S28-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
