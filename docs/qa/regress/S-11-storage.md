# S-11 — Хранение

Маршрут: `/app/ff/inventory`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Хранение».
- Значимый элемент «Литро-дни».
- Основное действие «Сформировать за месяц».
- Пустое состояние «Тариф хранения ещё не задан».

## Кейсы

- **TC-S11-P01.** Открываю /app/ff/inventory → жду заголовок «Хранение» и рабочий каркас портала.
- **TC-S11-P02.** Открываю экран → нахожу «Литро-дни» → элемент видим и доступен оператору.
- **TC-S11-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Тариф хранения ещё не задан», без пустой белой страницы.
- **TC-S11-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S11-R01.** Открываю экран → дважды быстро жму «Сформировать за месяц» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S11-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S11-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S11-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
