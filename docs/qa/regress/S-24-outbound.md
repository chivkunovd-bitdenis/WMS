# S-24 — Отгрузка

Маршрут: `/app/ops/outbound`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Отгрузка».
- Значимый элемент «Провести весь остаток».
- Основное действие «Новая заявка на отгрузку».
- Пустое состояние «Пока нет заявок».

## Кейсы

- **TC-S24-P01.** Открываю /app/ops/outbound → жду заголовок «Отгрузка» и рабочий каркас портала.
- **TC-S24-P02.** Открываю экран → нахожу «Провести весь остаток» → элемент видим и доступен оператору.
- **TC-S24-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Пока нет заявок», без пустой белой страницы.
- **TC-S24-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S24-R01.** Открываю экран → дважды быстро жму «Новая заявка на отгрузку» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S24-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S24-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S24-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
