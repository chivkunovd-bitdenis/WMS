# S-20 — Сортировка

Маршрут: `/app/ff/sorting`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Сортировка».
- Значимый элемент «Зона «Сортировка»».
- Основное действие «Выйти».
- Пустое состояние «Нет приёмок в сортировке».

## Кейсы

- **TC-S20-P01.** Открываю /app/ff/sorting → жду заголовок «Сортировка» и рабочий каркас портала.
- **TC-S20-P02.** Открываю экран → нахожу «Зона «Сортировка»» → элемент видим и доступен оператору.
- **TC-S20-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Нет приёмок в сортировке», без пустой белой страницы.
- **TC-S20-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S20-R01.** Открываю экран → дважды быстро жму «Выйти» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S20-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S20-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S20-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
