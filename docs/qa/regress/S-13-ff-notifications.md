# S-13 — Уведомления ФФ

Маршрут: `/app/ff/notifications`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Уведомления».
- Значимый элемент «Нет уведомлений».
- Основное действие «Выйти».
- Пустое состояние «Нет уведомлений».

## Кейсы

- **TC-S13-P01.** Открываю /app/ff/notifications → жду заголовок «Уведомления» и рабочий каркас портала.
- **TC-S13-P02.** Открываю экран → нахожу «Нет уведомлений» → элемент видим и доступен оператору.
- **TC-S13-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Нет уведомлений», без пустой белой страницы.
- **TC-S13-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S13-R01.** Открываю экран → дважды быстро жму «Выйти» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S13-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S13-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S13-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
