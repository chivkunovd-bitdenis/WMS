# S-22 — Приёмка

Маршрут: `/app/ops/inbound`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Приёмка».
- Значимый элемент «Тип операции».
- Основное действие «Новая заявка на приёмку».
- Пустое состояние «Пока нет заявок».

## Кейсы

- **TC-S22-P01.** Открываю /app/ops/inbound → жду заголовок «Приёмка» и рабочий каркас портала.
- **TC-S22-P02.** Открываю экран → нахожу «Тип операции» → элемент видим и доступен оператору.
- **TC-S22-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Пока нет заявок», без пустой белой страницы.
- **TC-S22-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S22-R01.** Открываю экран → дважды быстро жму «Новая заявка на приёмку» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S22-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S22-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S22-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
