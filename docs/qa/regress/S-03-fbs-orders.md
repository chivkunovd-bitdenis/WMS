# S-03 — Заказы FBS

Маршрут: `/app/ff/fbs`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Заказы FBS».
- Значимый элемент «Заказов в этой группе нет».
- Основное действие «Забрать заказы из WB».
- Пустое состояние «Заказов в этой группе нет».

## Кейсы

- **TC-S03-P01.** Открываю /app/ff/fbs → жду заголовок «Заказы FBS» и рабочий каркас портала.
- **TC-S03-P02.** Открываю экран → нахожу «Заказов в этой группе нет» → элемент видим и доступен оператору.
- **TC-S03-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Заказов в этой группе нет», без пустой белой страницы.
- **TC-S03-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S03-R01.** Открываю экран → дважды быстро жму «Забрать заказы из WB» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S03-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S03-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S03-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
