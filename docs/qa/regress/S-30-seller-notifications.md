# S-30 — Уведомления селлера

Маршрут: `/seller/notifications`. Портал: селлер.

## Что видно на живом экране

- Заголовок «Уведомления».
- Значимый элемент «Нет уведомлений».
- Основное действие «Выйти».
- Пустое состояние «Нет уведомлений».

## Кейсы

- **TC-S30-P01.** Открываю /seller/notifications → жду заголовок «Уведомления» и рабочий каркас портала.
- **TC-S30-P02.** Открываю экран → нахожу «Нет уведомлений» → элемент видим и доступен оператору.
- **TC-S30-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Нет уведомлений», без пустой белой страницы.
- **TC-S30-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S30-R01.** Открываю экран → дважды быстро жму «Выйти» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S30-R02.** Задерживаю ответ основного API → сразу ухожу на /seller/documents → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S30-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S30-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
