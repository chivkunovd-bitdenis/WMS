# S-21 — Интеграция Wildberries

Маршрут: `/app/integrations/wb`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Wildberries».
- Значимый элемент «Импортированные карточки».
- Основное действие «Привязать».
- Пустое состояние «Нужен хотя бы один селлер».

## Кейсы

- **TC-S21-P01.** Открываю /app/integrations/wb → жду заголовок «Wildberries» и рабочий каркас портала.
- **TC-S21-P02.** Открываю экран → нахожу «Импортированные карточки» → элемент видим и доступен оператору.
- **TC-S21-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Нужен хотя бы один селлер», без пустой белой страницы.
- **TC-S21-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S21-R01.** Открываю экран → дважды быстро жму «Привязать» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S21-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S21-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S21-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
