# S-15 — Ожидают маркировки

Маршрут: `/app/ff/packaging/pending-marking`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Осталось промаркировать».
- Значимый элемент «0 строк».
- Основное действие «Выйти».
- Пустое состояние «Все требуемые КМ напечатаны».

## Кейсы

- **TC-S15-P01.** Открываю /app/ff/packaging/pending-marking → жду заголовок «Осталось промаркировать» и рабочий каркас портала.
- **TC-S15-P02.** Открываю экран → нахожу «0 строк» → элемент видим и доступен оператору.
- **TC-S15-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Все требуемые КМ напечатаны», без пустой белой страницы.
- **TC-S15-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S15-R01.** Открываю экран → дважды быстро жму «Выйти» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S15-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S15-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S15-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
