# S-31 — Товары селлера

Маршрут: `/seller/products`. Портал: селлер.

## Что видно на живом экране

- Заголовок «Товары».
- Значимый элемент «Остаток».
- Основное действие «Выйти».
- Пустое состояние «Нет товаров».

## Кейсы

- **TC-S31-P01.** Открываю /seller/products → жду заголовок «Товары» и рабочий каркас портала.
- **TC-S31-P02.** Открываю экран → нахожу «Остаток» → элемент видим и доступен оператору.
- **TC-S31-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Нет товаров», без пустой белой страницы.
- **TC-S31-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S31-R01.** Открываю экран → дважды быстро жму «Выйти» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S31-R02.** Задерживаю ответ основного API → сразу ухожу на /seller/documents → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S31-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S31-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
