# S-01 — Товары SKU

Маршрут: `/app/catalog/products`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Товары (SKU)».
- Значимый элемент «SKU».
- Основное действие «Добавить товар».
- Пустое состояние «Ничего не найдено.».

## Кейсы

- **TC-S01-P01.** Открываю /app/catalog/products → жду заголовок «Товары (SKU)» и рабочий каркас портала.
- **TC-S01-P02.** Открываю экран → нахожу «SKU» → элемент видим и доступен оператору.
- **TC-S01-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Ничего не найдено.», без пустой белой страницы.
- **TC-S01-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S01-R01.** Открываю экран → дважды быстро жму «Добавить товар» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S01-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S01-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S01-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
