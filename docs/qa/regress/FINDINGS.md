# Находки регрессионного обхода

Здесь фиксируются продуктовые дефекты и экраны, которые не удалось пройти живым кликом за два захода. Инфраструктурная причина отдельно помечается и не выдаётся за дефект продукта.

- **S-28 не покрыт живым кликом.** Две попытки создать тестовую учётную запись селлера на актуальной локальной базе завершились инфраструктурной ошибкой `sqlite3.OperationalError: unable to open database file`: на хосте закончился диск. Исполняемые кейсы записаны по актуальному маршруту и существующему контракту экрана; живой прогон нужно повторить после освобождения места. Это не признано дефектом продукта.
- **S-29 не покрыт живым кликом.** Причина та же: после двух попыток локальная SQLite-база не смогла записать тестового селлера из-за заполненного диска. Кейсы для новой поставки добавлены, но живой вердикт по экрану отложен; продуктовый дефект не заявляется.
- **S-31 не покрыт живым кликом.** Портал селлера не удалось подготовить за два захода из-за невозможности записи тестового аккаунта на заполненном диске. Кейсы каталога селлера добавлены без заявления о живом продуктовом вердикте.
- **S-26 не покрыт живым кликом.** Экран документов селлера остался без живой проверки: обе попытки создать локального селлера остановила инфраструктурная ошибка записи SQLite на заполненном диске. Исполняемые кейсы добавлены; продуктовый дефект не заявляется.
- **S-30 не покрыт живым кликом.** Уведомления селлера не открывались в авторизованном портале после двух неудачных попыток подготовить тестовый аккаунт на заполненном диске. Кейсы добавлены по актуальному маршруту; продуктовый дефект не заявляется.
- **S-27 не покрыт живым кликом.** Честный знак селлера остался без авторизованного живого обхода: обе попытки создать локального селлера завершились инфраструктурным отказом SQLite из-за заполненного диска. Кейсы добавлены, продуктовый дефект не заявляется.
