# S-02 — Календарь отгрузок

Маршрут: `/app/ff/dashboard`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Календарь отгрузок».
- Значимый элемент «август 2026».
- Основное действие «Следующий месяц».
- Пустое состояние «Календарь без событий».

## Кейсы

- **TC-S02-P01.** Открываю /app/ff/dashboard → жду заголовок «Календарь отгрузок» и рабочий каркас портала.
- **TC-S02-P02.** Открываю экран → нахожу «август 2026» → элемент видим и доступен оператору.
- **TC-S02-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Календарь без событий», без пустой белой страницы.
- **TC-S02-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S02-R01.** Открываю экран → дважды быстро жму «Следующий месяц» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S02-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S02-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S02-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
