# S-09 — Товар в ЧЗ

Маршрут: `/app/ff/honest-sign/product/:productId`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Карточка товара».
- Значимый элемент «Лента».
- Основное действие «Коды».
- Пустое состояние «Товар не найден».

## Кейсы

- **TC-S09-P01.** Открываю /app/ff/honest-sign/product/:productId → жду заголовок «Карточка товара» и рабочий каркас портала.
- **TC-S09-P02.** Открываю экран → нахожу «Лента» → элемент видим и доступен оператору.
- **TC-S09-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Товар не найден», без пустой белой страницы.
- **TC-S09-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S09-R01.** Открываю экран → дважды быстро жму «Коды» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S09-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S09-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S09-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
