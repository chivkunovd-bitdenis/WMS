# S-06 — Импорт КМ

Маршрут: `/app/ff/honest-sign/import`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Честный знак».
- Значимый элемент «Общая корзина».
- Основное действие «Загрузить КМ».
- Пустое состояние «Пока нет кодов маркировки».

## Кейсы

- **TC-S06-P01.** Открываю /app/ff/honest-sign/import → жду заголовок «Честный знак» и рабочий каркас портала.
- **TC-S06-P02.** Открываю экран → нахожу «Общая корзина» → элемент видим и доступен оператору.
- **TC-S06-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Пока нет кодов маркировки», без пустой белой страницы.
- **TC-S06-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S06-R01.** Открываю экран → дважды быстро жму «Загрузить КМ» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S06-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S06-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S06-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
