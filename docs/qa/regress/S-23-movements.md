# S-23 — Журнал движений

Маршрут: `/app/ops/movements`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Журнал движений».
- Значимый элемент «Изменение».
- Основное действие «Обновить».
- Пустое состояние «Движений пока нет».

## Кейсы

- **TC-S23-P01.** Открываю /app/ops/movements → жду заголовок «Журнал движений» и рабочий каркас портала.
- **TC-S23-P02.** Открываю экран → нахожу «Изменение» → элемент видим и доступен оператору.
- **TC-S23-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Движений пока нет», без пустой белой страницы.
- **TC-S23-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S23-R01.** Открываю экран → дважды быстро жму «Обновить» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S23-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S23-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S23-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
