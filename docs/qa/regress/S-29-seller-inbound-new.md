# S-29 — Новая поставка селлера

Маршрут: `/seller/inbound/new`. Портал: селлер.

## Что видно на живом экране

- Заголовок «Заявка на поставку».
- Значимый элемент «Плановая дата».
- Основное действие «Добавить товары».
- Пустое состояние «Нет товаров».

## Кейсы

- **TC-S29-P01.** Открываю /seller/inbound/new → жду заголовок «Заявка на поставку» и рабочий каркас портала.
- **TC-S29-P02.** Открываю экран → нахожу «Плановая дата» → элемент видим и доступен оператору.
- **TC-S29-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Нет товаров», без пустой белой страницы.
- **TC-S29-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S29-R01.** Открываю экран → дважды быстро жму «Добавить товары» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S29-R02.** Задерживаю ответ основного API → сразу ухожу на /seller/documents → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S29-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S29-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
