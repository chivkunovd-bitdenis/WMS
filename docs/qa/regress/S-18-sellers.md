# S-18 — Селлеры

Маршрут: `/app/ff/sellers`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Селлеры».
- Значимый элемент «Email для входа».
- Основное действие «Добавить селлера».
- Пустое состояние «Пока нет селлеров».

## Кейсы

- **TC-S18-P01.** Открываю /app/ff/sellers → жду заголовок «Селлеры» и рабочий каркас портала.
- **TC-S18-P02.** Открываю экран → нахожу «Email для входа» → элемент видим и доступен оператору.
- **TC-S18-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Пока нет селлеров», без пустой белой страницы.
- **TC-S18-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S18-R01.** Открываю экран → дважды быстро жму «Добавить селлера» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S18-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S18-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S18-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
