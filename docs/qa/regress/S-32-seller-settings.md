# S-32 — Настройки селлера

Маршрут: `/seller/settings`. Портал: селлер.

## Что видно на живом экране

- Заголовок «Настройки».
- Значимый элемент «Wildberries».
- Основное действие «Сохранить».
- Пустое состояние «Настройки не загружены».

## Кейсы

- **TC-S32-P01.** Открываю /seller/settings → жду заголовок «Настройки» и рабочий каркас портала.
- **TC-S32-P02.** Открываю экран → нахожу «Wildberries» → элемент видим и доступен оператору.
- **TC-S32-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Настройки не загружены», без пустой белой страницы.
- **TC-S32-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S32-R01.** Открываю экран → дважды быстро жму «Сохранить» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S32-R02.** Задерживаю ответ основного API → сразу ухожу на /seller/documents → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S32-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S32-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
