# S-08 — Пул КМ

Маршрут: `/app/ff/honest-sign/pool/:poolId`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Карточка пула».
- Значимый элемент «Обзор».
- Основное действие «Коды».
- Пустое состояние «Пул КМ не найден».

## Кейсы

- **TC-S08-P01.** Открываю /app/ff/honest-sign/pool/:poolId → жду заголовок «Карточка пула» и рабочий каркас портала.
- **TC-S08-P02.** Открываю экран → нахожу «Обзор» → элемент видим и доступен оператору.
- **TC-S08-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Пул КМ не найден», без пустой белой страницы.
- **TC-S08-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S08-R01.** Открываю экран → дважды быстро жму «Коды» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S08-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S08-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S08-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
