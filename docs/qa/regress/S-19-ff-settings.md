# S-19 — Настройки ФФ

Маршрут: `/app/ff/settings`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Настройки».
- Значимый элемент «Время отсечки FBS».
- Основное действие «Сохранить».
- Пустое состояние «Сотрудников пока нет».

## Кейсы

- **TC-S19-P01.** Открываю /app/ff/settings → жду заголовок «Настройки» и рабочий каркас портала.
- **TC-S19-P02.** Открываю экран → нахожу «Время отсечки FBS» → элемент видим и доступен оператору.
- **TC-S19-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Сотрудников пока нет», без пустой белой страницы.
- **TC-S19-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S19-R01.** Открываю экран → дважды быстро жму «Сохранить» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S19-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S19-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S19-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
