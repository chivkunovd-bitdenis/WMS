# S-14 — Упаковка

Маршрут: `/app/ff/packaging`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Упаковка».
- Значимый элемент «Открытые».
- Основное действие «Создать задание».
- Пустое состояние «Нет открытых заданий».

## Кейсы

- **TC-S14-P01.** Открываю /app/ff/packaging → жду заголовок «Упаковка» и рабочий каркас портала.
- **TC-S14-P02.** Открываю экран → нахожу «Открытые» → элемент видим и доступен оператору.
- **TC-S14-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Нет открытых заданий», без пустой белой страницы.
- **TC-S14-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S14-R01.** Открываю экран → дважды быстро жму «Создать задание» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S14-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S14-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S14-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
