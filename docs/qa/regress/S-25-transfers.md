# S-25 — Перемещения

Маршрут: `/app/ops/transfers`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Перемещения».
- Значимый элемент «Откуда».
- Основное действие «Переместить».
- Пустое состояние «Выберите товар».

## Кейсы

- **TC-S25-P01.** Открываю /app/ops/transfers → жду заголовок «Перемещения» и рабочий каркас портала.
- **TC-S25-P02.** Открываю экран → нахожу «Откуда» → элемент видим и доступен оператору.
- **TC-S25-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Выберите товар», без пустой белой страницы.
- **TC-S25-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S25-R01.** Открываю экран → дважды быстро жму «Переместить» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S25-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S25-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S25-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
