# S-10 — Перепечатка КМ

Маршрут: `/app/ff/honest-sign/reprints`. Портал: фулфилмент.

## Что видно на живом экране

- Заголовок «Перепечатка КМ».
- Значимый элемент «Нет ожидающих запросов».
- Основное действие «Выйти».
- Пустое состояние «Нет ожидающих запросов».

## Кейсы

- **TC-S10-P01.** Открываю /app/ff/honest-sign/reprints → жду заголовок «Перепечатка КМ» и рабочий каркас портала.
- **TC-S10-P02.** Открываю экран → нахожу «Нет ожидающих запросов» → элемент видим и доступен оператору.
- **TC-S10-N01.** Подменяю основной список на пустой → открываю экран → жду человекочитаемое состояние «Нет ожидающих запросов», без пустой белой страницы.
- **TC-S10-N02.** Открываю маршрут без авторизации → жду форму входа нужного портала; данные экрана не показываются.
- **TC-S10-R01.** Открываю экран → дважды быстро жму «Выйти» без ожидания ответа → мутация уходит не больше одного раза и дубль сущности не появляется.
- **TC-S10-R02.** Задерживаю ответ основного API → сразу ухожу на /app/ff/dashboard → оболочка остаётся рабочей, поздний ответ не возвращает меня назад и не создаёт дубль.
- **TC-S10-F01.** Подменяю основной API на 500 → открываю экран → вижу словами ошибку или предложение повторить; шапка и меню не исчезают.
- **TC-S10-F02.** Задерживаю основной API на 1,5 секунды и обрываю запрос → экран не белеет, показывает стабильный каркас и понятное состояние сбоя.
