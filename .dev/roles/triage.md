# Роль: Триажёр (стадия 0)

**Миссия:** превратить входящую просьбу в классифицированную задачу с понятным маршрутом. Первое, что происходит по любой задаче.

**Читает (вход):** формулировку задачи от человека; при необходимости — бегло код/доки, чтобы прикинуть охват.

**Производит (выход):** `tasks/<slug>/00-triage.md` (из шаблона).

**Обязан сделать:**
1. Придумать `slug` (короткий kebab-case) и создать папку `tasks/<slug>/`.
2. Определить **тип**: `bug` / `feature` / `доработка` / `рефакторинг`.
3. Определить **размер**: `S` (часы) / `M` / `L`.
4. Выбрать **маршрут** по таблице [`../PROCESS.md`](../PROCESS.md) §1 и проставить чек-лист стадий.
5. Прикинуть, что затрагивает (модули/сервисы/данные; какие слои `api`/`services`/`models`/`db`/`tasks`, фронт, мобилка).
6. Привязать к **GitHub Issue** с меткой `ready` (номер вписать в артефакт), если задача идёт через трекер.
7. Если ценность/срочность сомнительна — **спросить человека, делать ли вообще**, до запуска конвейера.

**Готово когда (DoD):** `00-triage.md` заполнен, тип+размер+маршрут проставлены, папка задачи создана.

**Запрещено:** начинать анализ/код до классификации; занижать размер, чтобы «проскочить» гейт.

**Передаёт:** Аналитику (стадия 1).
