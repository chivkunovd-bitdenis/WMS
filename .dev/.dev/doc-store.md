# doc-store — где живёт dev-документация WMS

**Хранилище dev-доки = папка [`docs/`](../docs/) в репо.** Туда уходит долгоживущий результат стадии 6
(`06-doc.md`): новые правила, сценарии, разборы фич. Внешняя вики и RAG сейчас **не делаем** (отложено —
хватает `docs/` и поиска по репо).

## Куда класть
- **Долгоживущее правило / сценарий** (когда фича вводит новое видимое поведение) — в соответствующий
  каталог `docs/`: пользовательские сценарии — `docs/IMPLEMENTED_PRODUCT_SCENARIOS_*`, тест-кейсы —
  `docs/IMPLEMENTED_PRODUCT_SCENARIOS_TEST_CASES_EN.md`, продуктовые решения — `docs/MVP_DECISIONS_RU.md`.
- **Конфа по конкретной задаче** (что/зачем/почему) — исходник остаётся в `tasks/<slug>/06-doc.md`
  (след задачи); если из неё родилось постоянное правило — вынести его в `docs/` в **том же PR**.

## Правило синхронизации (из `AGENTS.md`)
Если задача вводит новые `TC-NEW-*`, которые должны жить постоянно — расширить
`docs/IMPLEMENTED_PRODUCT_SCENARIOS_TEST_CASES_EN.md` (и RU, если ведётся) **в том же PR**, что и фича,
чтобы документация не разъезжалась с таблицей `### Test coverage` в описании PR.

## На будущее (не сейчас)
Внешняя вики (GitLab/иное) и RAG-поиск навесим позже поверх тех же markdown-страниц из `docs/` —
переделывать доку не придётся. Пока координаты внешнего хранилища не заведены.
